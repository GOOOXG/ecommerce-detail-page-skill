# 商品图深度推演与图生图分镜技能

这是一个只为“商品参考图 → 商品卡待确认 → 用户确认 → 已确认商品卡 → 需求预判/输出范围 → 图组结构 → 5个综合方向 → 逐张确认 → 中文图生图分镜提示词 → 可选生图”服务的 Codex 技能。

它先实际识别图片中的商品主体，再由 AI 预构建卖点、事实需求、素材缺口和建议图片；你可以用数字选择，也可以直接纠正。选择后先生成商品卡（待确认），你明确确认后才进入需求预判、输出范围、结构、方向、图组规划和正式提示词编写。提示词完整交付后，是否生图、生成哪些分镜和每张生成几张，都由你决定。

商业、运营、产品、营销、消费者心理和美学知识只在后台帮助判断“做什么图、为什么做、怎样画”，不会另外生成运营报告、营销方案或产品分析报告。

## 核心能力

- 实际查看参考图，识别商品主体、品类、品牌、型号、SKU、颜色、容量、状态、包装和配件。
- 建立稳定的`参考图1、参考图2……`编号，并说明每张图能证明什么。
- AI预构建候选卖点、需要用户补充的事实与内容、可用素材、缺失素材、建议图片和生产条件。
- 用编号选择或自然语言手动纠正，先生成一张商品卡（待确认）；你明确确认后才形成已确认商品卡。
- 商品卡确认后展示设计需求预判卡，让用户确认真实输出对象、分镜数量、平台、用途和多 SKU 映射。
- 多图支持递进式主次、等量并列、混合结构；结构确定后固定推演5个产品专属综合方向。
- 从买家识别、理解、选型、证明、使用和防错任务中判断真正需要的图片数量，拒绝重复凑图。
- 输出主图、SKU图、详情页、海报、白底图、透明图和无字场景图的逐张中文图生图分镜提示词。
- 对背面、底部、内部、拆解分别计算还原置信度；只有91–100分才可做高置信推定/示意。
- 复杂任务可由商品识别、预构建、图组、视觉、提示词和独立审查子智能体分工，主控统一合并。
- 通过推演循环和经授权的偏好学习，提高后续分镜与用户思维的匹配度。
- 交互模式逐张展示完整确认卡；确认本张或返修后才进入下一张，也可授权剩余图片自动复核。
- 提示词交付后可选生图，可指定分镜、图组和每张候选数量。

## 唯一流程

```text
识别商品主体
  ↓
AI预构建（卖点、事实、素材、图片建议、视图置信度）
  ↓
用户数字选择或手动纠正
  ↓
商品卡（待确认）
  ↓
用户确认
  ↓
已确认商品卡
  ↓
设计需求预判与输出范围确认
  ↓
多图结构选择
  ↓
固定5个综合方向
  ↓
图组编排与逐张确认
  ↓
逐张中文图生图分镜提示词
  ↓
可选生图与候选数量
```

商品卡是中间确认依据，不是最终报告。最终核心交付始终是逐张图生图分镜提示词。

运行规则详见：[预构建与已确认商品卡](ecommerce-detail-page/references/prebuild-and-product-card.md)。

## 推进方式

| 说法 | 技能如何处理 |
|---|---|
| “先推荐让我选” | 展示主体、卖点、资料、素材、图片和视图置信度的编号建议 |
| “逐张确认” | 商品卡确认后，每张分镜先给完整确认内容，确认或返修后再继续 |
| “全部采用AI推荐并确认” | 压缩可见选择，但仍完成识别、冲突检查和商品卡；不代表授权生图 |
| “直接完成，只要提示词” | 仍先在内部生成并记录商品卡（待确认），把用户明示直出视为确认后完成其余判断，外部只保留最终逐张中文分镜 |
| “继续” | 商品卡待确认时先回问确认或纠正；在预判/范围阶段确认当前意向，在结构/方向阶段采用首推，在单图阶段只确认当前图 |
| “确认本张，剩余自动完成” | 确认当前图后，剩余图片进入内部自动复核并在最后统一交付 |
| “暂不生图” | 提示词交付后结束，不调用生图工具 |

## 第一步：图片识别

技能会按上传顺序建立参考图编号，并实际查看每张可访问图片，整理：

- 商品主体、品类和主要用途。
- 品牌、型号、SKU、颜色、容量、尺寸、状态和套装关系。
- 轮廓、结构、部件数量、颜色、可观察表面、标志、包装和配件。
- 每张参考图的职责：身份、视角、细节、文字、包装、配件、尺度或场景。
- 哪些是图片直接可见事实，哪些是用户提供事实，哪些只是策略推断或待验证内容。

如果图片无法支持主体或 SKU 判断，技能会指出最小冲突并请你补充；不会先猜一个商品再继续写提示词。

## 第二步：AI预构建

主体候选建立后，技能在一次对话中集中展示需要你确认的内容：

1. 候选卖点，以及每个卖点的依据或缺失证据。
2. 需要你提供的准确事实，例如尺寸、容量、材质、适配、数量、安装方式或包装清单。
3. 已有素材能证明什么，以及缺少哪些角度、细节、参数、实拍或三维资料。
4. 建议制作的图片、每张解决的买家问题和不做的代价。
5. 可用的视角、场景、人物、画布、后期和图生图生产条件。
6. 背面、底部、内部、拆解的独立还原置信度。

AI只建议你提供哪些资料，不会把猜测的数值当成事实。通常只给3到5项最有价值的补充建议；资料充分时会自动减少。

## 第三步：数字选择与手动纠正

建议卡的编号只用于当前卡；看到新的建议卡后按新卡重新选择，不沿用旧卡编号。推荐回复格式：

```text
主体：1
卖点：1,3
补充：容量=750ml
采用素材：1,2
建议图片：1,2,4
背面：采用92分高置信推定
底部：不做
```

也可以直接回复“全部采用AI推荐并确认”，或指出错误：

```text
参考图1和参考图2是同一款，容量不是500ml而是750ml；卖点3没有检测报告，不采用；只做主图4张。
```

用户手动纠正优先级最高。纠正后技能会重发受影响的建议，不会继续使用旧的 SKU、容量或卖点。

### 建议卡示例

```text
【AI预构建建议】
主体候选：1. 不锈钢保温杯（高）  2. 旅行水壶（中）
采用卖点：1. 双层保温结构  2. 防漏杯盖
需要补充：1. 准确容量  2. 材质证明  3. 包装清单
采用素材：1. 参考图1正面  2. 参考图2杯盖细节
建议图片：1. 首屏识别  2. 防漏证据  3. 使用尺度
视图推定：背面92分，底部68分，内部54分，拆解41分

1. 采用AI首推并生成商品卡（待确认）
2. 修改主体或SKU
3. 修改卖点
4. 补充事实或素材
5. 修改建议图片和数量
6. 逐项重新选择
7. 直接输入纠正
```

## 第四步：生成并确认商品卡

选择或纠正后会先生成一张标明“待确认”的紧凑商品卡：

- 商品主体与识别置信度。
- 品类、品牌、型号，以及 SKU 清单、身份参考图、颜色、容量和状态。
- 图片可见事实与用户确认事实。
- 已采用卖点、待补证卖点和已跳过内容。
- 已有素材、缺失素材及其职责。
- 用户原始输出意向（只作为待范围确认线索，不当作已确认对象或数量）。
- 必须保持、允许变化和禁止内容。
- 每个隐藏视图的独立置信度与事实边界。

请回复“确认商品卡”或直接指出需要修改的字段。待确认卡阶段不再提供裸数字确认菜单；只回复“1”等数字不视为确认，需回到“确认商品卡”或字段纠正。只有明确确认后，商品卡才标记为“已确认商品卡”，技能才会进入设计需求预判和输出范围确认；非关键资料可以选择跳过，相关主张会从后续设计中删除；主体、SKU、安全或合法性仍不成立时只问一个关键问题。用户明确要求“全部采用AI推荐并直接确认”时，仍先生成并记录商品卡（待确认），把这句话视为用户明确确认，经内部冲突检查通过后直接标记确认，不再额外停顿。

## 隐藏视图置信度规则

背面、底部、内部和拆解必须分别评分，不能用一个总分放开所有未知结构。评分参考可见几何、对称和连续结构、同 SKU 线索、品类结构稳定度、冲突数量和隐藏复杂度。

- `91–100分`：允许进入写实分镜，但必须标注“高置信推定/示意”，不能说成官方已证实结构。
- `0–90分`：不写实补画，改用已证实角度、补拍、真实商品层合成、三维资料或明确概念稿。
- `90分`不放行，因为门槛是“高于90分”。

“写实”只代表画面制作方式，不代表资料已经证明。补充同款资料后，相关目标视图重新独立评分。

## 第五步：设计需求预判与输出范围

商品卡确认后，先展示覆盖全部可能对象的设计需求预判卡，再让你确认真正要交付的范围。预判卡不是运营报告，而是把商品事实转成图片选择：

```text
【设计需求预判卡】
- 已确认商品：品类、商品关系和核心视觉锚点
- 已捕捉意向：原话中已经点名的对象、数量、平台或用途
- 主图：适合解决什么问题、现有依据和主要风险
- SKU图：可用的型号/颜色/容量/套装依据；没有真实关系时不启用
- 详情页：需要解释的决策链、证据和主要风险
- 海报：可成立的主题和场景；没有活动事实时不编造促销
- 产品素材图：白底、透明、无字场景的复用价值与可行性

请选择：
1. 主图  2. SKU图  3. 详情页  4. 海报
5. 产品素材图  6. 全部设计  7. 自定义组合
```

确认时同时写清：对象、分镜数量、平台/位置、用途和目标 SKU 映射。例如：

```text
对象：主图4张 + SKU图2张
目标SKU：红色500ml、蓝色750ml；每张标明对应SKU或“总览”
平台/用途：天猫商品页，解决识别和选型防错
```

这里的“4张、2张”是要交付的分镜数量；提示词完成后说“每张3张”才是每个分镜生成的候选图片数量。用户没有指定对象时，“继续”不会自动等于“全部设计”；用户已经点名对象时只需确认或调整，不重复问相同问题。

## 第六步：图组结构与五个综合方向

多张主图、SKU图、海报或详情页先选图组结构，每个对象单独选择：

1. **递进式主次**：从识别到理解、证明、场景或防错逐步增加信息。
2. **等量并列**：每张都能独立使用，各自解决不同购买问题。
3. **混合结构**：前段递进，后段作为独立 SKU、场景或人群变体。
4. **采用系统首推**。
5. **自定义结构**：说明主链张数、独立变体和顺序。

单张采用单张闭环，白底/透明/无字素材默认按资产角色并列；单张也会在内部比较5个方向，只在方向会改变任务或你要求选择时展示选择卡。多图结构确定后固定推演5个产品专属综合方向：

- 方向1–3：偏转化稳妥、平台适配、价值/品牌。
- 方向4–5：偏视觉差异、情绪场景。

每个方向都写当前商品的主任务、依据、主要画法和风险；方向不是五份报告，也不会自动增加图片数量。交互模式可以选择一个、组合或自定义；“采用推荐/继续”采用系统首推；直出/全自动在内部比较五个方向后采用首推。

没有确认结构和方向前，不开始第1张正式分镜。方向确定后先列出每张的唯一任务、目标 SKU、参考图、信息增量和前后承接，再进入逐张确认。

## 第七步：逐张分镜提示词

交互模式下，每次只展示当前一张完整确认卡，确认或返修后才进入下一张。确认卡至少说明：当前任务、对象和 SKU、参考图职责、商品锁定、允许变化、事实边界、画面、镜头、场景/人物、光影材质、文案安全区、生产后期、正向提示词、动态负面提示词和前后承接。

当前图操作使用 `0–9`：

```text
0 AI首推       1 确认本张并继续   2 定向返修本张
3 返回上一环节 4 补充商品资料     5 调整输出控制
6 调整卖点文案 7 调整视觉与生产   8 调整后续与模式
9 自定义
```

选择 `2` 后可用 `2-1` 到 `2-10` 定位当前任务、卖点证据、文案、美学、场景、镜头构图、商品事实、提示词、画布后期或整张重推。`1` 只确认当前图；只有说“确认本张，剩余自动完成”“1-全部”或“后面直接完成”才切换剩余图片为内部自动复核。直出/全自动只隐藏停顿，不跳过检查。

提示词编译顺序为：

```text
观察 → 草拟 → 结构检查 → 反证 → 最小修复 → 定稿
```

每张分镜只解决一个主要任务，并完整写明参考图职责、商品锁定、允许变化、视角与事实边界、最终画面、镜头构图、场景人物、光影材质、文字安全区、生产与后期、正向提示词和动态负面提示词。商品事实、SKU或参考图改变时，回到商品卡并只重做受影响图；未确认图不能被假装已经完成。

默认使用当前可用的最高推理强度；简单任务只压缩展示，不降低事实、结构和可执行性检查。

只有全部图确认或内部自动复核通过后，才无损聚合最终中文分镜。正式分镜不包含内部评分、置信度数字、子智能体讨论、隐藏思考链、未采用方案、状态或测试文字。

## 第八步：可选生图

正式提示词全部交付且没有待确认分镜后，你可以回复：

- `暂不生图`
- `生成主图-01和主图-03，每张3张`
- `生成当前主图组，每张2张`
- `生成全部图组，每张1张`
- `主图-01生成4张，详情页-03生成2张`

这里的数量是候选图片数量，不是分镜数量；没有明确数量时，每个指定分镜默认生成1张。只有当前环境提供可用生图能力时才执行；工具不可用、参考图不足或透明通道不成立时，保留已经交付的提示词并说明原因。

生图结果出现问题时，只返修最早失败层：商品识别、参考图绑定、图片任务、场景物理、提示词冲突或工具能力。未经要求不会自动重生整组。

## 返修

用稳定编号点名，例如：

```text
返修详情页-03。
保留：商品、SKU、参考图、任务和机位。
修改：手部接触、接触阴影和主体占比。
禁止：不要改容量、品牌原文或其他分镜。
交付：完整重发这一张分镜，暂不生图。
```

局部返修保留原页码和编号，只重算受影响字段；共享商品事实改变时才检查相邻分镜。

## 自我学习

当前任务中明确的选择、否定、纠正和有效返修会帮助后续分镜更贴近你的思路。跨任务长期保存必须由你明确授权；没有可用的私有记忆能力时只在本轮生效，不写入仓库。

学习不会改变商品事实、合规边界、隐藏视图置信度门槛或本轮明确要求。候选数量、工具故障和未评价结果不会被当成偏好。

## 常见问题

### 只有正面图，可以做背面吗？

可以先对背面单独评分。只有91–100分才允许以“高置信推定/示意”进入写实分镜；低于或等于90分改用补拍、合成、三维资料或概念稿，并在事实边界中说明。

### 没有卖点和参数怎么办？

AI会先列候选卖点和需要补充的准确字段，让你数字选择或手动输入。未确认的内容不会进入商品卡事实区、文案或提示词。

### 商品卡什么时候算确认？

数字选择或纠正后先得到“商品卡（待确认）”。只有你回复“确认商品卡”（或明确授权“全部采用AI推荐并直接确认”，且系统先形成待确认卡并通过冲突检查）后，才进入设计需求预判和输出范围；在此之前不会编写正式分镜。

### 可以直接出稿吗？

可以说“全部采用AI推荐并直接确认”。技能仍会先生成并记录商品卡（待确认），完成冲突检查后把这句话视为确认，再完成后续范围、结构、方向和逐图复核；外部只展示必要确认和最终分镜。

### 能不能只要提示词，不要报告？

可以。商品卡和建议只用于确认；最终交付只保留逐张中文图生图分镜提示词。

### 能不能生图？

可以在提示词完整交付后选择是否生图、生成哪些分镜和每张数量。默认不自动生图。

### 多张图为什么还要选结构和方向？

结构决定图片之间是递进、并列还是混合；方向决定这组图优先解决转化、选型、证据、视觉差异还是情绪场景。结构确认后固定给出5个产品专属方向，选择后才开始逐张编排，避免多张图只换背景。

### 我只确认当前图，什么时候会到下一张？

交互模式下，当前图确认或返修完成后才进入下一张。回复“确认本张，剩余自动完成”后，后续图仍会经过内部复核，但不再逐张停下来询问。

### 分镜数量和生图数量有什么区别？

范围确认里的“主图4张”表示交付4个不同任务的分镜；提示词交付后的“每张3张”表示每个分镜生成3个候选图片，两者不会混用。
