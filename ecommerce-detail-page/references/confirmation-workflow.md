# 需求确认、结构选择与逐图推进

本文件只负责商品卡确认后的用户交互。它把“真正做什么、怎样组织多张图、采用哪种方向、每张何时确认”说清楚；不负责商品识别细节、提示词字段写法或最终 Markdown 格式。

## 唯一顺序

```text
商品卡确认
→ 设计需求预判卡
→ 输出范围确认
→ 多图结构选择
→ 固定五个综合方向
→ 图组编排与逐张任务
→ 逐图确认或内部自动复核
→ 聚合正式分镜提示词
→ 可选生图
```

商品卡前不确认正式输出范围；商品卡确认后才展示需求预判。范围、结构和方向没有确定前，不编写第1张正式分镜。正式提示词全部交付后，才显示生图选项。

## 一、设计需求预判卡

只读取已经确认的商品卡，结合商品形态、买家任务、现有素材和用户原始意向，按信息缺口选择最短确认方式。它不是最终方案，也不替用户扩大范围：

1. **完整意向**：对象、数量、平台/位置、用途和目标SKU/版本都已明确且无冲突，原意向本身即完成范围确认；把一行范围摘要与结构首推放在同一轮，摘要只作透明记录，不等待再次回复，也不展示全对象菜单。
2. **部分意向**：只缺一两项时，保留已捕捉内容，只询问会实质改变图片任务的缺口。
3. **意向不清或主动探索**：才展示下面完整但紧凑的“设计需求预判卡”。

```text
【设计需求预判卡】
- 已确认商品：品类、商品关系、核心视觉锚点
- 已捕捉意向：用户已经点名的对象、数量、平台或用途；没有就删除本行
- 买家任务：识别、理解、选择、证明、使用和防错中当前最重要的任务
- 主图：适用条件、已有依据、能解决的问题和主要风险
- SKU图：可用的型号/颜色/容量/套装依据；没有真实 SKU 关系时注明暂不启用
- 详情页：需要解释的决策链、证据和主要风险
- 海报：可成立的主题、场景和传播边界；没有活动事实时不编造促销
- 产品素材图：白底、透明、无字场景的复用价值与可行性
- 组合关系：各对象共享什么，哪些内容不能重复，哪些对象缺素材

请选择实际输出对象、分镜数量、平台和用途：
1. 主图
2. SKU图
3. 详情页
4. 海报
5. 产品素材图（白底/透明/无字场景）
6. 全部设计（逐组确认数量）
7. 自定义组合（对象 + 分镜数量 + 平台/用途）
```

规则：

- 用户原话已经点名对象时，在对应项标记“已捕捉意向”，仍允许增减、合并或改数量；不重复追问同一句话。
- 预判对象服从商品形态：数字权益或服务只有真实复用价值时才出现白底/透明等资产；其SKU映射解释为权益档位、服务版本、时长、地区或账号类型，不强套实体颜色/容量。
- 用户回复“继续”时：若原始意向已明确但仍有一个待确认缺口，确认该缺口并推进；若完整意向已经无冲突，不需要再用“继续”完成范围确认；若没有明确对象，只能请用户选择，不能把“继续”解释成“全部设计”。
- 每个对象都记录“分镜数量”。“每张生成几张”属于提示词交付后的生图候选数量，不在这里混用。
- 多 SKU 不把多个款式压成一个名称：商品卡保留 SKU 清单、各SKU综合有效参考内容、差异和状态；范围卡可写“每个 SKU 2 张”或“总览 1 张 + 主推 SKU 各 1 张”。
- 当用户同时指定多个输出对象，却只说“每个 SKU 各 N 张”时，先问一个最小澄清：N 是每个对象各 N 张，还是所有对象合计 N 张；未澄清前不分配分镜数量。
- “全部设计”也要逐组确认对象和数量；没有依据的对象保留为未启用，不静默开全套。

## 二、输出范围确认

把用户选择整理成一行可核对的范围摘要，至少包含：

```text
对象：主图4张 + SKU图2张
目标 SKU：红色500ml、蓝色750ml（分别综合对应SKU/状态的有效参考内容）
平台/位置：天猫商品页首屏与规格区
用途：识别、选型防错
分镜数量：主图4张、SKU图2张
```

对象、数量、平台、用途或 SKU 映射存在缺口、冲突或多种解释，并且会改变图片任务时，才让用户确认一次。用户已经给出完整且无冲突的内容时，原意向本身就是确认；用“已按原意向记录范围”一句话留痕，并在同一轮直接进入结构首推，不等待回复、不重复问卷。范围确认后，未选对象和未采用卖点不进入后续分镜。

平台精确尺寸、裁切、禁限内容或促销规则只有在用户资料或任务当时可核验的当前官方来源支持时才写死。无法核验“最新规则”时，范围卡只记录平台、位置和需保留的安全适配空间，不凭记忆补造像素或政策结论。

## 三、多图结构选择

只有多张主图、SKU图、海报或详情页需要确定结构；单张采用“单张闭环”，白底/透明/无字素材默认按资产角色并列。每个输出对象独立判断，不把主图结构自动套给其他对象。用户已经明确“逐步讲清”“每张独立投放”或主链/变体关系时直接采用；一个结构明显占优时给出一句首推及影响，用户回复“继续”即可确认。只有多个结构会显著改变任务或顺序时才展示完整菜单。

```text
【图组结构选择｜主图4张】
- 系统首推：递进式主次
- 推荐理由：前张建立识别，后张依次补充利益与证据
- 对后续影响：每张必须新增一个购买理由，不能只换背景

1. 递进式主次：从识别到理解、证明、场景或防错逐步增加信息
2. 等量并列：每张都能独立使用，各自解决不同购买问题
3. 混合结构：前段递进，后段做独立 SKU/场景/人群变体
4. 采用系统首推
5. 自定义：说明主链张数、独立变体和顺序
```

用户说“递进式、每张逐步讲”即选1；说“每张都是独立主图/独立投放”即选2；说“前几张讲清楚，后几张做变体”即选3。说“继续、你来选、采用推荐”时选4，但要告诉用户采用了哪种结构及其一句影响。结构菜单只对当前阶段有效，进入下一阶段后旧数字失效。

## 四、固定五个综合方向

结构确定后，固定推演五个产品专属综合方向，不用临时改成一、三或十个方向。单张没有结构菜单时，也在内部比较这五个方向；只有方向会改变画面任务、用户明确要求选择，或存在真实歧义时才把选择卡展示给用户：

1. 稳妥转化：首屏识别与核心利益
2. 稳妥适配：平台阅读与选型防错
3. 稳妥价值：结构证据、信任与品牌感
4. 视觉差异：商品独有的材质、形态或场景记忆点
5. 情绪场景：真实使用情境与代入感

每个方向都必须针对当前商品写清主任务、依据、主要画法和风险；前3个偏转化、平台适配、价值/品牌，后2个偏视觉差异、情绪场景。方向不是五份报告，也不自动增加分镜数量。

```text
【综合方向选择｜主图4张】
1. [方向名]：解决什么购买问题；依据是什么
2. [方向名]：解决什么购买问题；依据是什么
3. [方向名]：解决什么购买问题；依据是什么
4. [方向名]：视觉记忆点和适用场景
5. [方向名]：情绪场景和适用场景

请选择：1–5；可回复“以1为主，采用4的场景”；也可直接说明自定义方向。
```

五个方向始终在内部完成比较，但“交互模式”不等于必须额外展示一轮菜单。只有两个以上方向会实质改变本组主任务、场景或生产方式，或用户明确要求看方向时，才等待用户选择、组合或自定义；一个方向明显占优、用户原话已充分指定，或回复“采用推荐/继续”时直接记录采用结论并用一句摘要推进。全自动、直出时内部采用首推，不展示无用发散。没有方向采用结论，不进入第1张正式分镜；有结论但无真实差异时，不为凑足五种画面而增加分镜。

## 五、图组编排与数量约束

方向确定后，先列紧凑图组清单，再逐张推演：

| 分镜 | 输出对象/目标 SKU | 唯一任务 | 参考图使用方式 | 新增信息 | 与前后图关系 |
|---|---|---|---|---|---|
| 01 | 主图/总览 | 首屏识别 | 综合目标SKU的有效参考内容 | 商品是什么 | 引出下一张 |

每张只保留一个主任务；递进结构必须新增信息，等量并列必须独立成立，混合结构明确主链和变体。用户指定数量超过可成立任务数时，先分配真实不同职责；仍不足时让用户在减少分镜数量、补充素材或明确标注视觉变体之间选择，不得靠换背景凑数。

每张必须绑定目标 SKU 或“总览”，并在多 SKU 任务中保持颜色、型号、容量、套装和配件不串款。这里的数量是要交付的分镜张数，不是生图候选张数。

## 六、逐图确认

交互模式下，每次只展示当前一张的完整确认卡。卡片顶部显示`第N/总数张｜对象-编号｜待确认`，确认后用一句“已确认第N张，下面进入第N+1张”建立清楚进度；至少包括：

- 当前分镜编号、对象、目标 SKU、组内角色和唯一成图任务；
- 参考图使用方式、商品锁定、允许变化、事实边界和视图限制；
- 画面、镜头构图、场景/人物、光影材质、文案安全区、生产与后期；
- 正向提示词、动态负面提示词、与前后图的承接和自检结论。

当前图没有被用户确认或返修完成前，不生成下一张的正式分镜。用户确认后才进入下一张；全部图确认后才把已确认内容无损聚合成最终分镜。最终聚合不重新发明卖点、画面或商品事实。

### 当前图的 0–9 操作

数字只绑定当前可见的单图菜单，下一张出现后旧数字失效；卡片明确提示“本卡数字只对当前分镜有效”。简单、低风险且没有返修历史时默认只显示`0 AI首推 / 1 确认本张并继续 / 2 定向返修本张`；用户要求更多控制、出现复杂风险或选择`2`时，再展开完整操作与局部返修项：

0. AI首推：先做一次当前图自检；无硬伤则确认本张并继续，有硬伤则最小修复后重发本张等待确认
1. 确认本张并继续
2. 定向返修本张
3. 返回上一环节或检查组内承接
4. 补充/修正商品资料
5. 调整输出对象、数量、顺序或结构
6. 调整卖点、证据、文案或购买任务
7. 调整场景、人物、镜头、构图、光影或生产方式
8. 预览下一张、调整剩余任务或切换自动模式
9. 自定义保留、删除、替换或重做

`1`只确认当前图，不代表确认整组。当前唯一对象就是这张分镜且没有歧义时，“这张可以”“通过”“下一张”“按这个继续”等自然中文与“确认本张并继续”等价。只有“确认本张，剩余自动完成”“1-全部”或明确的“后面直接完成”才切换剩余图片为内部自动复核。直出/全自动只隐藏停顿，不跳过同样的商品、结构、事实、连续性和提示词检查。

### 当前图的局部返修 2-1 至 2-10

选择 `2` 后可直接点名以下范围，也可用自然语言描述：

1. `2-1` 当前任务、页面角色或前后承接
2. `2-2` 卖点、价值主张、证据路径
3. `2-3` 标题、副标题或核心卖点文案
4. `2-4` 美学、色彩、字体、光影或组件风格
5. `2-5` 图型、场景、道具、人物或商品处理方式
6. `2-6` 视角、镜头、主体占比、构图或安全区
7. `2-7` 商品主体、参数、适配、品牌原文或事实边界
8. `2-8` 正向/负面提示词或生成方式
9. `2-9` 画布、素材槽位或后期排版
10. `2-10` 保留组级不变量，整张重新推演

涉及商品主体、SKU、参数、适配或品牌原文时，先回到商品卡纠正并重新确认；不能在单图返修里偷偷改商品事实。返修后完整重发当前确认卡，用户再次确认后才继续。

## 七、暂停、恢复与整组完成

用户说“暂停”时保留当前图、已确认图、剩余任务和推进方式；恢复时从当前待确认卡继续，不从第1张重跑。共享商品事实、SKU或参考图变化时，标出受影响的已确认图并重新确认；不受影响的图保持不变。

最后一张确认后检查数量、编号、结构、语义去重、商品一致性、连续性、画布和提示词可执行性。只有全部图都确认（或在全自动模式通过内部复核）后，才输出正式分镜；若仍有待确认图，不得声称整组已完成。

## 八、与生图的边界

正式分镜提示词交付后，只有用户尚未说明是否生图时才显示：暂不生图、指定分镜、当前图组、全部图组和每张候选数量。用户已经说“暂不生图”时直接结束，不重复菜单。生图只接收已确认的分镜；“每张 N 张”此时指候选图片数量，不改变分镜数量。分镜或商品事实返修后，先重新确认受影响分镜，再生图；工具不可用时保留提示词并说明原因。
