# 购买路径与销售表达系统

本文件只负责购买决策路径和销售表达模型。不写消费者心理细分、转化框架库或最终分镜模板。

## 购买决策路径

按产品选择1个主路径，必要时叠加1个辅助路径。输出给用户时解释中文含义，不堆英文术语。

| 模型 | 中文路径 | 适配场景 | 页面落地 |
|---|---|---|---|
| AIDA | 注意、兴趣、欲望、行动 | 大多数主图、海报、短详情页 | 先截停，再卖点，再证据，再行动 |
| AIDMA | 注意、兴趣、欲望、记忆、行动 | 货架电商、品牌心智弱但可反复触达 | 强化记忆锤、视觉符号和复看理由 |
| AISAS | 注意、兴趣、搜索、行动、分享 | 小红书、抖音、种草型产品 | 前置种草理由，补搜索证据和分享感 |
| ACCA | 认知、理解、确信、行动 | 新品类、新功能、复杂产品 | 先讲是什么，再讲为什么可信 |
| DAGMAR | 知晓、理解、确信、行动 | 高客单、强理性、耐用品 | 分层解释参数、证据和决策理由 |
| STP | 人群细分、目标选择、定位表达 | 人群差异明显的产品 | 明确卖给谁、为什么是它、怎么说 |
| 5A | 认知、吸引、询问、行动、拥护 | 私域、复购、会员型商品 | 加入咨询入口、复购理由和口碑扩散 |
| RACE | 触达、互动、转化、留存 | 站外投放、内容流、私域闭环 | 先做触达钩子，再设计互动和复购承接 |
| See-Think-Do-Care | 看见、考虑、行动、关怀 | 多阶段内容矩阵和全案设计 | 将主图、海报、详情页和复购素材分工 |
| CDJ | 初始考虑、主动评估、购买、体验、复购 | 高客单、耐用品、家电家居、服务型商品 | 加强对比、评价、售后、安装维护和复购 |
| 消费者采用路径 | 知晓、兴趣、评估、试用、采用 | 新品类、新技术、新生活方式商品 | 用教育页和场景页降低理解门槛 |
| PASTOR | 痛点、放大、故事、转化、报价、回应 | 痛点强、服务型或解决方案型产品 | 先共情，再证明，再回应顾虑 |
| PAS | 痛点、放大、解决 | 低客单快决策、主图和海报 | 一张图讲清问题和解法 |
| BAB | 之前、之后、桥梁 | 美妆、清洁、家居改善、效率工具 | 先展示理想结果，再让产品成为桥梁 |
| QUEST | 识别、理解、教育、刺激、转化 | 需要教育的新产品或复杂功能 | 先确认目标人群，再逐步教育和促动 |

## 销售表达模型

| 模型 | 用法 | 落地要求 |
|---|---|---|
| FABE | 特征、优势、利益、证据 | 把功能翻译成买家好处，并仅使用有准确依据的证据；无证据时降级为FAB |
| FAB | 特征、优势、利益 | 适合主图或海报短表达，证据不足时不强行背书 |
| USP | 独特销售主张 | 只抓一个最不同的点，避免每屏都想说全部 |
| SPIN | 现状、问题、影响、需求回报 | 适合详情页痛点段，不能制造不实焦虑 |
| EPP | 情绪、痛点、承诺 | 适合低门槛种草和轻促销，承诺必须可证实 |
| 4U | 有用、紧迫、独特、具体 | 用于标题、主图短文案和行动钩子 |
| 4C文案 | 清楚、简洁、可信、有吸引力 | 用于控制图内文案密度和可信度 |
| 3C定位 | 顾客、竞争、公司能力 | 用于判断卖点是否真实、差异是否能支撑 |
| 4P | 产品、价格、渠道、促销 | 用于运营视角检查信息是否完整 |
| 4C | 顾客、成本、便利、沟通 | 用于从买家角度重写页面 |
| 7P | 产品、价格、渠道、促销、人员、流程、有形展示 | 服务、定制、安装、咨询和本地生活类商品 |
| PEST | 政策、经济、社会、技术 | 只用于行业背景判断，不写入图内文案 |
| SWOT | 优势、劣势、机会、威胁 | 用于品牌或商品策略诊断，不把劣势包装成事实 |
| MECE | 相互独立、完全穷尽 | 用于卖点分组，避免重复卖点和信息打架 |
| 金字塔原则 | 先结论后理由 | 每屏先给结论，再给证据或画面解释 |
| JTBD | 买家雇佣产品完成什么任务 | 用于把功能转成真实使用任务 |
| Kano | 基础、期望、兴奋、无差异、反向需求 | 用于卖点排序，避免把基础功能当最大卖点 |
| 价值主张画布 | 用户任务、痛点、收益与产品价值匹配 | 用于定义核心价值主张和页面主线 |

## AI模型选择器

按以下顺序自动选模型，不向用户展示完整表格，只输出首推模型和理由：

1. 输出对象：主图优先AIDA/PAS/4U；SKU图优先MECE/Kano/4C；海报优先AIDA/AISAS/RACE；详情页优先ACCA/DAGMAR/CDJ/FABE/SPIN；素材图不默认使用完整营销模型。
2. 决策复杂度：低复杂度用PAS、FAB、4U；中复杂度用AIDA、FABE、USP；高复杂度用ACCA、DAGMAR、CDJ、SPIN。
3. 客单价：低客单强调快懂快买；中客单强调证明和对比；高客单强调信任、长期价值、风险兜底。
4. 平台心智：货架平台偏AIDMA/DAGMAR/USP；内容平台偏AISAS/RACE/BAB；私域偏5A/See-Think-Do-Care。
5. 类目属性：标品偏参数、USP和价值解释；非标品偏场景、审美、情绪和身份表达；安全敏感类偏信任和合规证据。
6. 证据强度：证据充分可用FABE、DAGMAR、合规信任；证据不足只用FAB、PAS、场景表达，不强行背书。

## 模型阶段演练

AI必须根据产品主动选择路径，并把每个阶段构设成“用户心理、页面任务、画面表达、证据要求”。对用户输出的是演练后的推荐和可修改位置。

| 路径 | 阶段性质 | 构设方式 |
|---|---|---|
| AIDA | 注意：让用户停住；兴趣：让用户觉得相关；欲望：让用户想拥有；行动：让用户知道下一步 | 主图/海报先做视觉钩子，详情页前段承接利益和证据，尾部给行动入口 |
| AISAS | 注意：被内容吸引；兴趣：产生收藏/搜索欲；搜索：主动验证；行动：下单；分享：愿意传播 | 内容平台先构设生活场景和搜索关键词，再补真实证据和分享理由 |
| ACCA | 认知：知道新品类；理解：看懂原理或差异；确信：相信值得买；行动：降低决策阻力 | 新品类或复杂产品先教育，再用剖面、对比、实测和FAQ建立确信 |
| DAGMAR | 知晓：知道存在；理解：知道价值；确信：相信证据；行动：完成购买 | 高客单或耐用品按参数、证据、场景、售后逐步推进 |
| CDJ | 初始考虑：进入候选；主动评估：比较和查证；购买：选择并下单；体验：使用后满意；复购：再次购买或推荐 | 家电、家居、服务类要补对比、安装、售后、维护和长期价值 |
| 5A | 认知：知道品牌/产品；吸引：愿意了解；询问：想咨询/搜索；行动：购买；拥护：评价和推荐 | 私域、会员、复购品要构设咨询入口、会员权益和口碑扩散 |
| FABE | 特征：产品是什么；优势：比旧方案好在哪；利益：用户得到什么；证据：凭什么相信 | 每个卖点页先写用户利益，再给有准确依据的功能、实测、结构或证据；证据不足时删除证据层并降级表达 |
| SPIN | 现状：用户当前场景；问题：有什么麻烦；影响：继续不解决的后果；需求回报：解决后的收益 | 痛点页只做真实问题递进，不制造不实恐慌 |
| JTBD | 用户任务：买来完成什么；旧方案：替代什么；成功标准：怎样才算买对 | 产品定位和页面主线必须围绕买家任务，不围绕厂商自嗨功能 |
| Kano | 基础：必须有；期望：越好越满意；兴奋：超预期记忆点；反向：会劝退 | 卖点排序时基础项做说明，兴奋项做视觉锤，反向项做排雷 |

输出给用户的推荐中，可写“推演依据：AIDA，含义是注意-兴趣-欲望-行动”，但必须同时给出具体页面构设和选择理由。

## 模型组合原则

- 路径模型决定页面顺序。
- 销售模型决定单张图怎么说。
- 心理模型决定为什么用户会信、会怕、会买。
- 业务模型决定卖点、价格、渠道、促销和服务是否闭环。
- 最终每张图只写1个主模型或主框架，复杂理论只留在内部推演。

## 输出接口

- 主购买路径：1个。
- 辅助购买路径：可选1个。
- 销售表达组合：2到4个。
- 业务判断模型：可选1到2个。
- 页面落点：首屏、卖点页、场景页、证据页、价格页或尾屏。
- 风险：是否需要事实证明、是否可能过度承诺。
