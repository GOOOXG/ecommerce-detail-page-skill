# 画布系统

本文件是画布比例/尺寸候选、像素折算、组级画布约束、用户确认和最终写入的唯一来源。不定义分镜槽位合同中的产品锚点、占比、裁切或安全区。

## 核心区分

- 产品比例属于产品资产，必须保持不变。
- 画布比例/尺寸属于输出载体，可按素材组独立设置。
- 用户未指定或未确认画布比例/尺寸时，允许给推荐，但最终分镜只删除比例/尺寸子项，仍保留`画布与槽位`的强制布局信息。
- 用户明确说“不写、不限制、后期再定”时，记录为不写比例/尺寸，不得删除分镜槽位合同。

## 常用候选

| 输出对象 | 常用候选 | AI推荐依据 |
|---|---|---|
| 主图 | `1:1`、`3:4`、`9:16` | 货架搜索优先1:1；内容流优先3:4；直播/竖屏沉浸可选9:16 |
| SKU图 | `1:1` | 便于统一角度、规格标签和对比 |
| 海报 | `9:16` | 适合移动内容流、直播间和私域转发；横版投放位可自定义 |
| 产品素材图 | 白底/透明常用1:1；无字场景按用途选择 | 优先复用、抠图和后期合成 |
| 详情页 | 通常不限制；可推荐宽1024或2048、高度不限 | 每张已是独立分镜，不写“长图切片” |

所有对象都支持自定义比例、像素或平台规范。推荐不是确认，未经用户指定/确认不得写入最终分镜。

## 像素折算

主图、SKU图、海报和产品素材图收到像素时，先约分或识别常规比例：

- 正方形像素，如800×800、1024×1024，写 `画布比例：1:1`。
- 接近3:4的像素，如900×1200，写 `画布比例：3:4`。
- 接近9:16的像素，如1080×1920，写 `画布比例：9:16`。
- 非常规尺寸或用户要求保留像素时，写 `画布尺寸：[原尺寸]`。
- 详情页不强制折算为比例；用户指定宽度时写 `画布尺寸：[宽度，高度要求]`。

不得把明显不同的像素比例强行归入常规比例。

## 组级画布约束

- 主图、SKU图、海报分别记录已确认比例/尺寸；同一组第1张到最后一张重复写入该值。
- 产品素材图可按白底、透明、无字场景分别确认，也可由用户指定统一值。
- 详情页只有用户确认后才逐张写入尺寸；默认不写。
- 只指定某一组时，不自动套给其他组，也不因其他组未指定而阻塞当前组。
- 用户主动要求跨组统一时才复用同一比例。

## 交互规则

- 半自动：只展示当前被点名对象的常用候选、AI首推和自定义入口。
- 全自动：可在源码块外给AI首推；未得到确认时不写入分镜。
- 直出/通版：用户未指定时直接省略比例/尺寸子项，不因画布追问阻塞交付。
- 用户输入自定义但没有具体值时，只追问具体比例或尺寸。

需要用户选择时，使用当前对象专属画布卡，不把所有对象的比例混在一起：

```text
【画布选择｜[输出对象]】
- AI首推：[比例/尺寸/不写]
- 推荐理由：[平台、用途、产品形态和信息密度依据]
1. 采用AI首推
2. [当前对象常用候选1及用途]
3. [当前对象常用候选2；没有第二候选时改为“不写画布”]
4. 不写比例/尺寸：最终分镜保留槽位，只省略比例/尺寸子项
5. 自定义：输入比例、像素尺寸或平台要求
```

主图可把`1:1`、`3:4`、`9:16`作为具体候选，并将“不写”和“自定义”顺延；SKU图、海报和详情页只展示真实常用项，不为凑满数量制造无意义选项。综合方案卡已包含画面方向，但不替用户确认画布；用户未选择时按运行模式省略，不阻塞设计。

## 最终写入

- 已确认常规比例：该素材组每张写 `- 画布比例：[比例]`。
- 已确认非常规尺寸：该素材组每张写 `- 画布尺寸：[尺寸]`。
- 已确认详情页尺寸：每张详情页写 `- 画布尺寸：[要求]`。
- 未指定/不写：只删除该组的画布比例/尺寸子项。
- 图生图提示词不重复画布信息，避免同一约束出现两次。
- 平台推荐但未确认：只放源码块外，不进入分镜。
- 无论比例/尺寸是否存在，最终分镜都必须保留`画布与槽位`中的产品锚点、占比、完整性、裁切边界，以及实际启用的文案/品牌/证据安全区。
