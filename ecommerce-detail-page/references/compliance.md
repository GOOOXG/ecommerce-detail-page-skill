# 合规系统

本文件只负责合规、事实边界和负面提示词。

## 禁止

不得编造功效、认证、检测报告、销量、评价、价格、促销、赠品、售后、专利、专家证言、平台背书。不得使用广告法高风险词、医疗化暗示、虚假前后对比、危险动作或无法证实的紧迫感。

## 活动与权益事实边界

主图、海报和详情页如果涉及价格、优惠券、赠品、限时、前N名、榜单、会员权益、质保、退换、安装服务，必须来自用户提供或图片可见事实。没有依据时：

- 价格和优惠：自动跳过价格组件；可改成不依赖价格的价值解释。
- 赠品和会员：自动跳过权益组件；可改成不含承诺的开箱氛围。
- 榜单和销量：自动跳过数据背书；改用已确认结构、场景或卖点证明。
- 售后和质保：自动跳过售后承诺，不保留政策占位。
- 限时和稀缺：没有真实活动依据时不得写倒计时、仅剩、错过涨价等强逼单表达。

## 缺失字段处理

没有准确值的功效、参数、证书、销量、售后、适配、价格和活动字段不得进入商品事实、分镜和消费者表达。商品卡可以把其中高价值且可核实的字段列为一次性可选补充建议；用户不补充即自动跳过，不写待确认、不留参数位、不重复索取。只有缺失信息会导致商品主体、安全或合规无法成立时，才暂停并询问一个关键问题。

图内无法证明的强主张应删除，或换用已确认结构、真实场景和边界表达。用户后续补充准确字段时，重新确认后再恢复对应组件。

## 高风险品类

食品、滋补、保健、母婴、宠物、运动健康、医疗健康边界、家电安全、数码充电、工业工具必须更严格。普通食品不得暗示治疗、改善身体机能、助眠、降糖、减肥、美容等。

## 全行业风险路由

| 风险类型 | 重点检查 | 处理 |
|---|---|---|
| 医疗、保健、美妆功效 | 治疗、预防、修复、无刺激、适用所有人等确定性主张 | 只使用获准且有依据的表述；普通商品不得医疗化 |
| 食品、滋补、母婴、宠物 | 成分、年龄、喂养、过敏、安全、产地、保质期 | 参数和边界必须来自真实资料，危险动作禁止生成 |
| 家电、数码、汽车、工业 | 功率、能效、防护、兼容、承重、工况、安全测试 | 不从外观推导性能，不伪造测试、认证和适配 |
| 教育、服务、金融相关 | 提分、就业、收益、回报、案例结果、退款 | 不承诺结果或收益，服务范围和权益必须可核实 |
| 环保、ESG、非遗、产地 | 可降解、零残忍、低碳、认证、非遗传承、原产地 | 必须有材料、认证、授权或溯源依据 |
| UGC、专家、榜单、盲测 | 用户评价、达人、专家身份、排名、测试过程 | 必须真实授权且可追溯；AI生成内容不得冒充真实证据 |
| 肖像、商标、IP和版权 | 模特、名人、竞品标志、角色形象、字体、图片 | 使用已授权资产或通用形象；不模仿受保护品牌元素 |
| 价格和促销 | 原价、到手价、限时、补贴、赠品、稀缺、库存 | 只使用当前真实机制，并提醒按目标平台最新规则复核 |
| 本地履约和企业采购 | 配送时效、服务区域、门店、起订量、交期、产能、客户案例 | 必须来自真实经营资料，不用场景合成冒充履约或生产证据 |

平台规则会变化。用户要求最新平台规范、价格规则或高风险行业审核时，读取可靠的当前来源；无法核实时以更保守表达和人工复核为准。

## 画面真实性

- 结构拆解、显微、透视、前后对比和实验画面必须标明是可验证展示、示意图还是概念预览。
- 不生成伪检测报告、伪证书、伪截图、伪用户评价、伪专家、伪门店或伪媒体报道。
- 场景合成不得制造产品实际不存在的配件、功能、安装方式、容量、尺度或使用结果。
- 涉及人物时检查肢体、年龄、危险动作、产品接触方式和适用人群，避免产生安全误导。

## 负面提示词组成

负面提示词必须包含：产品变形、改色、改包装、品牌标志错误、虚假文字、乱码、虚假认证、虚假促销、医疗化暗示、伪证据、侵权元素、过度夸张、主体过小、文字过多、低清晰度。有人物时补充肢体错误和危险动作；按行业继续补充风险项。

## 人工复核提醒

涉及资质、功效、检测、价格、促销、售后、食品、保健、母婴、医疗健康边界时，在源码块外提醒用户以真实资料和平台审核为准。
