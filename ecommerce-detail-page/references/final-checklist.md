# 最终放行检查

本文件只负责最终放行，不生成新方案、新文案或新视觉。失败项必须返回对应规则拥有者修正，再重新检查。

## 目录

`使用时机` / `调度与状态` / `商品与事实` / `内容与转化` / `视觉与生产` / `正式成品` / `格式` / `生图闸门边界` / `Q0-Q3 发布严重度` / `失败回退`

## 使用时机

- 最终分镜输出前。
- 局部返修或整组重发前。
- 用户要求测试、校验或完整性审查时。

## 调度与状态

- 当前任务/商品/参考图/范围/结构/方向合同分别存在实际`TC/PC/RC/SC/ST/DC-nnn`版本，状态均为`RELEASED`；任何缺失、`PENDING`、`INVALIDATED`或`BLOCKED`版本都阻塞最终交付。
- 当前交付范围的每张图都有已`RELEASED`的`FS-nnn`分镜槽位，其`parent_versions`逐项等于当前上游版本；不存在把旧工作包父版本原地替换为新版本的情况。
- 每张`FR-nnn`与`PR-nnn`状态均为`RELEASED`，两者的`release_pair`相互一致并来自同一次原子提交；FR与PR的`parent_versions`都精确绑定当前任务/商品/参考图/范围/结构/方向/分镜槽位，且提示词不依赖未发布分镜。
- 每对 FR/PR 的`source_artifact_id`必须相同并解析到实际不可变分镜草案；该草案未`STALE`，其`input_contract_versions`包含当前 FS，且逐项等于发布库中当前任务/商品/参考图/范围/结构/方向/分镜槽位版本。禁止用旧草案内容包装成伪当前 FR/PR 信封。
- 所有用于当前成品的合同、分镜草案产物和工作包都逐项校验`parent_versions/input_contract_versions`；任一父版本不是发布库中的当前版本时，先将受影响项标为`INVALIDATED/STALE`并回到负责模块重算。
- 只加载被点名对象的专属模块；多对象按组隔离，不把主图、SKU图、海报、素材图和详情页混入同一源码块。
- 新事实、新型号或商品纠正已经回到商品文档确认，并只重算受影响下游。

## 商品与事实

- 每组分镜均有编号到原始附件的稳定参考图索引；每张均有身份母图与视角/几何主参考图，辅参考图只列实际使用图片、能力轴和具体用途。
- 商品视觉DNA已经展开到轮廓、比例、结构、部件、颜色、可见材质表面、LOGO/原文、包装与配件，不只写“保持一致”。
- 产品锁定、允许变化、视角能力、未知面和事实边界互不冲突。
- 产品外观、比例、结构、颜色、材质、包装、配件、品牌标志和可见原文保持一致。
- 英文品牌、型号和包装原文保持原样。
- 每条卖点、参数、适配、功效、证据、价格、活动、售后和认证均有准确来源，表达没有超出来源可证明范围。
- 推断只用于人群、场景、风格、构图和顺序，没有升级为产品事实或消费者卖点。
- 自动跳过、冲突和禁用字段已经从文案、组件、画面、提示词和占位中删除。
- 参考图未展示的背面、内部结构、配件和安装关系没有被当作真实商品补画。

## 内容与转化

- 分镜任务解读已把平台/对象、买家决策、商品事实/证据、参考能力和主视觉语法收敛为单一任务读法；没有直接套用通用品类模板。
- 推演旋钮已映射到实际分镜字段，数值、评分和内部配置没有进入最终分镜。
- 每张只解决一个购买问题，并提供新的事实、利益、证据、场景或顾虑解法。
- 递进式逐张增加信息；等量并列每张独立成立；混合结构的主链和独立变体不重复命题。
- 主标题、副标题和核心卖点职责不同，跨页没有机械重复或近义改写。
- 文案简洁、自然、移动端可读，没有模型术语、后台话术、空泛大词和无依据承诺。
- 主图保证小图识别和点击理由；SKU图避免选错；海报主题单一且活动真实；详情页连续解释并降低退货；素材图保持复用价值。

## 视觉与生产

- 提示词清楚区分锁定层、重建层和生成层，并说明图像模型与后期分别负责什么。
- P0-P4只作摘要；每张所需身份、几何、材质、颜色、文字、包装配件、交互尺度、证据、新外部视角、内部拆解、材质贴图和动态状态能力轴全部通过。资料不足时没有生成未知背面、内部、配件或真实结构。
- 每张只有一个主风格、一个核心主体、一个主空间、最多一个主转化组件和一个可执行生产形式。
- 图组只使用一套主视觉语法；已排除无依据渐变/黑金/米黄套壳、万能圆台、粒子水花、随机人物、伪实验室、重复居中构图和伪剖面。任何上下文覆盖均有品牌、任务、证据与生产依据。
- 构图、人物、道具、光影、材质和尺度关系真实，产品不被装饰或文字遮挡。
- 生产方式与现有素材能力匹配；多角度照片不等于准确3D几何，也不证明内部。没有对应3D/CAD/摄影测量或结构资料时不生成未知角度、拆解或内部商用图。
- 同组产品、品牌、色彩、光源、字体、组件和修图质感连续；独立变体仍保持正式投放完整性。
- 每张均绑定已`RELEASED`的分镜槽位合同并写`画布与槽位`；未知比例/尺寸子项已删除，产品锚点、占比、裁切边界和实际启用的文案/品牌/证据安全区互不冲突，图生图提示词不重复画布数值。

## 正式成品

- 正式分镜包含参考图索引、基于已`RELEASED`分镜槽位合同的画布与槽位、身份母图、主/辅参考图、产品锁定、允许变化、视角与事实边界、生产与后期、图生图提示词和动态负面提示词。
- 除必要的一句执行阻塞说明外，正式交付没有独立商品分析、商业/运营/营销建议、多智能体报告、评分或A/B测试方案；所有专业视角均已转译为逐图任务与提示词约束。
- 最终源码块只包含 `storyboard-template.md` 定义的生产字段，不包含方案比较、模型名、测试标签、评分、评估、建议、候选、假设、确认状态、审核结论或返修说明。
- 画面文字严格服从白名单：产品原有可见原文和本张最终上图文案。字段名、状态、策略、评分、评语、说明和内部指令不得渲染。
- 无依据内容已整项删除并重新平衡版式，没有模糊措辞、空框、参数占位、证据槽或视觉暗示。
- 每张都是独立、完整、可直接生图和进入后期制作的正式电商成品。
- 产品白底图、透明图和无字场景图没有新增营销文字。

## 格式

- 完整素材组源码块先写本组`参考图索引`，再从 `## 第1张：` 真实递增到最后一张；局部返修保留原编号。
- 外层使用四个反引号加 `markdown`，内层提示词使用三个反引号加 `text`。
- 用户只要求一种素材时，源码块只包含该对象；多对象每组独立编号。
- 没有占位页码、省略号、空字段、模板说明或重复画布表达。
- 最终源码块中的图生图提示词和负面提示词已经执行交付语言净化，负面提示词没有反向罗列流程词。

## 生图闸门边界

- 正式分镜已先完整交付；没有把生图选项、候选数量、工具日志或结果诊断写入源码块。
- 未获得用户明确选择时没有调用生图工具。
- 生图目标只引用已发布分镜，并冻结`storyboard_id + frame_release_version + prompt_release_version + release_pair + source_artifact_id + candidate_count`；执行前已确认 FR/PR 信封属于同一当前原子发布对、共同来源草案未`STALE`且输入版本仍为当前版本。
- 生图失败通过结果诊断定位最早失败层；没有静默覆盖提示词、整组自动重跑或把候选数量写入进化记忆。

## Q0-Q3 发布严重度

`P0-P4`只表示参考图生产能力；为避免术语冲突，最终质量问题统一使用`Q0-Q3`：

| 级别 | 定义 | 发布处理 |
|---|---|---|
| Q0 阻塞 | 商品/SKU错误、伪事实、未知结构冒充真实、违法/危险、无有效参考图 | 立即阻塞，回到事实或参考图负责模块 |
| Q1 严重 | 唯一任务缺失、参考图职责错、分镜槽位冲突、生产方式不可执行、正负提示词互相否定 | 阻塞当前分镜，只修最早失败层 |
| Q2 重大 | 主体层级、移动端识别、信息密度、物理关系、组内连续性或反套路检查失败 | 在循环预算内修复；影响任务或执行时不得发布 |
| Q3 润色 | 不影响事实、任务和执行的细节润色 | 可在预算内修复，不得为了润色改变已确认合同 |

检查顺序固定为`Q0 → Q1 → Q2 → Q3`。发现更高等级问题时停止检查下游表现；每轮只修一个最早失败层。最终分镜与生图调用都不得出现Q等级、评分或审核话术。

## 失败回退

| 失败类型 | 返回文件 |
|---|---|
| 商品身份、参数、适配或来源 | `product-dossier.md` |
| 输出对象、数量或状态 | `execution-engine.md` |
| 结构和逐张职责 | `structure-selection.md` |
| 人群、卖点和综合方向 | `reasoning-engine.md` |
| 文案重复、空泛或越界 | `copywriting-system.md` |
| 场景、人物、构图和风格 | `visual-system.md`、对应视觉子文件 |
| 生产不可执行 | `production-methods.md` |
| 提示词包含内部信息或模糊内容 | `prompt-orchestration.md` |
| 页码、字段或源码块错误 | `storyboard-template.md` |
| 生图范围、候选数量、结果追溯或重生边界 | `render-gate.md` |

只修复失败层及必要下游；不得在终检中临时补写卖点、证据或视觉方案。
