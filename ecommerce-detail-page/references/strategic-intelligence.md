# 策略智能中枢

本文件把已确认的商品事实、用户目标和上下文收敛为可验证的策略判断。只生成洞察摘要、优先级、假设、风险和可执行动作；不保存商品事实、不替代用户确认、不展示完整思考链，也不生成最终分镜。

## 目录

`使用边界` / `智能原则` / `多维决策地图` / `证据校准与主张纪律` / `策略收敛` / `方案组合与反证` / `跨资产与学习闭环` / `交付摘要`

## 使用边界

- 商品合同未发布时，不读取本文件，不用行业常识补齐产品事实。
- 范围合同发布前，只运行轻量预判：识别各类资产可能承担的购买任务、信息基础和风险；不确定人群、渠道、策略或逐图表达。
- 范围合同发布后，运行完整策略推演。标准任务覆盖核心维度；深度、全案、强竞争、高客单、复杂SKU、跨平台或运营任务再按需展开扩展维度。
- 任何外部研究、竞品、价格、销量、平台规则或真实经营数据，只能在用户提供可靠材料或明确要求研究后使用；未知内容只保留为待验证假设。

## 智能原则

把“更深入思考”落实为更好的决策，不落实为更长的分析：

1. 建立从事实到购买行为、再到画面与经营反馈的因果链。
2. 优先解决对当前购买决策影响最大的阻力，而不是平均覆盖所有维度。
3. 让每个主张拥有可追溯的证据、可执行的视觉承载和明确的表达边界。
4. 同时评估短期转化、误点与退货风险、品牌信任、生产成本和后续资产复用。
5. 在不确定处标记假设与验证方式；不得把策略判断转写成商品事实、效果承诺或外部数据结论。
6. 输出结论、关键依据、风险、可修改位置和下一步；不得输出隐藏推理过程。

## 多维决策地图

完整策略从下列维度中选择当前真正影响决策的项目。核心维度必须覆盖；扩展维度仅在存在任务信号时展开。

| 层级 | 维度 | 要回答的决策问题 | 常见产出 |
|---|---|---|---|
| 核心 | 商品与证据 | 什么绝不能变、什么能够证明、什么必须删除？ | 事实边界、证据矩阵、生产边界 |
| 核心 | 买家任务 | 谁在什么情境下希望完成什么任务？ | 主买家任务、触发场景、非目标人群 |
| 核心 | 渠道与时点 | 用户在搜索、货架、内容流、私域或详情阅读的哪一刻决策？ | 入口任务、阅读时长、承接关系 |
| 核心 | 购买阻力 | 当前最大阻力是看不懂、不相信、怕买错、怕麻烦、怕不值还是不相关？ | 主阻力、次阻力、必须提前解释的顾虑 |
| 核心 | 价值翻译 | 哪个真实属性能变成用户可理解的价值，且不夸大？ | 价值主张、利益表达边界、反证条件 |
| 核心 | 信任与选型 | 需要什么证据、哪些SKU/尺寸/适配风险会导致退货？ | 证据路径、选型护栏、防退货任务 |
| 核心 | 生产与保真 | 现有素材能稳定实现什么，哪些画面必须降级？ | 生产路径、保真锚点、替代方案 |
| 扩展 | 差异与品类心智 | 同类商品常见表达是什么，当前产品可凭什么不同？ | 差异支点、品类符号、同质化风险 |
| 扩展 | 价格与价值感 | 不谈虚构价格时，如何解释价值、套装和选择成本？ | 价值证明顺序、价格敏感风险、禁用表达 |
| 扩展 | 品牌与文化 | 哪些语气、审美、地域、节日或身份符号有帮助且不冒犯？ | 品牌一致性、文化适配、敏感项 |
| 扩展 | 生命周期与复购 | 首购、补货、升级、礼赠或售后阶段是否改变表达？ | 生命周期任务、复用资产、关系维护边界 |
| 扩展 | 漏斗与经营 | 当前最值得改善的是点击、理解、加购、成交、退货还是复购？ | 优先指标方向、承接缺口、测试假设 |
| 扩展 | 资产组合 | 多个输出对象如何分工并共享同一事实和视觉系统？ | 资产角色图、信息去重、跨平台复用规则 |
| 扩展 | 无障碍与风险 | 阅读、语言、视觉负担、特殊人群、平台和法律风险如何降低？ | 可读性约束、敏感边界、人工复核项 |

默认先覆盖前七项。扩展项必须由用户目标、商品决策结构、平台任务、已知资料或风险信号触发，不为显得复杂而逐项展开。

## 证据校准与主张纪律

建立“主张—证据—画面—风险”矩阵，并只让证据等级允许的表达进入方案：

| 证据等级 | 可用来源 | 可以做什么 | 不能做什么 |
|---|---|---|---|
| 已确认 | 用户确认、权威资料、准确参数表、授权材料 | 写入商品事实、参数、适配和对应证据表达 | 超出原始范围延伸结论 |
| 可观察 | 清晰产品图片、包装可见原文、真实素材 | 描述外观、结构、颜色、材质表面和可见文字 | 推断性能、功效、内部结构或认证 |
| 策略假设 | 行业常识、场景逻辑、未验证用户意图 | 决定人群候选、画面顺序、场景和方案差异 | 写成商品卖点、数据、适配或背书 |
| 待验证 | 用户未提供但对策略重要的外部信息 | 形成研究/测试需求或可选补充建议 | 当作竞品、市场、价格或人群事实 |
| 禁用 | 冲突、无来源、过期、不可商用或合规高风险信息 | 删除、降级或人工复核 | 用视觉暗示、模糊措辞或“可能”绕过 |

若一个主张没有证据，改用可观察结构、真实场景、一般化的购买任务，或整项删除。图像表现本身不能充当性能、认证、价格或销量的证据。

## 策略收敛

按以下顺序形成一个最小充分策略，不将所有洞察都塞入页面：

1. 选定一个主决策：点击识别、理解、信任、选型、成交、防退货、复购或资产复用。
2. 保留一个次决策；若无法说明次决策如何支持主决策，则删除。
3. 写清核心假设：`目标情境 → 主购买阻力 → 可证明价值 → 证据/画面机制 → 预期行为变化`。
4. 为每张图或每类资产指定唯一购买问题，避免同一价值被换词重复。
5. 预先标记假设失败条件：证据不足、场景不适配、主体不保真、误点风险、信息过载或渠道承接断裂。
6. 选择信息更少、证据更强、生产更稳、返修成本更低的同效方案。

候选方案必须改变至少一个高杠杆变量：目标情境、主购买阻力、证据路径、渠道承接、价值叙事、视觉锤或生产形式。只换背景、色彩或形容词不构成不同策略。

## 方案组合与反证

需要输出5个综合方案时，按“3个稳妥路径 + 2个差异路径”构造：

1. 证据优先：以最强事实和最短购买链路降低犹豫。
2. 渠道优先：适应当前入口的注意力与阅读方式。
3. 价值优先：在不虚构价格的前提下解释长期、工艺、套装或使用价值。
4. 差异优先：利用真实产品特征形成可识别的记忆点。
5. 情境优先：以真实使用、礼赠、身份或生活时刻扩展需求。

先执行四道否决门：产品不一致、事实/合规不成立、渠道任务错配、生产不可实现。通过后再比较买家匹配、证据强度、信息增量、退货风险、品牌一致性、差异性和复用性。不得用未经验证的精确分数伪装决策质量。

对首推运行简短反证：移除核心文案、证据、场景或装饰，检查命题是否仍成立；从认错、误导、买错、看不懂、实现不了、被同类淹没六个方向寻找最早失效点。只交付反证后的结论和修正方向。

## 跨资产与学习闭环

多输出对象使用同一商品合同与方向合同，但每类资产只承担其不可替代的任务：

- 主图：建立快速识别与点击理由。
- SKU图：减少型号、规格、颜色、套装或适配误选。
- 详情页：把主张转化为解释、证明、比较和顾虑收口。
- 海报：承载单一传播主题或活动入口。
- 产品素材图：提供保真、可二次排版的基础资产。

形成学习假设时，只定义“要观察什么、变什么、保持什么、什么结果会推翻假设”。没有用户提供的真实数据时，不宣称提升幅度、市场份额、转化结果或竞品结论。单次测试只改变一个主变量；结果只在来源可追溯时写入偏好事件或评估记录。

## 交付摘要

向 `reasoning-engine.md` 交付：当前主/次决策、决策情境、主购买阻力、可证明价值、证据矩阵摘要、差异支点、渠道承接、生产边界、主要风险、失败条件、可选测试假设和已启用维度。

向 `operation-review.md` 交付：指标方向、测试变量、应保持不变的变量、观察信号和数据边界。

向 `final-checklist.md` 交付：主张是否有证据、资产是否分工、渠道承接是否连续、信息是否过载、假设是否被误写成事实以及是否存在未处理的误点/退货/品牌风险。
