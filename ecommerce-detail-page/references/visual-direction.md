# 视觉方向判断

只在场景、人物、镜头、构图、光影、色彩、材质或版式会改变当前分镜时读取本文件。不要为了“更专业”而预读所有视觉规则。

## 判断顺序

按以下顺序确定视觉方案：

1. 当前图片要解决什么购买问题。
2. 核心售卖对象哪些特征、界面、权益或状态必须第一眼被看见。
3. 参考图允许哪些角度、裁切和生成方式。
4. 什么场景、人物或道具能够证明任务，而不是只做装饰。
5. 主体视觉尺度、留白、视觉动线、信息安全区和移动端阅读是否成立。
6. 光影、色彩和材质怎样强化真实商品，而不是覆盖商品。

## 避免通用模板

没有商品、品牌或任务依据时，不自动使用黑金、紫蓝渐变、米黄生活方式、万能圆台、霓虹线、粒子、水花、烟雾、伪实验室、随机植物、咖啡杯和无关人物。不要连续多张使用相同居中构图，只换背景和文案。

从商品本身寻找视觉记忆点：独特轮廓、结构关系、材质反射、颜色对比、使用动作、尺度、包装开启方式或真实使用环境。视觉差异必须服务识别、理解、信任、选择或情绪关联。

## 用户视线与三秒检查

先按用户真实浏览顺序检查画面：

1. **第一眼停驻**：缩小到实际展示尺寸后，当前唯一任务所需的核心视觉载体仍然清楚；入口识别任务通常让商品获得最高视觉优先级，细节、证据、选型或场景任务则由AI按买家问题自主决定视觉中心与主体尺度。反差、尺度和构图张力来自商品与任务，不来自随机装饰。
2. **品类与价值识别**：入口图通常先让用户认出商品品类，再看到一到两个已确认核心卖点；其他任务可让细节证据、SKU差异、使用动作或场景关系先进入视线。AI根据唯一任务、展示位置和阅读距离自主决定商品、卖点、证据与辅助利益的层级，不套固定顺序。
3. **信任判断**：材质、做工、纹理、接触、尺度和光影保持真实；销量、认证、专利、授权或功效没有资料时不得用视觉暗示替代证据。
4. **情绪与身份代入**：场景、人物和氛围匹配真实目标人群与使用情境，不用刻板身份标签，也不让场景压过商品。
5. **行动与平台适配**：利益以及带有交易条件、权益、时效或稀缺性承诺的行动文案只使用用户确认内容；不承诺事实的普通导航型行动文案可以自主生成。按实际平台检查裁切、安全区、移动端字号、色彩对比和内容限制，关键信息不能只靠颜色区分。

这些检查只改变当前分镜的主体视觉尺度、构图、卖点层级、场景、光影、文案安全区和生产方式，不新增公开分析字段。

## 构图与版面

不限制输出长宽比。参考图的宽高关系不作为输出画面约束，也不因参考图是横图、竖图或方图而沿用其外框。系统根据商品特征、使用场景、输出位置、信息层级和裁切风险自主决定画面组织；不预设固定画幅、像素或主体百分比。每张把自主判断落实为：

- 商品位置：位于画面什么区域，为什么有利于当前任务。
- 主体视觉尺度：在正常阅读和缩略图下是否足以识别、理解或比较，不用固定百分比代替判断。
- 裁切边界：哪些部位必须完整，哪些可以自然出画。
- 信息安全区：文案、标志、证据或平台裁切需要哪里保持低细节。
- 视觉动线：视线怎样从商品进入卖点或证据。
- 前后景关系：什么可以虚化，什么必须清楚。

核心视觉载体的尺度服从任务。入口图优先识别；结构图优先可见细节；数字权益或服务以真实界面、权益层或流程为识别载体；场景图仍要保证售卖对象清楚；选型图优先并列可比。不要为了留白把核心载体缩小到失去识别，也不要为了“大”裁掉关键结构或证据。

## 视角与镜头

实体商品优先沿用参考图能够证明的机位。用户已经提供可确认的同SKU真实背面、底部、内部或拆解图片时，对应机位可作为直接证据。缺少适用目标视图的同SKU直接资料时，先读取商品卡中的独立还原置信度：超过80分且已通过用户序列号确认，才可进入写实分镜；不超过80分或尚未确认时，改用已证实机位、补拍、真实商品层合成、三维资料或明确概念稿。多角度照片不等于准确三维模型，也不能把品类常识当作内部结构证据。数字权益或服务不评分物理隐藏面，改为保护真实界面状态、流程顺序和证据像素。

选择镜头时说明景别、俯仰关系、透视和焦点。避免极端广角导致比例变形，避免高倍率伪微距凭空制造纹理。局部特写必须保留足够结构上下文，让用户知道细节属于商品哪里。

## 场景与道具

场景不是背景名称，而是“谁在何时何地完成什么任务”。每个场景至少说明：

- 与商品使用或购买问题的关系。
- 商品如何与台面、地面、人体或环境真实接触。
- 道具承担尺度、使用或氛围中的哪一种职责。
- 哪些道具会遮挡商品、造成套装误解或引入未经确认的适配关系。

道具越少越好。无法说明作用的道具删除。需要展示到手数量时，只使用已确认的包装与配件事实；多视图展示不得误导为多件商品。

## 人物与手部

只有人物能够证明尺度、使用、佩戴、操作、情绪或目标情境时才加入。先检查：

- 手指、关节、握持点、受力、重心和接触阴影是否真实。
- 商品是否被手、衣服、头发或道具遮挡关键结构。
- 人体与商品尺度是否符合已知尺寸；未知时采用保守构图。
- 人物是否与目标情境相关，是否避免年龄、收入、职业、地域和家庭结构刻板推断。
- 动作是否暗示未确认的功能、功效、安全性或使用方法。

无人、无手的任务直接写“无人物”，不要额外推演人物造型。

## 光影、材质与色彩

先固定主光方向、软硬、色温和接触阴影，再决定轮廓光与环境反射。商品的真实颜色优先于氛围色；金属、玻璃、透明件、织物、皮革、塑料和纸张只描述参考图可观察的表面，不猜测成分或工艺。

高反射商品要控制环境倒影；透明和半透明材质要交代边缘、折射和背景分离；哑光表面不要被生成成高光塑料。组内保持主要光向、白平衡、综合色和修图质感连续。

## 文字与版式

正常销售画面默认生成可见卖点文案。文案只从已确认商品卡中的采用卖点、买家任务和用户沟通结论取材；AI根据商品特征、品牌气质、目标买家、唯一图片任务、销售市场、阅读距离和版面空间，自主决定最合适的标题命题、信息层级、措辞、语气、节奏、位置、字形气质、对比和视觉效果。表达可以俏皮、柔和、理性、刚硬、专业、情绪化，也可以采用更贴合当前商品的方式，不需要为了选择语气增加一轮问卷。

创意自由只作用于表达层：可以提炼、重组、压缩、转译和形成记忆点，但不能改变卖点原本的对象、事实维度、程度、条件、时效和证据范围，也不能新增或强化未经确认的参数、材质、功能、功效、认证、权益、价格、促销、适用人群或承诺。每句可见主张都应能回溯到商品卡中的已确认卖点；无法回溯就改写为可证表达或删除。

只有用户明确选择“无文案”，或输出对象本身就是白底图、透明图、无字场景图等不承载销售文案的基础资产时，才删除`最终文案`字段并不生成可见销售文案；商品本体真实存在的品牌、包装、界面和必要标签原文仍按证据保留。参数表、长说明、标志、包装原文、真实UI、权益条款、授权与编号由真实证据层或后期排版；价格、参数、认证、功效、权益、活动以及带有交易条件、权益、时效或稀缺性承诺的行动文案仍需真实依据，不承诺事实的普通导航型行动文案可自主生成。

根据自主构图和阅读动线明确安全区的位置、大小和背景复杂度。不要在提示词中同时要求“商品占满画面”和“大面积文案留白”；发生冲突时优先保证当前图片的唯一任务，并保留避免品类误认所需的商品识别。

## 图组连续性

整组共享商品状态、版面节奏、核心色彩、主要光向、背景材质、字体气质、边距逻辑、文字安全区和修图标准；各张仍按自身任务自主决定构图，并通过景别、机位、空间或证据形式形成变化。把本张真正需要的共同锚点内联进该张正向提示词，使单张独立执行仍能与整组连贯；相邻页面同时检查重复、跳跃和因果断裂。

向提示词模块交付：主视觉语言、商品位置与视觉尺度、裁切、安全区、镜头、场景、人物、道具、光影、材质、色彩、文字与组内连续性约束。
