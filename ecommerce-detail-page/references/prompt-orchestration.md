# 图生图提示词编译系统

本文件是把商品参考图、视觉DNA、逐张任务、场景、镜头、光影、文案和生产边界编译为中文图生图提示词的唯一来源。最终提示词必须直接可执行，不是分析、方案解释或模型百科。

## 目录

`编译目标` / `输入前提` / `分镜偏好覆盖层` / `图组编译` / `单图编译顺序` / `生产模式写法` / `提示词模板` / `编译红队` / `输出接口`

## 编译目标

每张提示词要消除九类歧义：

1. 生成什么类型的电商图片。
2. 使用哪张参考图，分别提供什么信息。
3. 商品哪些部分必须锁定。
4. 原图哪些部分允许清除、重建或改变。
5. 最终场景、人物、动作和道具是什么。
6. 镜头、构图、主体占比和留白是什么。
7. 光影、材质、色彩和商业质感是什么。
8. 图像模型与后期分别负责什么。
9. 当前图最可能出现什么错误，如何禁止。

提示词宁可明确分层，也不要堆砌形容词。每个词必须能改变成图或防止错误。

## 输入前提

必须具备：

- 用户确认或可安全采用的输出对象与张数。
- `reference-image-reasoning.md` 生成的参考图编号、视觉DNA、P0-P4能力和单图参考策略。
- 当前图唯一任务与图组关系。
- 已发布的分镜槽位合同：画布状态、产品锚点/占比/裁切、文案/品牌/证据安全区与平台适配。
- 可用事实、可观察内容和禁用主张。
- 场景/视觉/生产工作包。
- `persistence-evolution.md` 放行的只读`preference_profile`偏好配置；没有适用规则时为空，不得由提示词编译器自行猜测。

P0不得编译商用提示词。P1-P4也必须检查本张所需能力轴全部通过；总体P级不能覆盖文字、未知面、内部、配件、尺度或证据轴不足。需要未知面、内部或精确适配但资料不足时，改用可靠视角、补图/建模、背景合成或概念稿，不在提示词里要求模型猜。

## 分镜偏好覆盖层

在编译前把`preference_profile`偏好配置映射到具体字段：

| 偏好目标 | 可影响字段 |
|---|---|
| reference | 身份母图、主/辅参考选择与实际上传范围 |
| scene | 场景真实性、人物/道具边界与空间具体度 |
| composition | 主体占比、机位、留白、裁切和文字安全区 |
| aesthetic | 风格、色彩、光影、材质感与信息密度 |
| fidelity | 锁定层、合成方式、未知视角容忍度与后期边界 |
| copy | 上图文案密度、语气与后期排版策略 |
| negative | 动态负面提示词的颗粒度与稳定禁区 |
| collaboration | 只影响确认节奏，不写入最终提示词正文 |

结构、图组排序与单图职责偏好只能在 ST/DC/FS 发布前由主控用于合法候选首推；提示词编译器必须忽略`structure`目标，不能在已发布合同或分镜草案上重排任务。覆盖层只改变尚未被上游合同冻结的提示词表达，绝不能覆盖商品事实、安全、当前明确要求、参考图能力、合规、输出范围、结构/方案确认状态、分镜草案或最终格式。更窄范围规则优先；撤销、失效、陈旧候选、E0、静默采用和未授权长期规则不注入。最终分镜不得出现“历史偏好”“用户画像”“记忆规则”等来源说明。

## 图组编译

先建立图组级不变量：

- 商品身份、视觉DNA和所有不可改变项。
- 统一商品清晰度、边缘、材质渲染和真实尺度。
- 品牌色、基础光源、修图质感、字体/组件语言和后期逻辑。
- 统一参考图索引、身份母图和各能力轴来源；每张只上传实际使用的参考图片。
- 统一禁用项：错误结构、错误文字、错误数量、错误SKU、伪证据等。
- 统一槽位语法：安全边距、商品层级、文字/品牌/证据区和平台裁切规则；每张可按任务改变主体占比与位置。

再建立逐张变量：任务、主参考图、视角、主体占比、场景、人物、道具、信息区、文案、证明方式和动态负面项。

不得为每张重新定义商品；不得只换背景制造不同页面。

## 单图编译顺序

### 1. 成图任务

写清输出对象、图型和唯一任务，例如“生成主图第2张核心结构证明图”，不要写内部营销模型或抽象目标。

### 2. 参考图调用

先明确身份母图，再明确逐张视角/几何母图与辅图；优先级固定为：身份母图只定义目标SKU身份，视角母图只定义机位与可见几何，辅图只补声明的能力轴，不得覆盖目标SKU、结构或颜色。具体写：

- `以参考图1作为商品主体与正面轮廓母图`。
- `以参考图3补充金属网纹与边缘细节`。
- `参考图2仅参考包装，不复制其背景和拍摄透视`。

每张参考图只说明实际用途。禁止使用“综合参考全部图片”“保持一致”这种无法执行的空话。

### 3. 锁定层

列出本张必须保持的具体锚点：

- 外轮廓、长宽厚比例、部件数量和连接关系。
- 孔位、接口、按键、缝线、纹理、透明区、开口和边缘。
- 主体色、局部色、金属/玻璃/织物等可观察表面。
- LOGO位置、方向、包装、配件、型号与可见原文。
- 当前可靠视角能看见的结构。

复杂文字、LOGO或包装优先使用真实商品抠图/锁定层，不能让模型重绘。

### 4. 重建与生成层

分别写清：

- 可清除/重建：原背景、临时支撑、无关反射、非目标道具、杂乱手部等。
- 可生成：新空间、背景、台面、人物、道具、氛围、阴影、反射、景深和文字安全区。
- 不可生成：未知背面、内部、额外配件、错误数量、错误SKU和无证据效果。

### 5. 最终画面

用一段肯定式描述完整画面：商品在哪里、与什么发生关系、唯一视觉焦点是什么、哪些元素是辅助。背景、人物和道具必须证明本张任务，不做无目的装饰。

### 6. 镜头与构图

先消费已发布的分镜槽位合同，再明确：

- 视角与相机高度、正面/斜角/俯视/微距。
- 景别与焦段感，避免不必要的极端广角。
- 主体位置、占比、朝向、透视、裁切和完整性。
- 前中后景、焦点、视觉动线、负空间和文字安全区。
- 商品锚点、主体占比与裁切边界；文案、品牌和证据只进入已批准安全区。
- 参考图视角之外的新表面是否会暴露；若会则禁止或换机位。

### 7. 人物与物理关系

有人物时写：人物景别、手势/动作瞬间、握持/佩戴/操作位置、产品与手/身体/空间接触、遮挡上限、尺度、重力、接触阴影和安全动作。人物不能覆盖关键结构或LOGO。

无人时明确商品静物或场景空镜，不添加随机人手、人脸或肢体。

### 8. 光影、材质和色彩

根据商品表面写光：主光方向与软硬、辅光、轮廓光、接触阴影、反射控制、透明/金属/织物/塑料等表面表现。色彩写主辅强调关系和背景色，不改变商品真实颜色。

### 9. 文案与后期

- 精确中文、参数表、价格、型号、LOGO和包装文字默认后期排版或沿用真实商品层。
- image负责预留安全区、层级、背景对比度和不遮挡主体。
- 若用户明确要求模型内生成短文字，只允许最终文案白名单，并提醒校对；长文字仍交后期。
- 无字场景、白底和透明素材不添加营销文案。

画面文字白名单只有两类：商品原有可见原文、本张最终上图文案。字段名、策略、状态、审核语、参数占位和流程词不得成为画面文字。缺少证据时，删除证据组件并重新平衡版式，不保留空框、伪报告或暗示性占位。

### 10. 成品质量

写与当前图相关的质量要求：真实商业摄影、商品清晰、边缘干净、材质可信、物理关系正确、移动端识别、同组一致。不要重复所有系统规则。

### 11. 动态负面提示词

只保留当前图高风险错误：

- 商品：变形、结构改变、部件增减、比例错误、改色、错误文字、错误LOGO、错误包装、错误SKU、重影、融合。
- 视角：生成参考图未展示的未知面、错误透视、镜像、悬浮、穿插。
- 场景：尺度错误、接触错误、阴影错误、危险动作、道具抢焦、背景复制原图杂物。
- 人物：多余手指、错误握持、肢体畸形、遮挡商品、人物喧宾夺主。
- 信息：乱码、伪参数、伪证据、伪价格、伪促销、文字过密。
- 风格：过度磨皮、塑料感、虚假光效、低清、噪点、锐化过度、组内漂移。

负面提示词不是规则垃圾桶。超过当前图必要范围的词删除，避免互相冲突；不得在负面提示词中罗列被禁用的流程词，以免反向带入画面。

## 生产模式写法

### 图生图锁定

适合P1-P3、当前视角可用。强调参考图主体、结构和颜色权重；只重建背景、光影与轻微摆放，不显著旋转到未知面。

### 真实商品抠图 + 背景生成 + 后期合成

品牌文字复杂、包装精确、像素级结构或商用保真要求高时强制优先。生产包必须给出真实抠图/透明通道、保护遮罩、无商品背景板、商品位置/尺度/透视、接触阴影方向、边缘综合色与最终文字校准要求。提示词只生成背景、人物、道具、光影与留白，不要求模型重绘商品本体。

### 局部重绘

只重绘明确遮罩区域，其他区域锁定。适合去杂物、修边、换小道具和局部背景，不用于重造商品结构。

### 3D/多角度

仅P4或有对应角度资料。说明模型/CAD/转台资料是几何依据；贴图、LOGO和颜色仍需校准。

### 概念稿

用户明确要概念探索时可使用低参考能力扩展，但必须在源码块外标明非商用真实商品图；正式分镜不能混淆概念与定稿。

## 提示词模板

编译后形成一段连贯指令，可用分号分层：

```text
生成【输出对象与图型】，本张任务是【唯一任务】；以【身份母图编号】锁定目标商品/SKU，以【视角母图编号】定义当前机位与可见几何，【辅参考图编号及其唯一用途】；严格锁定【具体视觉DNA与不可改变项】，只允许改变【背景/光影/摆放/人物/道具/留白等】，不得生成【未知面、额外部件、错误文字等】；最终画面为【完整场景与唯一焦点】；镜头采用【角度、景别、焦段感】，商品锚定于【槽位位置】，占画面【比例】，遵守【裁切边界】，呈现【构图、焦点、动线、留白】，文案/品牌/证据只进入【已批准安全区】；【人物与物理关系，若无人则删除】；光影采用【主辅光、反射、阴影】，准确表现【材质表面】，色彩为【关系】且商品真实颜色不变；【只描述最终可见短文案与文字安全区，不把后期工作流写进模型提示词】，保持【组内不变量】；成品达到【当前对象质量要求】。
```

删除所有括号、空字段、候选、模糊词和互相冲突的要求。

## 编译红队

每张输出前检查：

1. 是否明确主/辅参考图及用途。
2. 是否把“保持一致”展开为具体视觉DNA。
3. 是否区分锁定层、重建层和生成层。
4. 是否要求了资料不支持的新视角、内部、配件、数量或效果。
5. 场景、人物、构图和光影是否可实际执行且服务任务。
6. 图像模型与后期职责是否清楚，精确文字是否被错误交给模型。
7. 正面指令与负面提示是否冲突或过载。
8. 同组提示词是否共享商品和视觉不变量，每张是否有真实信息增量。
9. 是否含无依据事实、内部策略、评分、测试、建议或占位。
10. 是否完成交付语言净化：行动方向内部化，不把模型名、确认、审核、测试、候选、建议或后期工作流写入图像模型正文。
11. 是否严格消费分镜槽位合同，没有临时改变主体占比、裁切、文案区、品牌区或证据区。

失败时只修正失败层，不整段堆词重写。

返修、整组重发和局部页面输出都必须重新执行词汇扫描；只净化交付语言，不静默改变已确认商品、图组和视觉内容。

## 输出接口

向单图确认与分镜模板交付：提示词合同版本信封（`contract_version: PR-nnn`、规范`status`、`owner: prompt-orchestration`、任务/商品/参考图/范围/结构/方向/分镜槽位的实际`parent_versions`、与对应分镜合同相同的`release_pair`和分镜草案`source_artifact_id`及来源追溯记录）、参考图使用、分镜槽位合同、产品锁定、允许变化、最终画面、镜头构图、场景人物、光影材质、色彩排版、生产方式、后期职责、完整图生图提示词和动态负面提示词。编译完成后，提示词与从同一分镜草案派生的分镜合同先同时为`PENDING`；只有分镜确认时两者才可原子转为`RELEASED`，提示词不得把未发布分镜合同列为父版本，也不得把旧草案内容包装成指向当前父版本的新信封。
