# 图片需求与图组规划

只回答两个问题：真正需要制作哪些图片，每张图片为什么不可替代。AI预构建阶段使用轻量的 [image-type-index.md](image-type-index.md) 做候选初筛，不提前加载本文件的完整图型、排序和编排规则；商品卡与输出范围确认后，先读取买家任务、六维检查、硬淘汰、排序、去重和编排小节，再依据轻量索引、已选对象和当前买家问题只定位命中的图型类别，不通读十三类能力库。始终先遵守商品与参考图边界，不要为了显得完整而凑图。

## 还原买家任务

把用户目标、平台位置和商品事实转成买家必须完成的任务：

1. 识别：一眼确认这是什么、是不是正在寻找的商品。
2. 理解：看懂核心利益、结构特点和使用结果。
3. 选择：选对颜色、型号、容量、尺寸、数量、套装或适配关系。
4. 相信：看到能够支撑主张的结构、细节、参数、认证或真实使用依据。
5. 代入：理解商品在真实空间中的尺度、操作、穿戴、安装和生活关系。
6. 学会：知道必要的使用、安装、维护或收纳步骤。
7. 排除顾虑：避免买错、误用、预期偏差、退货或安全风险。
8. 行动：在有真实依据时承接明确主题、活动或传播入口。

为每项候选任务写清“买家问题、可用证据、可见表达、缺失代价”。没有商品事实或参考能力支撑的任务不要进入图组。

## 用户决策六维检查

把用户的浏览和决策心理转译为每张图的内部检查，不另行生成营销报告。六维只做用户视角诊断和零分淘汰，不再计算第二个总分：逐项判断是否成立；关键维度为零且任务依赖该维度时淘汰候选，其余候选仍只使用后文的一百分表排序。诊断结论折叠进分镜字段和提示词：

| 维度 | 用户瞬间要完成的事 | 编译进分镜时检查 |
|---|---|---|
| 注意力抓取 | 在列表页快速划屏时愿意停下 | 用商品真实优势支持主体比例、反差、构图张力或差异化记忆点；不靠无关装饰抢眼 |
| 三秒信息效率 | 迅速知道卖什么、好在哪 | 先让品类和主体清楚，再突出一到两个已确认核心卖点，保持“商品主体＞核心卖点＞辅助利益”的层级 |
| 信任建立 | 判断品质、真实度和依据是否可靠 | 用可观察的材质、做工、细节和用户确认的客观证据建立信任；不编造销量、认证、专利或功效 |
| 情绪与身份 | 想象自己使用并感到“适合我” | 只在任务需要且资料可实现时加入真实场景、目标人群、身份气质和氛围，不让情绪遮住商品识别 |
| 转化驱动 | 愿意点击、加购或继续查看 | 只有用户提供的真实价格、优惠、赠品、权益或行动文案才可出现；用版式和视觉动线引导下一步，不伪造承诺 |
| 平台与无障碍适配 | 在不同入口中看得清、用得上 | 遵守已确认平台尺寸、裁切和内容限制；保证对比度、字号和安全区，不只用颜色传递关键信息 |

不同输出对象不强行平均覆盖六维：主图优先注意力、三秒信息效率和品类识别；详情页优先信任、理解和防错；场景图优先情绪与尺度；白底/透明素材优先真实度和复用适配。所有维度最终都必须落到“成图任务”“画布与布局”“最终画面”“镜头与构图”“光影、材质与色彩”“生产与后期”或正负提示词，不新增公开字段。

如果已启用营销模型加速层，只接收它编译后的结论，不把模型名当成图片理由。把每条结论依次转成“买家问题、可证明的卖点/利益、证据需求、图片任务、顺序和信息增量”；证据不足时把利益降级为可观察特征、待补证或删除。模型只辅助结构和排序，不新增确认步骤，也不改变本文件的硬门槛、去重和最小充分图组原则。

## 开放式可设计图型能力库

下列内容是能力下限，不是类型上限，也不是每个商品都要做的固定清单。用户提供的图型、案例和分类默认作为思维起点；除非用户明确说“只限这些”，AI必须继续检查当前商品还有没有更重要但未被列出的买家问题。先匹配已有图型；若关键问题没有合适类型，再建立商品专属候选，并接受完全相同的证据、生产、风险、排序和去重检查。

按需读取规则：先用 [image-type-index.md](image-type-index.md) 选出最可能解决当前买家问题的类别名，再在本节定位对应三级标题，只读命中的类别与“可叠加的辅助表现手法与生产方式”；只有跨类别候选确实难分时才多读一个相邻类别。不得为了证明思考全面而一次加载全部类别。

每张候选只保留一个主任务和一个视觉中心。优先用一个主图型组织画面；当尺寸线、局部放大、引线、分屏、场景、时间切片或其他辅助表现确实能让同一买家问题更快读懂时，可以组合多个相容手法，数量由移动端可读性、证据和生产可行性收敛，不能形成第二中心。不能把“渲染、悬浮、拼贴、氛围”等制作或风格词当成图片存在的理由。每个候选内部必须写清：主图型与必要辅助表现、唯一买家问题、适用输出对象与目标SKU、所需证据、动态参考图使用方式、生产方式、视觉记忆点、主要风险，以及不能制作或需要降级的原因；对话中只展示通过初筛的3–5项，最终分镜不公开候选清单。

### 一、商品标准呈现类

用于先把商品讲清楚，建立后续主图、SKU图、海报和详情页可共同复用的真实商品底座。

| 图型 | 适用表达 | 证据与生产边界 |
|---|---|---|
| 纯白底标准图 | 清楚展示单件商品、套装或包装本体 | 保持轮廓、颜色、边缘、接触阴影、配件和数量真实，并遵守平台白底规范 |
| 透明背景商品图 | 生成可跨背景复用的独立商品层 | 交付必须是真实透明通道；玻璃、半透明、毛发、镂空和柔边需要可靠抠图能力 |
| 商品英雄识别图 | 用大比例主体、简洁背景和可靠机位完成首屏识别 | 只突出一个已确认利益或记忆点；不能用华丽环境遮住品类、轮廓和真实颜色 |
| 多角度身份图 | 在统一尺度和光线下展示有直接证据的不同视角 | 每个视角都需要同SKU直接图片或可靠三维资料；未知面不能借镜像或常识补齐 |
| 商品与包装同框图 | 同时确认商品、包装版本和品牌身份 | 商品与包装必须属于同一SKU/版本；不让包装数量或场景道具造成到手内容误解 |

### 二、结构拆解类

用于透明化呈现构造、材料层级和装配关系，解决内部用料与做工顾虑。

| 图型 | 适用表达 | 证据与生产边界 |
|---|---|---|
| 爆炸分解图 | 零部件沿装配轴分层散开，呈现零件与组装关系 | 需要同SKU零件、拆解实拍、工程图或可靠三维资料；没有直接内部证据时，必须满足隐藏视图规则并得到用户序列号确认，不得补造零件 |
| 剖面结构图 | 截面展示内部层级和核心部件 | 层级顺序、厚度关系、部件名称和材质必须有资料；不得把品类常识画成当前SKU事实 |
| 分层堆叠图 | 规整展示扁平多层材料 | 只使用已确认的层数、顺序、颜色和材料；适合面膜、纸尿裤、鞋垫、复合板等平层结构 |
| 线稿结构图 | 用简洁线条表达轮廓、连接和结构关系 | 可作为非写实结构表达，但线条所指部件仍需证据；不添加置信度或视图推断标签 |
| 装配演示图 | 分步表达拼接、安装、拆卸或收纳 | 步骤、方向、配件和完成状态必须真实可执行；单张无法看清时拆成连续分镜，不把多步骤挤成一团 |
| 局部开窗透视图 | 只打开一个关键区域，保留外观与内部位置关系 | 需要对应内部直接证据、工程图或可靠模型；开窗边界是解释手法，不得暗示商品真实带透明外壳 |
| 核心部件定位图 | 在整体轮廓中标明关键部件所在位置 | 部件位置、数量和作用必须可核验；精确名称、引线和文字交给后期排版 |

### 三、细节质感类

用于放大局部、支撑品质与定价，前提是参考内容分辨率足够。

| 图型 | 适用表达 | 证据与生产边界 |
|---|---|---|
| 局部放大特写图 | 放大关键结构、边缘、连接或做工 | 保留局部属于商品何处的上下文，不凭空增强纹理或锐度 |
| 材质肌理图 | 呈现皮纹、木纹、编织、釉面等可观察表面 | 只描述图片可见表面或用户已确认材质，不把视觉观感升级为未知原料 |
| 工艺细节图 | 呈现缝线、倒角、焊点、印花、接口咬合 | 工艺名称和品质结论必须有资料；图像只放大真实细节，不伪造精度 |
| 微距细节图 | 呈现膏体、纤维、元器件等微观特征 | 只有原图或专业素材支持相应倍率时采用，禁止模型凭空生成微观结构 |
| 触感交互特写图 | 用按压、弯折、开合、触摸或涂抹呈现真实手感与反馈 | 需要动作和形变依据；不能把视觉柔软、弹性或顺滑升级为无证据性能结论 |
| 全貌与单一细节拼接图 | 同时确认商品身份和一个关键品质证据 | 只使用同SKU完整图与高分辨率局部；移动端仍需看清，避免双中心和伪造纹理 |

### 四、功能验证类

用于把抽象卖点变成可观察证据；画面必须是真实可复核的验证，不是效果表演。

| 图型 | 适用表达 | 证据与生产边界 |
|---|---|---|
| 性能测试图 | 防水、防摔、耐磨、承重、不粘等测试场景 | 需要真实测试条件、数值边界和安全做法；没有证据时不制造极限测试或结果 |
| 使用状态图 | 点亮、雾化、展开、伸缩、工作状态 | 状态、动作和效果必须由实拍、说明书或用户资料证明 |
| 前后效果对比图 | 同条件展示使用前后差异 | 必须有同条件真实样本和可用授权；美妆、健康、清洁等效果不得夸大或伪造 |
| 动态演示静帧图 | 用连续静帧表达开合、回弹、旋转、调节 | 保持动作顺序、受力和部件连接真实；需要多帧时明确阅读方向 |
| 数据可视化图 | 把续航、分贝、精度等参数转成刻度或图表 | 只使用用户确认的数据、单位、测试条件和比较基准；图表由后期排版，不让模型编造数字 |
| 工作机制路径图 | 用流向、路径或局部透明解释水、气、热、光、力或信号如何经过商品 | 路径、方向和作用必须有说明书、测试或工程依据；图形覆盖层由后期制作，不生成伪科学能量线 |
| 功能作用范围图 | 展示照明、喷雾、覆盖、收音、支撑等真实作用区域 | 范围、角度、距离和条件必须已确认；氛围光、水雾或轨迹不能代替性能证据 |
| 痛点与结果对照图 | 以同一问题的使用前、过程或解决后时刻说明价值 | 结果必须可观察且有证据；不能用夸张表情、虚假耗时或不成立的环境制造效果 |

### 五、参照认知类

用于帮助用户快速理解尺寸、容量、比例和差异，降低误购与退货。

| 图型 | 适用表达 | 证据与生产边界 |
|---|---|---|
| 尺寸参照图 | 与常见物体、手掌或尺寸线建立尺度 | 商品尺寸和参照物尺度必须准确；参照物不得造成套装或赠品误解 |
| 容量展示图 | 用真实填充物呈现可容纳数量 | 容量、填充方式和物品尺寸必须已确认，不以夸张堆叠虚增容量 |
| 真人比例图 | 用手持、佩戴、穿着或操作展示真实比例 | 需要尺寸依据，保证人体接触、姿态、遮挡和安全关系真实 |
| 竞品对标图 | 对比厚度、重量、功能或结构差异 | 仅在用户提供合法、同条件、可核验的竞品资料时采用；没有可靠基准时改做自身规格解释 |
| 空间落位图 | 展示商品放入房间、柜体、桌面、车内或设备位后的占用关系 | 需要商品和目标空间尺寸、安装状态或真实场景；不得泛化为“适配所有空间” |
| 收纳携带图 | 展示折叠、闭合后放入包、柜、后备箱或随身携带的关系 | 需要商品与容器尺寸、真实闭合状态和配件；不暗示所有包型都可容纳，也不把容器当赠品 |
| 重量与握持感知图 | 用手持、提拿或已知重量参照帮助理解便携性 | 需要真实重量和安全姿态；“轻若无物”等主观结论只有证据支持时才可使用 |

### 六、选择适配与防错类

用于回答“我该买哪款、能不能装上、哪些情况不适用”，优先降低误购、误用和退货。

| 图型 | 适用表达 | 证据与生产边界 |
|---|---|---|
| 同系列SKU差异图 | 用统一机位并列颜色、容量、尺寸、型号或套装差异 | 每个SKU分别绑定有效参考内容和真实差异字段；不跨SKU借色、借件或融合 |
| 尺码与版型选择图 | 解释身体、脚型、商品尺寸或穿着松量的选择关系 | 需要可靠尺码表、测量方法和模特信息；不承诺未经验证的上身效果 |
| 接口与兼容匹配图 | 展示接口、设备、车型、滤芯或配件的适配关系 | 需要精确型号、接口、尺寸、公差和授权资料；外观相似不能作为兼容证据 |
| 规格选择引导图 | 根据人数、空间、用量、用途或场景选择合适规格 | 选择逻辑和边界必须由用户资料支持；不自行推算使用周期、覆盖范围或节省金额 |
| 适用与不适用边界图 | 清楚展示允许和禁止的环境、人群、对象或用法 | 只使用说明书、法规或用户确认边界；不新增医疗、安全或人群结论，不演示危险动作 |
| 自身版本对比图 | 对比本商品不同代际、规格或套装的真实差异 | 只比较用户提供且可核验的同品牌版本；复杂参数和文字由后期排版 |
| 定制选项预览图 | 展示刻字、图案、颜色、尺寸、表面或组合选项怎样落在同一基础商品上 | 需要真实可生产范围、可变区域、字符/图案限制和效果样张；预览不能承诺每种组合已有现货，也不能改动固定结构 |
| 模块与配置组合图 | 帮助用户选择主机、模块、配件或服务组件的合法组合 | 需要兼容关系、必选/可选规则、数量和到手边界；不把不可组合项拼成虚构配置 |

### 七、使用教学与维护类

用于回答“到手后怎么装、怎么用、怎么清洁、怎么收纳”，降低学习成本与错误操作。

| 图型 | 适用表达 | 证据与生产边界 |
|---|---|---|
| 分步安装图 | 按真实顺序展示安装、连接、校准或首次设置 | 需要说明书、配件、工具和完成状态；步骤较多时拆成连续分镜，不省略安全环节 |
| 分步使用图 | 展示开机、调节、使用、关闭或取用流程 | 操作点、方向、界面和反馈必须对应当前SKU；不让模型重写精确界面文字 |
| 正确与错误用法图 | 对照容易混淆的正确动作与禁用动作 | 禁用内容必须来自真实边界；危险情况用安全图示表达，不制作可模仿事故场景 |
| 清洁保养图 | 展示可拆洗部件、清洁工具、方式和禁忌 | 需要防水、可拆、清洁剂和保养资料；不得因画面方便而错误浸泡或拆机 |
| 折叠收纳图 | 展示折叠、卷收、归位或节省空间的真实步骤 | 需要结构、动作顺序和收纳尺寸依据；保持连接、受力和部件数量准确 |
| 耗材更换图 | 展示滤芯、刀头、电池、补充装等更换位置和步骤 | 需要兼容型号、开启方式和更换说明；周期、寿命和成本必须有真实资料 |

### 八、场景呈现类

用于唤醒真实需求、建立尺度和使用想象，场景必须说明谁在何时何地完成什么任务。

| 图型 | 适用表达 | 证据与生产边界 |
|---|---|---|
| 实景使用场景图 | 在真实空间展示商品使用、摆放和接触 | 商品仍是主要识别对象，空间尺度、重力、接触和道具关系真实 |
| 氛围感场景图 | 用环境、光色和生活痕迹强化情绪调性 | 适合次级主图、海报或场景素材；列表入口图不得因氛围弱化品类识别 |
| 多场景组合图 | 在一张图中说明多个真实用途 | 只有“多用性”是唯一主任务时采用；各场景必须清楚且不能暗示未确认功能 |
| 第一视角场景图 | 从驾驶、办公、用餐或操作视角建立代入 | 视线、手部、接触、遮挡和安全符合真实使用，不用夸张广角扭曲商品 |
| 时间触发场景图 | 呈现早晨、通勤、工作、运动、晚间或季节中的具体使用时刻 | 时间与商品需求必须相关；不以日夜、天气或节日暗示未确认性能和权益 |
| 空间约束场景图 | 在小户型、桌面、车内、柜体或有限动线中说明商品关系 | 需要尺度和落位依据；商品不得穿模、挡住真实接口或制造不成立空间 |
| 人物关系场景图 | 呈现亲子、伴侣、朋友、人宠、同事或赠礼中的真实互动 | 关系必须服务购买问题，避免身份刻板化；不补造礼盒、配件或适用人群 |
| 使用过程场景图 | 捕捉取出、握持、穿戴、操作、清理或收纳中的关键动作 | 动作、接触、受力和商品状态必须真实，关键结构不能被人物完全遮挡 |
| 结果时刻场景图 | 呈现完成任务后的可观察结果和情绪反馈 | 结果需要真实证据且仍让商品可识别；不靠夸张表情替代功能证明 |
| 跨场景迁移图 | 用连续或分区画面展示商品从家中到通勤、户外或旅行的多场景价值 | 只有多场景本身是核心卖点时采用；场景数量服从移动端可读性，不虚构多用途 |

### 九、创意视觉类

用于形成差异化记忆点和品牌调性。创意必须先回答“除吸睛外，新增了什么识别、理解、信任、场景或行动价值”；答不出就淘汰，且创意不能改写真实商品。

| 图型 | 适用表达 | 证据与生产边界 |
|---|---|---|
| 悬浮呈现图 | 用受控悬浮、倒影和留白形成轻盈或高级感 | 只作为明确的创意陈列，不暗示真实使用状态；选用时负面提示词不得再禁止悬浮 |
| 原料创意图 | 用成分、食材或天然材料建立视觉联想 | 原料、成分和含量关系必须有用户确认资料；不把装饰元素写成实际成分 |
| 趣味拟人图 | 通过动作、表情或故事强化年轻化记忆 | 只改变创意叙事，不改变商品结构、数量和功能；符合品牌、人群与平台边界 |
| 轮廓与负形构成图 | 利用商品独特外形、阴影或留白建立快速识别 | 需要准确轮廓与比例；抽象背景不能拉伸商品或让用户认错品类 |
| 事实锚定视觉隐喻图 | 把已证实但抽象的轻、静、暖、快、柔等利益转成直观联想 | 隐喻只作用于环境和图形层，商品保持真实；无主张证据时不得使用 |
| 材质与色彩节奏图 | 用真实表面、品牌色和重复节奏形成审美记忆 | 需要准确颜色、可观察表面和品牌边界；只换背景而无决策价值时淘汰 |
| 编辑式拼接图 | 通过全貌、单一细节、留白和图形版式形成杂志式视觉 | 只围绕一个任务并控制一个局部证据；文字与精细蒙版由后期完成，避免双中心 |
| 连续动作与时间切片图 | 把真实运动、开合、倾倒、飞溅或轨迹组织成有节奏的静态画面 | 动作顺序和物理轨迹必须成立；不把动态效果误写成功能或性能证据 |
| 感官视觉转译图 | 用质地、温度感、香气联想、清脆或柔软的视觉线索唤起感官 | 只表达氛围与联想，不编造气味、口感、功效或材料；食品和美妆需更高证据门槛 |
| 品牌符号场景图 | 让品牌图形、包装结构或专属色成为空间和构图的一部分 | 需要品牌资产和授权边界；不得重绘错误标志，也不能让符号吞没商品 |
| 微缩或尺度叙事图 | 以明确的概念比例制造趣味故事和记忆点 | 仅用于海报、次级主图或创意素材，并明确是视觉叙事；不得用于真实尺寸、容量或性能证明 |

### 十、组合、包装与到手类

用于展示套装、规格、包装与交付内容，所有数量和权益关系必须与实际售卖内容一致。

| 图型 | 适用表达 | 证据与生产边界 |
|---|---|---|
| 全家福套装图 | 展示商品主体、包装、配件和赠品 | 只出现已确认到手内容，区分标配、选配和赠品，不把场景道具当成套装 |
| 多色款陈列图 | 并列展示真实颜色、款式或规格 | 每款绑定对应SKU/状态的综合参考内容，统一机位便于比较，不生成不存在的颜色 |
| 量贩堆叠图 | 呈现多件装、耗材量或批量价值感 | 数量必须对应真实售卖规格；不得靠复制堆叠夸大到手数量或优惠 |
| 开箱到手清单图 | 展示包装开启后真实收到的主体、配件、说明和赠品 | 需要对应包装版本与完整清单；精确文字和包装原文使用真实像素或后期 |
| 包装层级与运输保护图 | 展示内外包装、固定、防护和收纳关系 | 包装结构、材料和数量必须真实；不得把保护性画面升级为无证据抗摔承诺 |
| 礼赠交付图 | 展示已确认礼盒、手提袋、卡片与赠送时刻 | 不补造礼袋、卡片、赠品或节日权益；人物关系与品牌气质真实克制 |
| 补充装与主品关系图 | 解释主品、替换件、补充装、耗材或组合购买关系 | 型号、数量、接口和是否含主品必须清楚，避免把补充装误认成完整商品 |

### 十一、信任背书与来源类

用于让客观证据可见，不允许图像模型生成看似真实但不存在的资质、文档、人物或数据。

| 图型 | 适用表达 | 证据与生产边界 |
|---|---|---|
| 真实资质与检测图 | 展示认证、检测报告、专利或授权中的相关事实 | 需要有效文件、对应SKU、使用授权和有效期；文档原件用真实像素，摘要由后期排版 |
| 原产地与原料来源图 | 展示可核验的产地、原料或供应链来源 | 需要来源证明；场景不得冒充当前批次实拍，也不把自然意象写成认证事实 |
| 制造工艺与品控图 | 展示真实生产步骤、工艺或检验环节 | 需要工厂/工艺素材和授权；不生成伪工厂、伪实验室或不存在的检测过程 |
| 防伪与溯源图 | 说明真实防伪位置、查询入口或批次追溯方式 | 需要官方流程与可用入口；二维码、编号和精确文字必须由真实素材或后期负责 |
| 用户使用证据图 | 呈现获得授权的真实用户、案例或使用结果 | 需要授权、同条件和真实性说明；不得生成虚假评价、头像、销量或专家背书 |
| 服务与保障范围图 | 说明已确认的保修、退换、安装、客服或服务边界 | 条款、地区、期限和条件必须真实；不把服务承诺扩张成无条件保证 |
| 品相与个体差异披露图 | 展示二手、样品、孤品、手作或天然材料的真实磨损、纹理、色差与允许波动 | 需要当前实物或有代表性的授权样本；区分“实物一件一图”和“自然差异范围”，不磨掉瑕疵或承诺每件完全一致 |

### 十二、利益与行动类

用于把真实价格、优惠、赠品、权益和下一步行动转成清楚的视觉入口，只在用户提供并确认具体信息时启用。

| 图型 | 适用表达 | 证据与生产边界 |
|---|---|---|
| 价格与优惠主图 | 突出到手价、立减、折扣或限时利益 | 需要价格、地区、平台、时间和条件；数字及规则由后期精确排版，不生成虚假倒计时 |
| 买赠与权益图 | 展示赠品、会员、安装、配送或附加权益 | 每项权益的内容、数量和条件必须已确认；画面清楚区分商品、赠品和服务 |
| 套装价值关系图 | 说明组合购买中每项真实内容和总价值关系 | 需要实际套装和价格依据；不自行计算原价、节省金额或制造虚高锚点 |
| 活动主题图 | 围绕已确认节日、渠道或活动形成单一传播主题 | 需要活动资料和授权；主题装饰不能遮住商品，也不自动带入优惠 |
| 下一步引导图 | 通过箭头、留白或短行动文案引导查看详情、选择SKU或继续浏览 | 行动必须符合平台允许方式；不使用欺骗性按钮，不让模型生成长文字 |

### 十三、数字权益与服务交付类

用于让非实体商品的交付内容、真实体验、版本差异和服务边界可见。必须至少有一种可访问参考视觉；不能把数字权益画成会收到的实体卡、礼盒或快递。

| 图型 | 适用表达 | 证据与生产边界 |
|---|---|---|
| 权益总览图 | 一眼说明用户实际获得的版本、时长、次数、权限或内容 | 权益名称、数值、适用账号/地区和条件必须已确认；精确文字由后期排版 |
| 真实界面预览图 | 展示软件、会员中心、课程、数字内容或服务入口的真实体验 | 使用已授权真实截图像素，不补造按钮、页面、功能、数据或用户状态 |
| 交付与激活流程图 | 说明付款后的发放、绑定、预约、激活、核销或开始使用路径 | 步骤、渠道、时效和异常分支必须有流程资料；不把时效范围夸成即时或绝对承诺 |
| 版本与权益差异图 | 比较不同档位、时长、地区、账号类型或服务版本 | 每个版本分别绑定真实权益和限制，不跨版本拼接成不存在的套餐 |
| 有效期与边界图 | 说明生效时间、到期、续费、退款/取消、使用范围和不适用情况 | 条款必须来自当前有效资料；不暗示自动延长、无条件退款或无限权限 |
| 服务过程与触点图 | 展示预约、沟通、交付、验收或售后中的真实触点 | 只用已授权人员和场景资料；没有授权时使用中性流程载体，不虚构专家、门店或成功案例 |
| 授权与异常处理图 | 建立来源、授权、客服入口和异常处理范围的信任 | 授权文件、编号、印章、联系方式和条款保留真实像素或后期排版，不由模型生成 |
| 订阅、租赁与预约周期图 | 说明获得的是访问权、使用权还是服务时段，以及计费、生效、归还、续期或取消节点 | 需要当前周期、费用条件、押金/归还、续订和取消资料；不把使用权画成所有权，也不暗示自动续期或无条件退款 |
| 服务覆盖与履约范围图 | 说明门店、区域、时段、上门、远程或跨区服务可覆盖到哪里 | 需要真实地区、时间、预约容量和例外；地图、范围与时效由可编辑后期负责，不画成无限覆盖 |

### 可叠加的辅助表现手法与生产方式

辅助表现手法不能独立成为分镜任务。局部放大窗、引线标注、分屏、时间轴、刻度图表、轮廓光、负形、图形色块、轻量轨迹和文字安全区，只在帮助同一个主图型更快读懂时叠加。精确文案、数字、表格、认证、型号、二维码和界面文字统一交给真实像素或后期排版。

| 生产方式 | 适合情况 | 边界 |
|---|---|---|
| 真实商品层加场景生成 | 商品外观必须高度保真，但背景、人物或氛围可生成 | 锁定商品像素、尺度和接触关系，生成内容不得覆盖关键结构 |
| 多参考图图生图 | 同SKU多图可互补身份、角度、细节、包装或场景 | 推理先分析全部资料，生成时只输入目标SKU同款内容；其他SKU默认不传入单SKU生成，冲突必须先裁决并写出采用与舍弃结果 |
| 三维建模与渲染 | 需要统一多角度、复杂灯光、结构或可控动画静帧 | 需要可靠模型、工程资料或足够多角度证据；三维只是生产方式，不补造未知结构 |
| 实拍或补拍 | 精确结构、质感、人物接触、测试和合规证据最重要 | 把缺失机位、动作、测试条件和授权写成明确补拍清单 |
| 信息图形与后期合成 | 参数、步骤、对比、证书、长文字或准确界面需要可编辑 | 商品事实来自真实资料；图像模型只提供底图和安全区 |
| 明确概念稿 | 用户接受不保证实物还原的前瞻、提案或广告概念 | 不冒充真实商品、实测结果或官方结构，并与写实分镜分开确认 |

图型确定后，只把采用图型的画法、证据、构图、生产方式和风险写进当前分镜；未采用图型、候选比较和分类清单不进入最终提示词。

## 先排除不能成立的候选

评分前先淘汰以下候选；后续分数不能覆盖这些问题：

- 混淆商品身份、SKU、颜色、型号、数量、套装、包装或配件。
- 依赖置信度不超过80分的背面、底部、内部、拆解等未知视图，或依赖虚构结构、错误尺度、无法成立的人物接触或当前素材不能实现的视角。超过80分但尚未得到用户序列号确认的目标视图，也不得进入写实分镜。
- 使用无依据的参数、功效、认证、销量、评价、价格、优惠、赠品、适配、案例或竞品结论。
- 把用户确认的推理视图当成安全结构、性能、功效、适配或安装步骤的证明。视图确认只允许相应写实画面进入候选，这些高风险主张仍需要直接资料。
- 违反平台、授权、隐私、人身安全或类目合规边界。
- 与已选图片只换背景、同义文案、装饰或风格名，没有新增事实、证据、选择帮助、场景或顾虑解法。
- 无法转译为明确的图片职责和可执行画面，只能产生咨询结论、运营动作或抽象审美描述。

## 使用已确认的综合方向

综合方向的定义、比较和用户选择只以 [confirmation-workflow.md](confirmation-workflow.md) 为准，本文件不再重复建立第二份方向规则。这里直接读取上游采用方向，用它改变主要买家阻力、关键证据、使用情境、视觉记忆点、对象组合或生产方式，再进行候选排序和图组编排。综合方向最多比较5个，但不要求每次凑满；直出或全自动任务也必须已有内部采用结论；只换颜色、背景、风格标签和同义文案不算落实方向。

## 按需定量排序

先排除不能成立的候选。若一个候选明显同时具备最高证据、唯一任务价值和可生产性，直接说明决定性理由，不为简单任务制造一串分数；只有复杂任务、多个候选难分高下、用户要求定量或需要可复核取舍时，才按零到五分评价下列六项并换算为一百分：

| 评价项 | 权重 | 判断问题 |
|---|---:|---|
| 买家决策价值 | 25 | 是否直接完成关键识别、理解、选择、信任或顾虑任务 |
| 事实与证据强度 | 20 | 画面与主张是否有可靠商品资料或可观察依据 |
| 素材与生产可行性 | 20 | 现有参考图、工具和后期方式能否稳定实现 |
| 信息新增程度 | 15 | 相比已选图片是否带来新的事实、证据、场景或解法 |
| 视觉理解效率 | 10 | 缩略图和正常阅读中能否快速看懂唯一任务 |
| 输出对象适配 | 10 | 是否适合实际位置、阅读方式和复用目标 |

统一使用整数锚点：`0=不成立，1=极弱，2=有明显缺口，3=足够采用，4=强，5=直接证据与高适配`；不使用3.7之类假精度。按“该项得分 ÷ 5 × 权重”计算并向下取整为整数总分，同时记录真正决定取舍的一项，不用相近总分假装存在客观精确差异。优先选择总分更高的候选；总分相差不足5分时视为同一档，依次选择证据更强、买错风险更低、生产更稳定、所需图片更少的方案。不要让纯审美分量盖过商品真实性和买家决策价值。

## 用新增价值去重

每选入一张，就让剩余候选通过“新增价值门”，避免再叠加一套伪精确百分制。候选至少要明确命中以下一项，并且前图没有完成：关闭尚未解决的买家任务、增加新的可验证事实或证据、降低选错/误用/预期风险、补充必要场景/尺度/交互，或补齐用户点名且有真实复用价值的资产形态。只换背景、同义文案或风格标签一律不通过。

- 若是否新增仍有争议，对上述五项分别记`0=没有、1=部分、2=明确`，总分达到2且至少一项为2时保留；否则合并或删除。该十分制只用于边界候选，不作为公开报告。
- 已确认范围内的选型防错、安全边界、法定信息或关键使用步骤属于必需任务时，先保证被正确覆盖，再选择最清楚的图型；不能因为边界候选分数较低而静默删除。若现有分镜数量不足，让用户调整数量、合并方式或主张范围。
- 用户指定数量高于可成立任务数时，先尝试分配真正不同的职责；仍无法成立时，请用户在减少数量与明确制作视觉变体之间选择，不要静默凑数。
- 需要补拍、建模或新增资料的任务可以列为素材缺口，但在资料到位前不能进入正式分镜，也不能写成可立即生图的提示词。

## 按商品难点调整优先级

- 多SKU、尺寸或适配复杂时，提高选型、防错和比较图优先级。
- 高客单、耐用品或专业采购时，提高结构证据、服务边界和真实生产优先级。
- 穿戴、手持、安装或操作商品时，提高尺度、接触、动作和步骤优先级。
- 食品、保健、美妆、母婴或安全相关商品，提高成分、功效、认证和适用人群的证据门槛。
- 礼赠商品提高包装、到手内容、赠送情境和数量关系优先级。
- 强视觉、低解释商品提高首屏识别、真实场景和视觉记忆点，减少无必要长页。

这些调整只用于改变当前图片的任务、顺序、证据、构图或提示词约束。

## 形成必要图片清单

1. 先满足用户点名的输出对象和不可缺买家任务，不擅自扩展全套资产。
2. 复杂候选使用定量排序；明显占优的简单候选直接按决定性理由选择。每选一张后，让其余候选重新通过新增价值门。
3. 当所有必需任务已覆盖，且剩余候选都不能通过新增价值门时停止增加。
4. 为每张只保留一个主任务；次要信息只能帮助主任务，不能形成第二中心。
5. 最终成品是一张连续详情页长画布时，仍按真实买家任务形成内部模块清单；实际模块数等于已确认商品卡中有依据、可生产且通过新增价值门的具体任务数，不按常见长页长度固定为8、10或12，也不使用“卖点一/卖点二”“结构或功能”等占位任务。每个模块单独编号、单独写提示词，并在生产与后期中声明长画布顺序与合成关系。只有一个真实主任务时才压成一条分镜，不能把“成品1张”误当成“只需要1个模块”。
6. 只在已经确认的结构内编排：递进结构承接连续解释，并列结构承接独立SKU或独立入口，混合结构同时保留主链和独立变体。若候选任务与已确认结构不适配，先回到结构选择让用户重选，不在编排时静默改结构。
7. 让顺序服务于“识别 → 理解 → 证明 → 选择/使用 → 顾虑收口”，但只保留当前商品真正需要的环节。

## 交给逐图提示词

内部逐张摘要输出对象、唯一任务、目标买家问题、可用事实与证据、选择理由、新增价值、应如何画、不可出现内容和前后承接。把这些结论折叠进正式模板已有的`成图任务`、`最终画面`、`镜头与构图`、`商品锁定`、`视角与事实边界`和提示词，不新增公开字段。商业、运营、营销、产品和美学知识只能改变这些内容，不得生成独立策略、投放、测试或审美报告。
