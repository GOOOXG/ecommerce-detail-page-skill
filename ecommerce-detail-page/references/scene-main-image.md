# 主图场景系统

本文件只负责主图场景。张数读取执行模块的范围合同。

## 目标

主图目标是提升点击率、小图识别度和第一眼利益理解。

## 子场景

1. 搜索首图场景：主体清晰、白底或浅背景、产品识别优先。
2. 点击钩子场景：强视觉锤、少字、强利益点，适合信息流或货架竞争。
3. 卖点证明场景：一张图只讲一个核心卖点，用可见结构、准确材质、真实效果或已有证据证明；依据不足时切换到不依赖该字段的表达。
4. 机制可视化场景：适合过滤、吸力、芯片、成分、材质层级等抽象卖点。
5. 品牌质感场景：适合高客单、礼赠、品牌调性和审美溢价。
6. 活动承接场景：仅在用户提供真实活动、价格、赠品或时间依据时启用。
7. 独立投放变体场景：围绕同一准确卖点输出不同构图、文案密度或风格方向，每张均作为完整正式主图独立成立。

## 执行规则

- 正式设计前读取 `structure-selection.md` 的主图结构合同；未发布时停止，不在本文件重新判断或切换结构。
- 递进式主次结构的卖点文案不得重复：每张图只拆解一个新卖点或新购买顾虑，主标题、副标题和核心卖点必须形成“识别 -> 利益 -> 证明 -> 场景 -> 防错/信任”的递进链路；行动方向只在内部参与排序，发现重复时必须重写或合并。
- 等量并列结构不要求卖点递进，但必须多维度覆盖主图营销文案特征：每张独立主图都要有清晰点击钩子、一个主利益、一个视觉锤和一个完整购买理由；不同图之间从痛点、利益、结构、场景、质感、信任、活动依据中选择不同角度，不得只换背景。
- 默认内部比较4类策略方向：稳妥转化型、品牌质感型、机制可视化型、独立投放变体型。
- 主图必须预留主标题、副标题、卖点标签、Logo或品牌标识位置；生图提示词不要求模型生成准确文字，精确文字默认后期排版。
- 产品占比通常40%到65%，小型零件、细节主张或极简首图可由AI按识别度调整；标题区、卖点区、品牌区和辅助视觉区必须有明确承载位置。
- 禁止产品占满画面导致无法排版，禁止背景光效覆盖文字安全区。
- 产品一致性要求高时，优先采用“背景生成 + 真实产品后期合成”或“图生图产品锁定”；提示词只描述背景、光影、场景、留白和辅助视觉。
- 竞品研究只提炼点击逻辑、卖点表达和版式结构，不复制竞品画面、文案或品牌元素。

## 素材槽位

主体识别槽、点击钩子槽、核心卖点槽、证据/机制槽、品牌标识槽、后期文案安全区、独立变体差异槽。

## 组内角色

- 递进式主次结构：第1张写“主图”；后续按实际任务写“卖点承接图、结构证明图、场景联想图、选型防错图、信任收口图、活动承接图”等语义角色。
- 等量并列结构：每张都写“独立主图”，后台记录不同点击角度或投放场景。
- 混合结构：主链图片使用语义角色，独立变体写“独立主图”，后台只记录单一视觉变量或投放场景。
- 最终成图名称、上图文案和图生图提示词不得出现实验编号、测试标签、比较评语或内部变量名。
- 不得输出机械编号式组内角色；必须使用能说明本张任务的语义角色。
