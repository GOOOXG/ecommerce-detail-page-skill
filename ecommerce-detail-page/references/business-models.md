# 商业模型调度系统

本文件统一负责全行业商业问题分类、模型选择、复杂度判断和业务子文件路由。模型是AI后台决策工具，不是用户前台选项，也不得替代商品事实。

## 启用时机

- 当前任务仍以分镜提示词为产物，且已确认的货盘、价格、品牌、渠道、复购或经营条件会直接改变图组任务、证据、顺序或提示词字段。
- 商品跨类目、跨平台、高客单或强竞争本身不自动触发；只有通用需求、图组和营销模块无法裁决一个具体分镜决策时才读取。
- 普通主图、SKU图、海报、产品素材图和单组详情页默认不读取；独立经营分析、品牌咨询、增长方案、投放复盘或行业研究不属于本技能运行链。

加载前必须声明要修改的范围、结构、方向、分镜或提示词字段；无法映射到字段时停止，不加载本文件或任何业务子文件。

## 八维分类

先判断：

1. 决策层级：战略、战术、执行或复盘。
2. 商业性质：产品、服务、平台、内容或数据。
3. 客户类型：ToC、ToB、ToG或多边关系。
4. 成交方式：货架、内容、直播、门店、顾问或招标。
5. 增长引擎：流量、转化、客单、复购、裂变、提价或降本。
6. 资源底座：品牌、供应链、组织、技术、牌照或关系。
7. 行业属性：消费、制造、科技、医疗、本地生活等。
8. 时代变量：内容电商、私域、即时零售、跨境或AI Agent。

分类只用于确定页面职责和证据路径，不生成行业参数、平台数据或产品能力。

## 问题路由

| 当前问题 | 主模型方向 | 页面动作 |
|---|---|---|
| 新品类、复杂功能、用户看不懂 | JTBD、ACCA、DAGMAR | 先解释是什么，再建立理解和确信 |
| 货架点击和短链路 | AIDA、PAS、4U | 强化识别、利益和快速证明 |
| 内容种草与分享 | AISAS、RACE、BAB | 场景代入、搜索验证和传播理由 |
| 高客单与耐用品 | CDJ、FABE、SPIN | 评估、证据、服务和顾虑兜底 |
| SKU复杂、容易买错 | MECE、Kano、选择架构 | 总览、差异、适配和防错 |
| 价格与套餐 | 心理账户、锚定、版本定价 | 先解释价值，再呈现真实价格关系 |
| 复购、会员、私域 | RFM、CLV、5A | 分层、周期、权益和唤醒 |
| 品牌升级与礼赠 | 定位、品牌资产、品牌原型 | 心智位置、独特符号和仪式感 |
| 页面效果差 | 指标树、漏斗、OODA、事前验尸 | 找到最高影响节点并定向返修 |

## 模型适用层级

- 通用基础：漏斗、JTBD、Kano、指标树、RFM、品牌资产，可跨行业使用。
- 领域标准：AIPL、O-5A、GPM、MEDDIC等，只在对应成交场使用。
- 平台方法：FAST、FACT、KFS、STEPS等，需要确认平台和当前适用性。
- 探索工具：趋势模型、创意方法和局部经验，只生成假设，必须由事实、数据或用户确认收敛。

## 复杂度与思考工具

| 类型 | 处理 |
|---|---|
| 简单 | 一个主模型直接首推 |
| 繁杂 | 用MECE、信息层级和指标树拆解 |
| 复杂 | 用假设、情景、反事实和小范围变体收敛 |
| 混乱 | 先回商品文档解除主体、事实和合规冲突 |

按问题选择最少工具：拆问题用MECE/逻辑树，找根因用5Why/漏斗，做选择用决策矩阵/事前验尸，快速迭代用OODA/CRO，发散用双钻/TRIZ，防误判用奥卡姆剃刀/Goodhart/红队挑战。

## 岗位视角

- 市场/CMO：定位、品牌资产、内容漏斗和品效协同。
- 电商运营：货盘、平台人群、投放效率、利润和大促节奏。
- 产品经理：JTBD、Kano、双钻、RICE和验收标准。
- 消费者研究：任务、动机、障碍、信任和心理账户。
- 视觉总监：独特资产、视觉锤、信息层级和情感化设计。
- 数据分析：指标树、漏斗、留存、归因和因果边界。
- 风控合规：平台规则、宣传边界、知识产权和证据真实性。

多视角只提交结论与风险，最终合成为一个方案；不得把岗位意见并排堆给用户。

## 选择算法

1. 用八维分类确定业务问题和成交场。
2. 判断复杂度，决定直接首推、结构化拆解、变体迭代或先解除冲突。
3. 选择一个主模型组合，最多两个辅助工具。
4. 将模型翻译为用户阶段、页面任务、证据、场景、文案、视觉和风险边界。
5. 用商品事实、生产可行性和合规否决不成立方案。
6. 只输出产品化建议和可修改位置；模型名仅可作为简短依据，不进入最终分镜。
