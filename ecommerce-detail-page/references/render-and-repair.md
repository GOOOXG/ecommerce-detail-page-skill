# 返修与可选生图

先保护已经确认并交付的正式分镜，再处理定向返修或用户明确选择的生图。生图永远位于完整提示词之后，不能成为默认动作，也不能反向改变商品事实和分镜任务。仍处于逐图待确认的分镜不得进入生图范围。工具能力画像应在图组规划前先完成；本文件负责在实际调用前复核，不把能力适配留到结果失败后才开始。

## 定位返修范围

优先使用稳定分镜编号，例如`主图-02`，而不是只说“第二张”。记录：

- 保留项：商品、SKU、参考图、任务、机位、构图、场景、光影、文案或其他不可联动内容。
- 修改项：用户明确指出的字段和预期结果。
- 禁止联动项：此次修改不得影响的相邻图片或组级规则。
- 生图选择：只重发提示词、生成新候选，还是先确认再生图。

问题描述不完整但不影响商品真实性时，采用最小解释并继续；会导致SKU、结构、尺度或安全误判时只问一个关键问题。

## 判断最早失败层

1. 商品身份、SKU或参考图筛选与综合方式错误：重新建立该张动态参考图使用方式。
2. 该张任务重复、顺序或组内职责错误：修正图组规划并检查受影响相邻图。
3. 场景、人物、构图、光影或物理关系错误：只重算视觉字段。
4. 提示词歧义、冲突、遗漏或负面词误伤：只重写相应提示词段。
5. 实际图片的偶发瑕疵：保持提示词，先生成新候选或做局部后期。
6. 工具、配额、尺寸、遮罩或透明能力失败：记录为执行问题，不把它误判为提示词质量问题。

只修最早错误层及其必要下游。共享商品事实或整组视觉语言未改变时，不重做全部分镜。

## 局部返修交付

- 保留原阅读页码和稳定编号，例如只返修原第4张仍写`第4张（详情页-04）`。
- 重发该张完整分镜，避免用户把补丁片段手工拼接到旧提示词。
- 未修改字段按当前正式版本保留；修改字段必须与正向、负面、生产和后期说明同步。
- 不在正式分镜中附加修改日志、内部评分或旧版本差异。若对话中确实需要说明改动，把它放在正式 Markdown 交付之外；不得把说明句混入待校验的分镜正文或代码围栏。
- 用户没有要求重新生图时，只交付修订提示词，不自动调用工具。

## 提示词交付后的选择

全部分镜提示词交付且没有待确认图时，不在同一份正式分镜中自动追加菜单。用户已在范围阶段给出生图意向就按其选择执行；尚未说明时只停止在提示词交付，等待用户后续另行选择：

1. 暂不生图。
2. 生成指定分镜。
3. 生成当前图组全部分镜。
4. 生成全部图组。
5. 为不同分镜分别设置候选数量。

用户原请求已经写明“暂不生图”时直接结束，不重复显示菜单。用户后续只说“生图”但未说明范围时，才显示上面的紧凑选择。这里的数量始终是“每张分镜的候选图片数量”，不是分镜数量；数量必须是每张明确的正整数。用户已经要求生图但未写数量时，每个指定分镜默认生成1张。只有用户明确说“后续都按N张”时才继承该数量，不把某一张曾用过的数量自动套给其他分镜。若总量超过当前工具、配额或时间的合理范围，先说明拆批方式与影响，不静默截断。

## 生图前能力检查

调用工具前逐项确认：

- 当前环境确有可用的图片生成或编辑工具。
- 目标稳定编号存在、没有重复，范围与用户选择完全一致。
- 目标分镜均已确认或经过全自动内部复核，没有待确认卡。
- `参考图使用`中声明的实际生成参考输入仍可访问；当前目标SKU/版本/状态和综合证据没有被替换或跨款融合，单SKU生成没有传入其他SKU图片。
- 执行器已把分镜中的自然语言输入职责解析到当前任务内的具体可访问附件、裁切或遮盖区域；该映射只用于工具调用和结果回溯，不新增到正式分镜，不输出固定参考图编号。自然描述无法唯一对应附件时只问一个最小问题，不猜测绑定。
- 工具支持所需参考图数量、图生图或编辑方式、负面提示词、遮罩、目标尺寸和候选数量。
- 透明成品要求工具能够输出真实透明通道；白底或棋盘格不能冒充透明。
- 当前正向、负面、画布、交付目标和遮罩已经冻结用于本次调用；工具适配只能改变等价序列化或分批方式，不能改写语义。

若在范围或结构阶段尚未记录能力画像，先补记以下最小信息再编排：可接收的参考图数量、是否能隔离 SKU、是否支持遮罩/分层、是否能输出真实透明、文字和界面由谁保留、目标画布和候选上限、失败结果能否回溯到分镜编号。能力未知时采用真实商品/界面层优先的保守路径，不用模型承诺代替工具能力。

按以下顺序适配能力：

1. 工具原生支持时，分别传入正向提示词、动态负面提示词、实际参考输入、遮罩、尺寸和候选数量。
2. 工具没有独立负面提示词入口时，把动态负面内容转换为同一次生成指令末尾的“需要避免的具体失败”，保持原意且不新增禁令；这是等价序列化，不需要用户重复确认。
3. 候选数量超过单次上限时无损拆批；目标尺寸只有等价比例或更高分辨率档位时可等价映射，并记录实际输出。
4. 工具只支持一张参考图时，只有在不丢失目标SKU证据的前提下，才可使用已确认的真实商品层，或把同一目标SKU的互补资料确定性排成单一参考画布；参考画布不改色、不重绘、不加入其他SKU，并保留足够分辨率。若会损失关键角度、细节或身份约束，就不能视为无损。
5. SKU总览/比较图的工具不能稳定隔离多个身份时，分别生成或保留各SKU真实商品层，再后期合成；不得把多个SKU同时交给会混合身份的生成步骤。
6. 透明成品只有在原生透明输出或可靠抠图/分割能保留玻璃、半透明、毛发、镂空和柔边时才成立；否则保留提示词并说明不能交付真实透明通道。
7. 分镜已经指定“底图生成后叠加真实证据层”或“分SKU生成后合成”时，按该顺序分别生成、遮盖、裁切、合成与校字；不能把多步生产压成一次生成后声称真实UI、商品文字或多个SKU已经精确保留。

必需能力仍缺失时不调用。若必须减少参考证据、改变画幅语义、透明目标、遮罩或生产方式，先让用户确认新的分镜方案；不得把工具限制伪装成原方案已完成。

## 生成与候选管理

- 按稳定分镜编号逐张绑定提示词、动态参考图使用方式和候选序号，避免结果串图。
- 工具单次上限低于用户数量时无损分批，例如4个候选可按2加2执行。
- 不因某张失败而重复生成已经成功且未被点名的其他分镜。
- 不伪造图片、下载地址、透明能力或完成状态。工具失败时保留已交付提示词并说明可重试条件。

## 审查实际结果

对每个候选依次核对：

1. 商品与目标SKU是否一致，结构、比例、颜色、材质、文字、包装和配件是否漂移。
2. 本张唯一任务是否成立，商品是否仍是正确的视觉中心。
3. 构图、人物、接触、尺度、重力、阴影、反射、景深和文字安全区是否真实。
4. 是否出现正负提示词没有预见的稳定失败模式。
5. 多个候选的差异是随机质量波动，还是所有候选都重复出现同一可归因问题。

再按以下结果维度记录是否达到本张首要目标：

- **事实保真**：商品身份、SKU、结构、颜色、文字和状态是否可追溯到证据；
- **任务清晰**：缩略图和正常阅读下是否一眼知道本张要解决的问题；
- **决策增益**：是否新增了证明、选择、使用、场景或顾虑解除，而不是只换背景；
- **生产完成度**：真实商品/界面层、后期排版、合成、遮盖和透明边缘是否按分镜执行；
- **平台可用性**：裁切、安全区、字号、对比度和目标位置是否成立。

用户明确采用、否定、纠正或返修时记录原因；若有点击、加购、成交、停留、退货或客服反馈，只在当前商品、平台和任务范围内使用，不把单次结果直接推广为通用偏好。只返修最早失败层：事实错误回商品卡，任务错误回图组，生产错误回工具适配，表达错误回当前提示词。

偶发问题优先选别的候选或后期修复；重复问题才触发提示词最小返修。用户明确采用、否定或说明原因时，把反馈交给偏好学习模块，但候选数量、工具故障和未评价结果不构成偏好。
