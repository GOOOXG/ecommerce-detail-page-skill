# 输出对象选择与设计

在商品卡确认后，按 [confirmation-workflow.md](confirmation-workflow.md) 判断用户真正要制作的对象。用户已经点名对象、数量、平台/位置、用途和目标SKU/版本且无冲突时，原意向直接成为范围结论，摘要与结构首推在同一轮给出，不另停一次；只有内容缺失、冲突、存在多种解释或用户主动要求完整探索时，才展示对应缺口或完整设计需求预判卡。范围明确后只读取“通用规则”和实际选择的对象小节；选择多个对象时再读“组织跨对象关系”，不加载未选对象规则。所有对象最终都必须变成逐张中文图生图分镜提示词。

## 通用规则

1. 为每张图指定一个输出位置、一个主要买家任务和一个可见结果。
2. 只使用已确认事实、可观察内容和可靠参考图；不要因对象惯例补造参数、促销、认证、适配或SKU差异。
3. 让构图、场景、光影、文案区和后期方式共同服务唯一任务；不要先选风格再寻找理由。
4. 让同组图片共享商品身份、颜色材质和视觉语法，同时用机位、信息和场景形成真实增量。
5. 把商业、运营、营销和美学判断转译成“做什么图、为什么、怎样画”；不能转译时不要加载或输出。
6. 数字权益或服务的核心视觉载体可以是真实界面、权益页、交付流程、授权资料或已授权服务场景；不强套实体轮廓、材质和包装，也不把权益画成会收到的实体卡、礼盒或快递。
7. 正常销售画面默认根据已确认商品卡中的采用卖点生成可见文案；AI自主选择最合适的语气、结构、层级和视觉呈现，但创意只能重组表达，不能偏移原始信息维度或增加未经确认的事实。用户明确选择“无文案”，或选择白底图、透明图、无字场景图等不承载销售文案的基础资产时，才不生成可见销售文案。

## 主图

解决“这是什么、与我是否相关、为什么值得点开或继续看”。

- 先做缩略图停驻检查：根据商品形态、首屏任务和展示位置自主选择清楚易识别的主体尺度，并用清晰轮廓、有效反差和有张力但不失真的构图抓住注意力；品牌专属色、原料构图或使用场景必须与真实商品和任务有关。
- 从商品轮廓、材质、结构、颜色、原料、动作或真实场景中建立差异化记忆点，不复制类目通用背景或只靠夸张装饰。
- 做三秒信息检查：入口识别任务通常先让用户认出品类与商品，再看到一到两个已确认核心卖点；若本张负责细节证据、SKU选择或真实场景，AI根据唯一任务、展示位置和阅读距离自主安排商品、卖点、证据与辅助利益的视觉层级，不套固定顺序。
- 让后续主图分别承担利益、结构证据、真实场景、选型或信任任务；不要只换背景和同义文案。
- 用身份可靠、边缘清晰、颜色稳定的参考图保留实物真实感；需要品质信任时，用可观察材质、做工和细节，不用过度精修或虚构背书替代证据。
- 场景、人物身份和氛围只在能够强化真实使用代入时加入；商品仍是主焦点，不能拍成其他品类或让情绪遮住商品。
- 价格、优惠、赠品、销量、认证、专利、授权，以及带有交易条件、权益、时效或稀缺性承诺的行动文案，只有在用户提供真实依据并确认使用时才可出现；不承诺事实的普通导航型行动文案可由AI自主生成，但必须符合平台允许方式且不得伪装成交互控件。
- 按用户资料或任务当时可核验的当前官方规则检查平台尺寸、裁切、内容限制、移动端字号、色彩对比和安全区；无法核验时不把记忆中的旧规则写成最新事实。关键信息不能只依赖颜色表达。
- 默认把商品卡中已确认的核心卖点重组为首屏可见文案；AI根据首屏任务、商品特征、品牌气质、销售市场和阅读场景自主决定最合适的措辞、语气、层级与呈现，正式分镜只写最终结果，不写决策过程。创意表达不能改变卖点事实维度；复杂标志、型号和长文字交给真实像素或后期排版。只有用户明确选择“无文案”时，当前主图才不承载销售文案。
- 参考图的宽高关系不作为输出画面约束；每张主图根据商品特征、使用场景、输出位置、信息层级和裁切风险自主决定商品位置、视觉尺度、留白和动线，不套固定比例或主体百分比。
- 不把详情页的参数百科、海报的情绪主题或SKU对照全部塞进一张主图。

## SKU图

解决“我该选哪一个、怎样避免买错”。

- 只展示真实存在的颜色、型号、容量、尺寸、数量、套装、包装和适配关系。
- 需要总览时统一机位、比例、光线和标签位置，让差异可比较，并让各SKU使用独立商品层或分区合成；需要单SKU时只向生成模型提供该SKU/状态的有效参考内容，其他SKU只在内部用于识别差异并形成具体禁区。
- 把最容易混淆、退货代价最高的差异放在最清楚的位置，优先展示选择依据而非装饰。
- 没有准确尺寸、参数或适配资料时，删除相应承诺，不制造空白参数表或推测关系。
- 不借用其他SKU的颜色、部件、包装或配件，也不把多个SKU融合成理想款。
- 数字权益或服务把SKU解释为档位、版本、时长、地区、账号类型或服务包，分别展示真实权益和限制，不跨版本拼成不存在的套餐。

## 详情页

解决“为什么适合我、依据是什么、怎么选和使用、还有哪些顾虑”。

- 先定义三层交付粒度：最终成品多少张、内部有多少个分屏/模块及对应多少条分镜提示词、后续每条分镜生图多少个候选。`N条详情页分镜`默认表示N个不同任务的分屏、模块或最终切片；若最终交付一张连续长画布，写成`成品1张 + 内部若干个模块/分镜`，明确阅读方向、模块顺序、衔接锚点与合成方式。实际模块数只来自当前商品有依据且互不重复的具体买家任务，不套通用长页张数或条件式占位模块。每个模块只解决一个问题，不能让“一张详情页”同时指长页、单个模块和一条含糊提示词。
- 用最少页面形成连续决策路径：首屏承接商品识别，随后解释核心利益、证据、真实场景、选择或使用，最后处理必要顾虑。
- 让每屏只完成一个任务，并让上一屏的问题自然引出下一屏；没有新增信息的页面合并或删除。
- 把结构、材质、步骤、参数、认证和对比放在最能证明它们的画面中；没有来源时改为可观察表达或删除。
- 用真实尺度、接触、重力、遮挡和光影关系建立可信场景，不用华丽氛围代替证据。
- 页数服从商品复杂度、SKU关系、证据数量和买错风险，不因“详情页”名称默认做成长页。
- 数字权益或服务优先解释真实体验、交付/激活或预约路径、版本差异、有效期、退款/取消/续费和异常处理边界；真实界面与条款用证据像素或后期排版，不让模型补造。

## 海报

解决“在一个明确时点或主题下，商品要留下什么记忆并引导什么行动”。

- 每张只保留一个传播主题、一个主要情绪和一个商品利益，让商品仍是视觉主体。
- 根据真实人群、场景、节日、活动或渠道语境选择画面；没有活动与权益依据时，不生成价格、折扣、赠品或倒计时。
- 用强构图、色彩节奏、空间层次和文字安全区建立记忆点，不牺牲商品识别、颜色和材质真实性。
- 需要多张海报时，让每张承担不同主题或真实场景；纯换色和换口号不算新任务。
- 不把海报扩张成商品百科，也不让氛围元素暗示不存在的功效、身份或生活方式承诺。

## 白底图

解决“获得清楚、标准、易审核和易复用的商品基础图”。

- 使用可靠机位完整呈现商品，保护轮廓、比例、颜色、材质、标志、配件和数量。
- 使用干净白底、受控接触阴影和清晰边缘；不要加入场景道具、宣传文字或无依据装饰。
- 根据商品透明、反光、毛绒、镂空和细小边缘特征安排抠图与后期，不用过度锐化伪造材质。
- 背面、底部、内部和拆解没有直接同款资料时，只有独立置信度超过80分且已由用户用序列号确认的目标视图，才可进入写实分镜。未确认视图不得写实补画。
- 展开、开合、组合或其他状态必须有对应参考图或用户确认的真实资料，不纳入隐藏视图置信度放行规则。

## 透明图（透明背景图）

解决“获得可跨版式、跨背景和跨渠道复用的商品图层”。

- 把交付目标明确为真实透明通道；棋盘格、白底图和待抠底稿都不能冒充透明成品。
- 保留半透明、玻璃、纱网、毛发、柔边、镂空和反射区域的正确边缘关系。
- 明确是否保留独立阴影；需要阴影时让阴影可单独编辑，不把背景颜色污染商品边缘。

## 无字场景图

解决“获得可二次排版、可跨渠道复用的真实使用场景底图”。

- 让商品在具体空间中保持合理尺度、接触、握持、穿戴、安装、遮挡和光影。
- 不生成宣传标题、价格、参数和促销文字；商品本身真实存在的品牌与包装原文仍按参考图保留。
- 为后期排版预留干净区域，但不要用无意义空台、随机人物或与商品无关的豪华布景制造留白。
- 选择能解释使用、尺度、收纳、搭配或情绪时刻的场景；没有新增任务的场景图不要加入图组。
- 人物不是必需时优先用商品、空间和使用痕迹讲清任务；需要人物时确保动作安全、物理关系可信且不遮挡关键结构。

## 组织跨对象关系

- 用白底图或透明图建立可复用商品底座，再按真实需要延展主图、海报和无字场景；不要因此自动生成全部对象。
- 让主图负责入口，SKU图负责选择，详情页负责解释与证明，海报负责单一主题，基础素材图负责复用。
- 同一事实只在最合适的对象中重点表达；其他对象需要引用时缩减为辅助信息，避免全组重复。
- 最终只使用分镜模板已有字段：对象写入`输出对象`，AI自主决定的位置、视觉尺度、留白、裁切与安全区写入`画布与布局`，唯一任务写入`成图任务`，其余内容分别归入同名字段、`视角与事实边界`、`生产与后期`或`动态负面提示词`；不要新增公开字段。
- 需求预判时自动隐藏与商品形态无关的资产：数字权益或服务通常不推荐白底/透明商品图，除非确有可复用的真实图标、界面卡片或视觉载体且交付目标清楚。
