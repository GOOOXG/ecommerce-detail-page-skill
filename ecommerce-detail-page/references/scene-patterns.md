# 图型矩阵系统

本文件只负责图型选择和输出对象图型偏好。不写具体主图、SKU、海报、素材图或详情页场景。

## 图型矩阵

命中场景后，从下列图型中选择最适合的表达，不机械套模板。图型服务于输出对象、卖点和素材质量：

| 图型 | 适用对象 | 适合任务 |
|---|---|---|
| 白底/浅底产品图 | 主图、素材图、SKU图 | 平台货架识别、主体保真、基础展示 |
| 核心卖点图 | 主图、详情页 | 一图讲清一个利益点 |
| 单卖点证明图 | 主图、详情页 | 参数、结构、材质、实测或对比证明 |
| 材质微距图 | 主图、详情页、素材图 | 放大质感、工艺、滤网、接口、面料、涂层 |
| 生活场景图 | 主图、海报、详情页、素材图 | 使用想象、场景信任、生活方式 |
| 人物/手持展示图 | 主图、SKU图、海报、详情页 | 通过手部、局部、半身、全身、人像或第一视角表达尺寸感、人群适配、真实操作和情绪代入 |
| 多场景拼图 | 主图、详情页 | 扩展使用边界，适合低风险多场景商品 |
| 三角度/多角度图 | SKU图、素材图、详情页 | 正面、侧面、背面、俯视等结构说明 |
| 包装/开箱图 | 海报、详情页、素材图 | 礼赠、套装、到手体验、品牌完整度 |
| 信息图/参数图 | SKU图、详情页 | 尺寸、规格、安装、适配、步骤和证据 |
| 结构拆解图 | 主图、详情页 | 过滤、机械、家电、数码、多层材质和核心机制 |
| 前后对比图 | 主图、详情页、海报 | 只在事实可验证且合规时使用，不能制造虚假效果 |
| 直播/信息流图 | 主图、海报 | 前三秒理解、强主体、单一信息焦点 |
| UGC真实感图 | 海报、详情页 | 小红书、私域、真实反馈和低广告感 |
| 杂志编辑图 | 海报、详情页 | 高客单、礼赠、美妆、服饰和品牌气质 |
| 高级氛围图 | 海报、详情页 | 高端、礼赠、珠宝、美妆、生活方式溢价 |

## 核心主体系统

核心主体决定画面第一视觉层。每张图只设置一个主主体系统，辅助主体不得抢焦点。

| 系统 | 主体表达 | 优先任务 |
|---|---|---|
| 产品静物 | 摆拍、平铺、悬浮、堆叠、单体英雄视角 | 全品类主图、SKU图、细节和素材图 |
| 人物使用 | 手部、局部、半身、全身、人像、第一视角 | 使用证明、尺度、上身、情绪与人群代入；细则读 `visual-people.md` |
| 宠物互动 | 宠物与用品的真实、安全关系 | 宠物用品尺寸、使用、陪伴和场景 |
| 美食饮品 | 摆盘、质地、食材、制作与食用瞬间 | 食品饮料食欲、口感联想和场景 |
| 植物花艺 | 绿植、鲜花、枝叶和自然构图 | 家居、美妆、食品的自然辅助；非植物商品通常只作配角 |
| 局部人体 | 手、脸、颈、脚等与产品直接相关部位 | 珠宝、鞋履、美妆、护肤、工具和配件 |
| 美妆质地 | 膏体、粉质、精华、试色、拉丝和微观纹理 | 美妆质地与上脸/上肤前的感官表达 |
| 服饰平铺/挂拍 | 平铺、挂拍、叠拍、版型与细节 | 服饰SKU、颜色、面料和版型基础展示 |
| 3C数码产品 | 结构、接口、金属、屏幕、光影轮廓 | 数码家电主图、参数、结构和生态 |
| 虚拟数字产品 | 界面、权益卡、流程、数字图标和服务场景 | 会员、课程、软件、数字权益和虚拟商品 |
| 文创文具 | 纸张、印刷、装帧、书写与桌面搭配 | 文具、纸品、出版和文创周边 |

主体选择必须检查：是否与商品身份一致、能否证明本张命题、参考图能否保真、是否需要人物/宠物安全、是否涉及IP授权、是否会遮挡品牌与关键结构。

## 图型选择规则

- 主图优先：白底/浅底产品图、核心卖点图、材质微距图、结构拆解图、生活场景图、直播/信息流图、独立投放变体图。
- SKU图优先：多角度图、SKU总览图、规格参数图、套装组合图、适配防错图。
- 海报优先：品牌氛围图、杂志编辑图、高级氛围图、直播/信息流图、UGC真实感图、节日礼赠图。
- 产品素材图优先：白底图、透明图、无字生活场景图、材质微距图、多角度图。
- 详情页优先：首屏氛围图、痛点场景图、单卖点证明图、结构拆解图、信息图、生活场景图、信任证据图、顾虑兜底图。

当用户说“主图”“SKU图”“海报”“详情页”“素材图”时，先命中对应输出对象，再只调用该对象相关图型；只有用户要求全部设计时才跨对象组合。

## 输出接口

交给场景工作包和最终分镜的图型结论必须包含：

- 图型名称。
- 适用输出对象。
- 图型依据：为什么该图型适合当前商品和任务。
- 视觉承载：主体、卖点、证据、参数、场景或情绪。
- 风险边界：是否需要事实证明、是否禁止文字、是否可能误导。
