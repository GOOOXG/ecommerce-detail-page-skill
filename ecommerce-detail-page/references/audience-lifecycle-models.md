# 人群资产与生命周期系统

本文件只负责人群细分、画像、人群资产、会员、社群、生命周期、复购和流失经营。不写平台经营细则或最终分镜模板。

## 人群细分

| 方法 | 适配 | 页面动作 |
|---|---|---|
| 人口统计细分 | 年龄、性别、收入、地域明显 | 文案语气、人物和场景要对应 |
| 地理细分 | 气候、城市级别、商圈差异 | 场景道具、气候、空间和配送承诺要匹配 |
| 心理细分 | 价值观、生活方式、态度 | 情绪价值和身份表达前置 |
| 行为细分 | 频次、客单、品类、活跃度 | 新客、老客、复购客看到不同利益 |
| 场景细分 | 送礼、通勤、露营、熬夜等 | 一屏一个高频场景，降低代入成本 |
| JTBD细分 | 用户要完成的任务 | 把功能转成任务完成结果 |
| 价值细分 | 高中低价值客户 | 高价值客户重服务和稀缺，低价值客户重门槛 |
| 圈层细分 | 二次元、户外、潮玩、健身、国风 | 使用圈层符号和语言，但不过度堆黑话 |

## 人群资产模型

| 模型 | 适配 | 页面动作 |
|---|---|---|
| Persona | 典型人群明确 | 输出用户卡式策略，不写进最终分镜 |
| 同理心地图 | 需要共情痛点 | 将“所想所说所做所感”转成痛点页 |
| AIPL / 5A / O-5A / 4A | 平台人群资产 | 不同素材对应认知、兴趣、行动、忠诚或拥护阶段 |
| FAST | 阿里系人群健康 | 人群总量、转化、高价值、活跃决定素材重点 |
| RFM / RFMTC | 复购和会员 | 新客、老客、高价值、沉睡客采用不同文案和权益 |
| 用户价值矩阵 | 当前价值×潜在价值 | 区分高价值维护和潜力人群教育 |
| Lookalike | 拉新扩展 | 主图/海报要提炼可被相似人群理解的通用利益 |
| 排除人群包 | 投放和私域 | 避免把不适用人群写成适用 |
| ONE-ID / 人群迁移 | 全域经营 | 从认知池到购买池的素材不要断层 |

## 特殊人群经营

| 人群 | 核心策略 | 分镜动作 |
|---|---|---|
| 新客 | 首单补贴、正品体验、二单设计 | 低门槛、强信任、轻行动 |
| 老客 | 会员日、新品优先、积分加速 | 强调专属、升级、补货和回购 |
| 沉睡客 | 权益、内容、时间窗 | 用温和唤醒，不做骚扰感 |
| 高净值/VIP | 1v1顾问、私享活动 | 高级留白、稀缺、服务感 |
| KOC | 真实分享任务和激励 | UGC、原相机、真实体验 |
| 企业福利 | 团购、定制、发票、统一配送 | 规格、服务、流程和合规票据 |
| 学生/校园 | 低价入门、社交裂变 | 性价比和轻社交 |
| 银发 | 大字、服务、信任、子女决策链 | 字大、步骤少、售后清楚 |
| 下沉市场 | 性价比、本地生活、社交信任 | 价格理由、本地信任、简单行动 |
| 跨境本地人群 | 语言、文化、支付差异 | 本地化表达，不只翻译 |

## 会员、社群与关系资产

| 模型 | 用法 | 分镜动作 |
|---|---|---|
| 积分会员 / 等级会员 / 付费会员 | 权益设计 | 只写真实权益，缺失时自动跳过权益组件 |
| 会员生命周期 | 入会、激活、升级、续费、流失 | 尾屏和私域海报承接复购 |
| 会员ROI | 权益成本 vs 增量贡献 | 判断是否强调会员利益 |
| 社群运营漏斗 | 拉群、活跃、信任、成交、裂变 | 私域图突出加入理由和社群价值 |
| 私域四阵地 | 企微、社群、朋友圈、1v1 | 不同素材承接不同触点 |
| 加粉率-开口率-转化率-复购率 | 私域复盘 | 私域海报不要只求加粉，要能开口和成交 |
| 品牌社区UGC飞轮 | 内容社区 | 鼓励真实分享和二次传播 |
| 老带新推荐计划 | 双边奖、阶梯奖、活动奖 | 奖励必须真实，不虚构 |

## 生命周期与复购

| 模型 | 用法 | 分镜动作 |
|---|---|---|
| 用户生命周期五阶段 | 引入、成长、成熟、衰退、流失 | 针对不同阶段输出不同素材 |
| CLV/LTV | 长期价值 | 高频复购品重周期和组合 |
| 首单到二单引擎 | 电商复购关键 | 首单页埋二单理由 |
| 复购周期预测 | 耗材、食品、美妆、宠物 | 用补货提醒、周期装和家庭装 |
| 订阅续订模型 | 订阅品 | 到期提醒、优惠、价值证明 |
| 流失预警 | 活跃下降、投诉、竞品痕迹 | 用售后、替换和权益降低流失 |
| 流失原因树 | 产品、价格、服务、竞品、场景消失 | 判断是改卖点、价格还是服务 |
| 挽回策略树 | 券、礼物、人工、产品替换 | 只使用真实权益 |
| NPS分层 | 推荐者、被动者、贬损者 | 评价页和UGC素材要区分语气 |
| 服务补救悖论 | 售后修复 | 尾页可坦诚说明保障和补救 |

## 输出接口

- 目标人群。
- 人群阶段。
- 人群资产模型。
- 会员或复购策略。
- 主要购买防御。
- 页面动作。
- 已确认权益或服务；没有准确值时删除本项。
