# 证据、目标与结果反馈

本文件把第一性原理落到分镜决策中：先明确要改善哪一个买家结果，再把每个可见主张绑定到证据、授权范围和生产方式，最后用生成结果与用户反馈修正下一次首推。它只供内部推演和对话确认使用，不新增公开报告、合同或状态机。

## 一、先定义要优化的结果

在商品卡确认后、正式规划图组前，先确定一个本组首要目标，最多保留两个次要目标，并写出不能牺牲的护栏。目标必须能落到图片任务，而不是泛泛地说“做得高级”或“提高转化”。

可用的首要目标包括：

- 首屏快速认出品类和目标商品；
- 降低 SKU、尺码、容量、接口或套装误购；
- 证明一个已经有依据的卖点或使用关系；
- 解除安装、清洁、收纳、交付或售后顾虑；
- 建立质感、信任或品牌记忆；
- 提高合格点击、加购或详情页继续阅读意愿。

优先级按以下顺序裁决冲突：商品事实与安全/合法性 → 用户本轮明确要求 → 首要目标 → 次要目标 → 视觉偏好。用户没有给出首要目标时，依据输出位置、商品决策特征和原始意向做一个首推；只有这个假设会改变图组时才向用户说明。

不要把点击、成交、品牌溢价、降低退货同时当作同一优先级。它们可以共同考虑，但每一组图必须有一个主目标，否则无法判断候选是否真的更好。

## 二、建立轻量主张账本

对会进入商品卡、文案、画面或提示词的每个重要主张，内部记录以下字段：

| 字段 | 记录内容 |
|---|---|
| 主张 | 例如“杯盖有可见开合连接”或“权益有效期为30天” |
| 来源 | 参考视觉、用户声明、当前官方资料或策略推断 |
| 具体证据 | 图片中可见的区域、原文、界面状态或资料段落 |
| 状态 | 可观察事实、用户确认事实、外部可核验事实、推断、未知/禁止 |
| 可用范围 | 可写入商品身份、可用于本张画面、只能作风格灵感或不可使用 |
| 不可推导 | 不能由该证据推出的参数、功能、功效、认证、适配或安全结论 |
| 时效与风险 | 是否会变化，以及低、中、高风险等级 |

“可观察事实”不自动等于“功能事实”；“用户声明”可以作为本次创作资料，但健康、安全、性能、认证、价格和促销主张仍需要相应直接资料或当前可核验来源。策略推断只能决定怎样画，不能升级商品事实。

多张参考视觉先合并同款证据，再处理冲突。一个局部证据只能补充对应局部，不能改写整体比例或 SKU。发现上游主张来源不明时，删除主张或退回补证，不用更长的提示词掩盖缺口。

## 三、区分确认权限

每次用户确认只授予明确范围，不把不同确认合并解释：

| 用户确认 | 允许做什么 | 不代表什么 |
|---|---|---|
| 商品卡 | 锁定本轮商品、SKU/版本和用户接受的事实摘要 | 不自动确认所有卖点、未知视图或分镜方案 |
| 写实视图序列号 | 允许该隐藏视图作为本次画面目标 | 不证明结构、功能、性能、参数或安全主张 |
| 输出范围 | 确定对象、成品/分镜数量、平台、用途和 SKU 映射 | 不确认具体构图或文案 |
| 结构/方向 | 确定图组关系和视觉取舍 | 不新增商品事实 |
| 单张分镜 | 确认该张任务、画面和生产路径 | 不确认其他分镜或生图数量 |
| 生图选择 | 授权指定分镜和候选数量调用工具 | 不授权修改已确认商品事实 |

在需要用户回复时，用一句中文说明“本次确认授权什么，不授权什么”。裸“继续”不能跨越尚未显示的确认对象；明确直出只能压缩停顿，不能静默确认未知事实。

## 四、按风险决定证据门槛

- **低风险**：背景、光影、构图、道具和情绪氛围。允许较大创意空间，但不能遮挡或误导商品。
- **中风险**：尺寸参照、收纳容量、包装清单、安装关系、适配、SKU差异和到手内容。要求对应参考图、用户资料或可靠生产依据。
- **高风险**：健康/功效、安全、承重、防护、性能测试、认证、兼容承诺、价格促销、金融权益和个人信息。没有直接资料时删除主张、补充资料或停在概念表达；80分和用户确认都不能替代证据。

隐藏背面、底部、内部和拆解仍按既定“严格超过80分并由序列号确认”规则处理，但只允许进入本次画面目标，不得承载高风险主张。正式分镜不显示分数、推断标签或内部状态。

## 五、前置工具能力画像

在确定图组结构和生产路径前，记录当前执行环境是否支持：多参考图、图生图/编辑、局部遮罩、真实透明通道、精确画布比例、独立负面提示词、分层或后期合成、批量候选、真实文字/界面层保留和结果回溯。

能力未知时采用保守路径：真实商品/界面层优先，模型负责背景与环境；多 SKU 分别生成或后期合成；精确文字、二维码和长参数由证据层或排版完成。工具限制不能悄悄减少证据、改变画面语义或把降级结果说成原方案完成。

## 六、让推演深度自适应

用同一个 `loop`，但根据不确定性、错误代价、候选差异和新增信息价值决定深度：

- 低不确定性、低风险、单一目标：一轮证据观察、反证和收敛即可；只给首推。
- 中等不确定性或多种可行画法：比较1–3个真正改变任务的候选，去掉重复方案。
- 高风险、多 SKU、关键冲突或工具能力不明：增加独立反证或第二轮推演，直到关键冲突解除。
- 只有确实存在多种不同生产或商业取舍时，才比较更多方向；综合方向最多比较5个，五个是内部上限，不是每次必须生成的数量。

当候选没有新增事实、证据、决策帮助或风险降低时停止。不要用循环次数、子智能体数量或候选数量证明思考深度。

## 七、把生成结果纳入反馈

生图后先按最早失败层复核：商品身份与 SKU → 任务是否清楚 → 证据和文字是否真实 → 物理/界面关系 → 缩略图可读性 → 工具与后期是否按分镜执行。只返修受影响字段，不把工具失败误判为用户偏好。

记录用户明确采用、否定、纠正和返修的原因；沉默、候选数量和工具失败不升级为偏好。若用户提供点击、加购、成交、停留、退货或客服疑问等结果，只把它们作为该商品、平台和任务范围内的反馈，不直接推广成通用规则。

偏好更新必须保留适用范围、来源、确认次数、最近一次验证和撤销方式。跨任务保存需用户明确授权；没有私有记忆能力时只在本轮有效，不声称已经长期学习。
