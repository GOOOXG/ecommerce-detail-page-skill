# 图生图分镜交付模板

本文件只定义最终中文Markdown分镜格式。内容必须来自已完成的商品图推理、图组编排和提示词编译，不在最终阶段重新发明策略或改写已确认内容。

## 输出边界

- 最终核心交付是逐张图生图分镜提示词。
- 用户只要求一种对象时只输出该对象；多对象分组输出，每组从第1张重新编号。
- 完整组使用真实连续数字；局部返修保留原编号。
- 外层使用四个反引号加`markdown`，内层提示词使用三个反引号加`text`。
- 空字段、未采用候选、自动跳过内容、内部模型、评分、状态、菜单、测试和解释全部删除。
- 最终源码块不得附带独立的商品分析、商业/运营/营销报告、多智能体意见或A/B测试建议；这些内容只作内部推演。仅当关键素材边界会阻止执行时，可在源码块外用一句话说明。
- 每张必须消费已`RELEASED`的分镜槽位合同并写`画布与槽位`；比例/像素尺寸只在用户指定或系统已采用时写入，未知尺寸子项删除，产品锚点/占比/裁切和实际需要的文案/品牌/证据安全区仍须保留。提示词正文不重复画布数值。
- 每组源码块先写紧凑`参考图索引`，绑定编号与附件名或上传轮次+原始序号；只列本组实际使用的图片。

## 单张正式模板

````markdown
### 参考图索引
- 参考图1：【附件名或第1轮上传第1张｜目标SKU/状态｜身份母图】
- 参考图3：【附件名或第1轮上传第3张｜目标SKU/状态｜材质/文字辅图】

## 第1张：【最终成图名称】
- 输出对象：【主图 / SKU图 / 海报 / 产品素材图 / 详情页】
- 成图任务：【为什么要做这张图；唯一任务与准确卖点】
- 图组角色：【首图 / 承接 / 证明 / 场景 / 选型 / 收口 / 独立变体；不需要时删除】
- 画布与槽位：【已确定时写比例/尺寸；始终写产品锚点与占比、裁切边界、实际启用的文案/品牌/证据安全区和平台适配】
- 身份母图：【参考图编号｜锁定哪个商品/SKU/状态】
- 主参考图：【参考图编号｜本张用于定义视角与可见几何】
- 辅参考图：【参考图编号｜分别补充角度、材质、文字、包装、配件或交互；没有则删除】
- 产品锁定：【外轮廓、比例、结构、部件、颜色、可见材质表面、LOGO/原文、包装、配件等本张不可改变项】
- 允许变化：【可清除/重建的原图区域，以及可生成的背景、人物、道具、光影、摆放和留白】
- 视角与事实边界：【可用视角、禁止暴露的未知面、不能生成的内部/配件/适配/效果】
- 最终画面：【商品、空间、道具、人物、真实关系、唯一视觉焦点与信息层级】
- 镜头与构图：【角度、景别、焦段感、主体位置与占比、透视、焦点、动线、前中后景、裁切和文字安全区】
- 场景与人物：【空间、人物景别、动作、产品接触、尺度、遮挡与安全；无人画面删除】
- 光影、材质与色彩：【主辅光、反射、轮廓、阴影、表面纹理、主辅强调色和商品真实颜色保护】
- 最终上图文案：【只写有依据且实际采用的短文案；无字/白底/透明图删除】
- 生产与后期：【图生图锁定 / 真实商品抠图合成 / 局部重绘 / 3D；AI负责范围、后期负责范围、精确文字与修图要求】
- 🎨 图生图提示词：
```text
【完整、单义、可直接执行的中文图生图提示词】
```
- ⚠️ 动态负面提示词：
```text
【只包含当前图相关的产品、视角、场景、人物、文字、事实与质量排雷项】
```
````

## 字段规则

- `身份母图`与`主参考图`必须存在；只有同一张图同时可靠定义身份和视角时，才可使用同一编号。若没有任何有效参考图，不能输出商用图生图分镜。
- `辅参考图`只写实际使用的图片，不为显示专业而罗列全部上传图。
- `产品锁定`必须具体到当前商品视觉DNA，不能只写“保持一致”。
- `允许变化`必须区分原图可重建区域与新增生成内容。
- `视角与事实边界`必须说明参考图能力，防止模型补画未知结构。
- `最终画面`写成成品，不写候选、建议、可能、尝试等措辞。
- `生产与后期`明确模型和后期分工；精确长文字、LOGO和包装优先真实层/后期。
- 白底、透明和无字场景图删除新增文案；保留商品原有真实文字。
- 无人物时删除人物字段，不写“无人物”。
- 没有已`RELEASED`的分镜槽位合同时阻塞提示词编译与最终交付，不能删除整个字段绕过；仅删除未知比例/尺寸子项。无字图不保留空文案槽，但仍保留产品锚点、占比与裁切边界。

## 图组规则

- 递进结构：每张新增任务，前后承接但提示词只写本张执行内容。
- 并列结构：每张独立成立且改变一个有业务意义的主变量，不能只换背景颜色。
- 混合结构：明确主链与独立变体；共享商品、品牌和视觉不变量。
- 同组主参考图可不同，但视觉DNA与商品身份必须一致。
- 删除任一张不会破坏主任务时，应考虑合并或删除；不为固定张数凑图。

## 聚合规则

- 单图确认模式从发布库中的当前 FR/PR 配对无损映射；直出/全自动模式先完成内部红队再聚合。
- 最终模板不得静默改变商品事实、参考图、产品锁定、最终画面、文案或提示词。
- 局部返修只输出点名图片，除非用户要求重发整组。
- 源码块外默认只保留一句交付说明与必要返修入口；只有会阻止执行的商品图/素材限制才可简短说明。不输出商品分析报告、多智能体报告、运营/营销报告、测试方案或完整推理链。
