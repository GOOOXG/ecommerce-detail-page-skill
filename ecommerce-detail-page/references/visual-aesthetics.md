# 视觉美学系统

本文件只负责美学定调、风格调性、视觉进化、平台视觉心智和5种美学方案。不写背景空间细则、字体授权、视图角度或最终分镜模板。

## 五维定调

1. 物理视觉：形态、比例、材质、光影、色彩。
2. 买家心理：真实渴望、最大顾虑、情绪价值。
3. 视觉锤：最值得放大的局部、结构、材质或动作。
4. 场景氛围：最能提升身价的空间、道具和人群状态。
5. 页面节奏：首屏、痛点、卖点、场景、证据、兜底。

## 视觉进化算法

视觉方案必须经历“识别、放大、取舍、统一、压缩”五步：

1. 识别：从产品形态、材质、颜色、使用方式中找最强视觉资产。
2. 放大：把最能代表卖点的局部、动作或场景放成视觉锤。
3. 取舍：每张图只保留一个主视觉任务，弱化无关装饰和多余标签。
4. 统一：全套保持光影、字体、标签、道具等级和背景语气一致。
5. 压缩：最终分镜只写必要构图、风格和提示词，不解释完整理论。

## 美学推演矩阵

自动定调时至少内部比较以下维度，再输出5种方案：

| 维度 | 低风险选择 | 差异化选择 | 判断依据 |
|---|---|---|---|
| 光影 | 柔光、自然光、均匀布光 | 硬光、轮廓光、局部高反差 | 材质、价格带、平台 |
| 色彩 | 低饱和、同类色、白灰背景 | 高对比、撞色、深色背景 | 品类心智、点击需求 |
| 构图 | 居中、三分、黄金分割 | 斜切、局部超近景、分层透视 | 主图/详情/海报任务 |
| 密度 | 留白、少字、强主体 | 高信息密度、促销标签 | 客单价和平台 |
| 质感 | 实拍、自然道具、真实环境 | 超现实、悬浮、微观、结构分解 | 产品结构和卖点 |

## 视觉与营销联动

- 首屏截停对应：强主体、强对比、少字、明确视觉锤。
- 痛点递进对应：问题画面、旧方案对比、隐形问题可视化。
- 感官转译对应：微距、流体、结构分解、动作定格。
- 合规信任对应：有准确依据时使用证据平铺、真实报告、实测过程和边界说明；依据不足时删除该组件。
- 价值解释对应：生命周期图、套装对比、使用步骤和成本可视化。
- 顾虑兜底对应：仅使用准确参数、选型关系、适配范围和售后政策；无准确值时切换到不依赖该字段的真实顾虑表达。

## 商品物理特征到美学

- 看形态定构图：圆形、长条、扁平、瓶罐、盒装、零件、软材、硬壳分别选择不同主体占比和视角。
- 看材质定光影：吸光材质用柔光，反光材质用硬光和轮廓光，透明材质用逆光，金属材质用高光边缘。
- 看色彩定基调：低饱和偏高级，高对比偏科技和促销，暖色偏温情和食欲，冷色偏专业和洁净。
- 看价格带定道具：高客单用同级道具和留白，低客单用清晰利益点和紧凑信息。
- 看使用场景定氛围：只决定冷暖、明暗、密度和情绪；具体厨房、浴室、桌面、户外、车内、办公室、礼赠等空间读取 `visual-spaces.md`。

## 5种美学方案

进入需要用户单独返修美学定调的节点时给5种：1到3为建议方案，4到5为视觉差异化方案。每种包含名称、适配理由、关键词、字体、色彩比例、光影、排版密度、适合页面、风险提醒。初次设计时把美学方向嵌入 `reasoning-engine.md` 的5个综合方案，不再额外弹出一轮同义选择；全自动、直出和通版只在内部比较并采用首推。

排序规则：

1. 最稳妥的转化方案。
2. 最适合平台的方案。
3. 最符合价格带的方案。
4. 视觉差异化方案。
5. 品牌/情绪差异化方案。

## 自动风格判断

- 科技/家电/数码：冷静、清晰、硬光、结构感、参数可视化。
- 家居/生活方式：低饱和、柔光、空间感、材质和秩序。
- 美妆/个护：干净、细腻、肌理、成分可视化、肤感表达。
- 食品/饮料：食欲、产地、开袋、真实光泽和口感联想。
- 服饰/鞋包：上身、版型、面料、搭配和人群氛围。
- 母婴/宠物：安全、温和、真实互动、比例关系和边界说明。
- 工具/工业/办公：专业、耐用、参数、工况和步骤清晰。
- 礼品/珠宝：高级留白、精致光影、开箱仪式和体面感。

## 风格调性系统库

风格只决定情绪、材质语言和审美，不替代商品事实、品牌VI或页面任务。每个方案选择一个主风格；节日与品牌VI作为覆盖层。

| 系统 | 视觉语言 | 优先品类/任务 | 风险控制 |
|---|---|---|---|
| 古风传统 | 传统书画、古典器物、历史感留白 | 文化、非遗、茶酒、传统礼赠 | 不拼贴无关朝代符号，不伪造文化来源 |
| 国潮新中式 | 东方纹样、书法/水墨语汇与现代网格、年轻撞色 | 食品、美妆、服饰、文创、活动 | 控制符号密度，字体必须可商用，避免廉价国潮模板 |
| 现代简约 | 留白、低饱和、清晰网格、弱装饰、强产品 | 3C、家居、家电、轻奢美妆 | 避免空泛和主体过小，保留一个视觉锤 |
| 北欧INS风 | 莫兰迪色、自然肌理、柔和日光、松弛家居 | 家居、服饰、宠物、小众美妆 | 道具和空间要真实，不把低对比做成灰脏 |
| 日系治愈 | 清新暖调、生活烟火、柔光、轻手作感 | 食品、母婴、文具、日用品 | 不滥用幼态元素，食品与母婴保持真实安全 |
| 科技赛博 | 深色基底、霓虹边缘、金属、未来线条 | 3C、电竞、潮玩、汽车用品 | 产品颜色不被光效改写，避免界面和光线过载 |
| 复古怀旧 | 港风、美式、民国、胶片颗粒和年代配色 | 服饰、食品、文创、复古美妆 | 年代语汇保持一致，不用颗粒掩盖产品细节 |
| 轻奢高端 | 克制低对比、金属/石材、精致光影、大留白 | 珠宝、高端家居、美妆、礼赠 | 不靠金色堆砌，不让道具贵过产品 |
| 可爱萌系/马卡龙 | 明亮马卡龙、圆润形态、轻量卡通语言 | 母婴、宠物、零食、文具、潮玩 | 注意可读性和年龄适配，不使用未授权角色 |
| 暗黑酷感 | 黑灰、硬光、强明暗、硬朗结构 | 男装、户外、电竞、五金工具 | 暗部保留产品结构，避免危险和攻击性误导 |
| 市井烟火 | 原生生活、亲民色彩、真实摊铺与使用痕迹 | 生鲜、农产品、零食、百货 | 真实但不脏乱，不伪造产地、摊位或人情背书 |
| 酸性潮酷 | 高饱和撞色、先锋几何、实验排版 | 潮牌、潮玩、潮流美妆、音乐周边 | 精确文字后期排版，避免影响商品识别 |
| 二次元动漫 | 原创或授权动漫、卡通、游戏视觉语言 | 动漫周边、游戏、潮玩、二次元服饰 | 禁止仿冒受保护IP和角色，不虚构联名 |
| 工业质感 | 水泥、金属、粗粝肌理、结构与工况感 | 工业用品、五金、露营、潮牌男装 | 专业不等于脏旧，参数和工况必须真实 |

### 覆盖层

- 节日节气：春节、618、双11、中秋、圣诞等只在用户给出节点或活动目的时启用；装饰、促销与日期事实必须一致。
- 品牌VI：品牌色、字体、LOGO安全区、图形资产和组件规范优先于风格库；没有VI时由AI建立临时活动视觉不变量，不伪造品牌规范。

## 风格选择算法

内部比较商品材质、目标人群、价格带、平台心智、页面任务、品牌资产、场景真实性和生产可行性。先剔除会降低产品识别、与品牌冲突、需要未授权IP或无法生产的风格，再进入5个综合方案。不得为了差异化同时混用多个主风格；跨风格只允许一个明确辅助语汇并说明用途。

## 平台视觉心智

- 淘宝/天猫：主体识别、卖点清楚、风格统一，详情页前3屏承接主图利益点。
- 京东：参数、结构、质量、服务和安装边界优先，视觉更克制专业。
- 拼多多：利益点和套装价值更直接，但不得编造价格、优惠或赠品。
- 抖音/快手：前三秒理解、强主体、强情绪钩子、直播/信息流入口清楚。
- 小红书：低广告感、真实场景、审美种草、少字和生活方式语气。
- 私域：信任、复购、礼赠、会员和关系表达更重要，画面可更温和。
- 跨境平台：主体清晰、白底和低文字密度优先，避免中文密集堆叠。
