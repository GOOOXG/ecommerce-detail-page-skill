# 商品与参考图判断

只回答三个问题：这是什么商品，哪些参考图能证明什么，哪些画面能够真实制作。必须实际查看每张可访问参考图；低清、严重遮挡、损坏或无法读取的图片不能作为商品依据。没有可访问的商品图时停止图生图分镜并请用户上传；只有用户明确同意时，才降级为不保证商品还原的文生图概念稿。

## 内部证据追踪

1. 可以按附件到达顺序在内部临时编号，用于识别错误纠正、冲突定位和用户指代；编号不进入正式分镜。
2. 为每张图片记录可见附件名、上传轮次或原始顺序。不要猜测缺失信息。
3. 保留重复图、排除图和被替换图的内部位置，新图只追加，避免纠错时指向错误图片。
4. 同时记录每张图对应的商品、SKU、颜色、型号、容量、开合状态、包装版本、配件组合和拍摄视角。无法确认时明确写“未知”，不要强行归组。
5. 正式分镜不输出参考图索引或固定参考图编号，只说明当前画面怎样综合使用一张、多张或全部有效参考图。

## 锁定商品、SKU与状态

1. 先识别品类、商品名称、品牌、型号、数量、套装关系和可见用途，再区分不同SKU与状态。
2. 把颜色、容量、尺寸、包装、配件、开合、安装和使用状态分别核对；不要把多个版本平均成一个虚构商品。
3. 每张待制作图片只指定一个主体SKU与状态。SKU总览可以并列展示多个真实选项，但不能融合颜色、部件、包装或配件。
4. 用户指定SKU后，把其他SKU视为防串款反例；只有确认结构和材质完全相同时，才允许借用相应局部依据。
5. 图片与文字在型号、数量、套装、适配或关键规格上冲突，且可能导致买错时，停止下游设计，只问一个能够解除冲突的问题。

## 提取可见商品特征

从有效参考图中提取可复核的共享特征，并为每个SKU或状态记录差异：

- 锁定轮廓、长宽高关系、重心、部件数量、连接方式和可见几何。
- 锁定可观察的表面表现，如哑光、高光、透明、半透明、金属反射、织物纹理或细粗纹；没有资料时不要把表面观感升级为具体材质名称。
- 锁定主体色、辅色、透明区、金属色、不可改色区域和可能受白平衡影响的颜色。
- 锁定品牌标志、型号、包装文字、标签位置、真实配件和数量关系。
- 记录能可靠判断的尺度、握持、穿戴、安装和接触关系；没有比例依据时不要制造精确尺寸感。

为每个锚点指出来源参考图和具体区域，并标记可信程度与冲突。优先保留多图一致且清晰的特征；不要用行业常识补齐图片没有展示的结构。

## 综合全部有效参考图

先完整读取所有有效图片，再为每个SKU/状态建立统一证据集合：

- 汇总多图一致的商品身份、轮廓、结构、颜色、可观察表面、文字、包装、配件、尺度和状态。
- 把清晰局部用于补充细节，把完整视角用于约束整体几何；局部证据不得改写整体比例或SKU。
- 把场景图中的空间、光线、人物和氛围作为视觉候选，不让它覆盖真实商品外观。
- 把低清、严重遮挡、错误SKU、失真、重复或来源不明的图片标为排除证据，并记录原因。
- 先从全部图片深度提炼可证实卖点、购买顾虑、使用情境和文案方向，再把缺少参数、功效或认证依据的表达列为待补证，不能直接采用。

每张分镜再按任务动态采用一张、多张或全部有效参考图。先按当前目标SKU/状态筛选，同SKU多图可以互补，其他SKU只用于已确认差异、组合关系和防串款。发生冲突时依次保护商品身份、目标SKU、可见几何、颜色材质、文字包装和局部补充；无法解除时回到商品卡询问，不平均或融合冲突内容。

## 区分事实、观察与推断

- 把用户明确提供且不与可靠图片冲突的资料记为“已确认事实”。
- 把图片中可直接看见的轮廓、颜色、表面、文字、数量和位置记为“可观察内容”。
- 把人群、使用情境、购买阻力、视觉表达和构图选择记为“策略推断”，只用来决定怎样画，不得改写参数、功效、适配或认证。
- 把缺少来源、彼此冲突或需要猜测的内容记为“待验证或禁用”，从正式画面和文案中删除。

用户对真实商品事实的纠正可以更新判断；用户要求概念改色、改款或创意变形时，只把它记录为本次允许变化，不要反向改写真实SKU。

## 保护未知面与精确文字

1. 用户已经提供可确认的同SKU真实背面、底部、内部或拆解图片时，对应目标直接作为证据使用，不评分、不进入序列号确认；仍需核对SKU、状态与其他资料冲突。
2. 缺少目标视图的同SKU直接资料时，背面、底部、内部和拆解分别判断还原置信度；只有超过80分的目标才列入“写实视图确认”清单，用户用序列号确认后才允许进入写实分镜。置信度不超过80分的目标不列入清单，改用可靠角度、真实商品像素合成、补拍、三维资料或明确概念稿；不能用一个总分一次放开所有未知结构。
3. 多角度照片不等于精确三维模型；禁止镜像替代真实另一侧，也不能把品类常识当作同款结构证据。
4. 复杂标志、型号、参数表和包装长文字优先保留真实像素或后期排版；图像模型只负责商品之外的空间、光影和文字安全区。

主体识别、AI预构建、编号选择、商品卡和逐目标置信度的完整交互规则，统一读取 [prebuild-and-product-card.md](prebuild-and-product-card.md)，本文件不重复定义第二套确认流程。

## 交给图组推演

只交付必要摘要：目标商品与SKU或状态、全部有效参考内容的综合结论、逐张动态参考图使用方式、可见商品特征、不可改变项、允许变化、目标视图的直接证据状态或缺失目标置信度、写实视图确认结果、事实边界、可靠生产方式和唯一未解除风险。商品卡确认前不进入正式分镜。
