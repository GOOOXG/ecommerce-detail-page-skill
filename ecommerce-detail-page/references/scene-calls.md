# 场景调用与基础系统

本文件统一负责场景路由、产品处理模式、跨图视觉不变量、动态场景匹配和场景工作包。图型、空间、生产形式和对象专属规则按需读取对应文件。

## 调用顺序

1. 从已发布范围合同确定对象，不在对象确认前加载专属场景。
2. 选择产品处理模式和当前图任务。
3. 需要图型时读 `scene-patterns.md`；需要具体空间时读 `visual-spaces.md`。
4. 只读取被点名对象的专属文件。
5. 读取 `production-methods.md` 确认生产可行性。
6. 向提示词编译器只交付场景工作包和制作工作包摘要。

## 对象路由

| 输出对象 | 专属文件 | 数量来源 |
|---|---|---|
| 主图 | `scene-main-image.md` | 范围合同中的数量 |
| SKU图 | `scene-sku.md` | 范围合同中的数量 |
| 海报 | `scene-poster.md` | 范围合同中的数量 |
| 产品素材图 | `scene-material.md` | 范围合同中的数量 |
| 详情页 | `scene-detail-page.md` | 用户指定或类目平台系统推演 |

多对象按组调用，共用商品、事实、品牌和活动视觉不变量；不加载未点名对象。主图不读取详情页长链路，SKU图不读取海报传播规则，素材图不读取完整营销系统。

## 产品处理模式

- 严格保真：真实产品抠图、图生图锁定或真实产品合成，只生成背景、光影、道具和排版空间。主图、SKU、白底、透明和品牌商品优先。
- 保真增强：只优化清晰度、光影、摆放和背景，不改变外观、结构、颜色、材质、包装、配件和原文。适合海报与详情场景。
- 概念提案：只用于用户明确要求的方向探索，不得混入正式商用分镜；商用前必须回到真实产品资产。

具体实拍、图生图、背景合成、3D、插画和创意合成规则读取 `production-methods.md`。没有完整多角度或3D资料时，不把未知背面和内部结构生成成真实商品。

## 跨图视觉不变量

同一批输出共享：

- 品牌与活动记忆点。
- 主辅色、基础光源方向、背景材质和道具等级。
- 字体、标签、图标、分割线、参数框和证据组件语言。
- 产品占比基线、阴影、修图质感和后期排版逻辑。

对象职责不同但视觉属于同一店铺：主图负责点击，SKU负责选型，海报负责传播，详情页负责解释和信任，素材图负责复用。独立变体只改变一个有业务意义的主变量，其余组级不变量保持稳定。

## 动态匹配

- 形态：长条偏斜向动线，圆形偏居中/环绕，扁平偏俯拍，零件偏微距/结构，大件偏真实空间。
- 材质：金属用轮廓高光，塑料用干净柔光，玻璃用逆光，织物用侧光微距，滤网/孔洞用局部定向光。
- 卖点：抽象功能只有在事实可证时转为结构、过程、对比或结果；否则删除该功能表达。
- 人群：理性买家看参数与证据，审美买家看质感与场景，谨慎买家看边界与防错。
- 人物：只有能证明操作、尺度、上身、情绪或空间关系时读取 `visual-people.md`；否则保持无人产品画面。
- 平台：货架优先识别与信任，内容流优先快速理解与真实场景，私域优先关系和复购。

## 场景选择

初次设计把场景合并进5个综合方向，不额外弹出同义选择。只有用户要求重选场景、多个真实场景会改变产品使用逻辑，或返修需要时才显示专项场景选择；全自动、直出、通版和连续确认采用方向合同中的场景。

专项选择只给：AI首推、2到4个实质不同方向、自定义入口、选择影响和主要风险。用户可以修改输出对象、张数、平台、人群、卖点、场景、风格、画布和禁止元素；涉及商品事实时先返回商品卡确认，纯场景修改只重算场景及其下游。

## 场景工作包

向下游交付：输出对象、命中场景、图型、产品处理模式、视觉不变量摘要、人物策略、素材槽位、数量来源、生成方式、生产形式、输入资产、AI/后期边界、留白策略、证据组件状态、结构类型和可返修点。不存在的字段删除。
