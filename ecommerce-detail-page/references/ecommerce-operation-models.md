# 电商经营模型系统

本文件只负责电商全链路、平台方法、成交场、投放复盘、指标字典和阶段模型。不写人群生命周期细则、品牌模型或最终分镜模板。

## 电商全链路

| 模型 | 适配 | 页面动作 |
|---|---|---|
| 电商经营北极星体系 | 运营复盘 | 净利润/现金流下拆GMV、毛利、ROI、退货率、复购率 |
| 电商全链路十段 | 全案和详情页 | 选品、供应链、内容、流量、成交、履约、售后、评价、复购、复盘逐段承接 |
| 人货场 | 中国电商通用 | 人群、商品、场景三者必须同屏闭环 |
| 公域-私域-品牌域三域 | 全渠道经营 | 公域素材负责获客，私域素材负责沉淀，品牌素材负责提效 |
| 单品-爆品-品类-品牌四段成长 | 新品到品牌 | 单品验证、爆品放量、品类矩阵、品牌心智分阶段出图 |
| 选品五力 | 新品和多SKU | 需求强度、竞争、供应链、利润、内容表达性决定主推方向 |
| 爆款公式 | 爆品打造 | 高需求、强差异、可传播、高转化、稳供给缺一不可 |
| 货盘金字塔 | 多SKU和套装 | 引流款、利润款、形象款、复购款分工 |
| 价格带卡位 | 多款价格 | 低中高三带明确，避免自相残杀 |
| SKU精简与长尾平衡 | SKU图 | 头部SKU清晰，长尾场景不混乱 |
| 详情页转化信息序 | 详情页 | 痛点、方案、证据、场景、规格、评价、保障、催单 |
| 主图CTR模型 | 主图 | 1秒识别、3秒利益、差异化、可读性和合规性 |
| 信任状组合 | 证据页 | 专利、检测、销量、达人、媒体、售后必须有真实依据 |

## 成交场与话术

| 成交场 | 推荐模型 | 分镜/提示词落地 |
|---|---|---|
| 货架销售 | 搜索词包、主图CTR、USP、FABE | 主图和详情页要快速说明品类、差异和证据 |
| 内容销售 | AISAS、内容循环、叙事运输、小红书笔记漏斗 | 海报和场景图先代入，再给搜索/收藏理由 |
| 直播销售 | GPM、直播漏斗、福利-讲解-倒计时-连单 | 海报突出直播信任、节奏和真实活动依据 |
| 门店/本地 | 到店核销、评价排名、地理便利 | 海报突出位置、场景、评价和核销路径 |
| 顾问销售 | 顾问式销售、价值销售、Gap Selling | 高客单详情页强调诊断、方案、ROI和边界 |
| ToB交易型 | 目录、价格、交期、账期 | SKU图和参数页清楚展示规格、交期和适配 |
| 项目型销售 | 立项、方案、POC、商务、交付 | B端详情页展示流程、案例边界和交付能力 |
| 社交销售 | 私域四阵地、关系链推荐 | 海报和私域图强调身份、信任和轻行动 |

成交技法只作为表达策略：二选一成交、假设成交、价格锚点、LAER异议处理、社会证明、演示三步法、复购提醒脚本均不得制造虚假价格、虚假紧迫或无证据背书。

## 投放与复盘

| 模型 | 用法 | 分镜关联 |
|---|---|---|
| 投放目标分层 | 曝光、点击、加购、成交、ROI、市场份额 | 决定主图/海报到底解决哪个指标 |
| 计划-单元-创意三层 | 投放结构优化 | 一个卖点可生成多个创意方向 |
| 人群包策略 | 核心、相似、排除、再营销 | 不同人群用不同主张 |
| 素材工厂 | 卖点标签化+批量测试 | 同一产品生成多风格主图/海报 |
| A/B/n测试 | 多版本实验 | 仅用户已明确纳入输出范围时转成单变量正式分镜；不得在源码块外附加测试变量或建议 |
| Lift Test | 看真实增量 | 不把平台归因直接等于真实效果 |
| 边际ROI | 预算打到更高效率渠道 | 判断素材是否适合放量 |
| CRO流程 | 数据定位、假设、设计、实验、全量 | 返修时只改影响最大页面 |

## 电商指标字典

| 指标组 | 常用指标 | 用法 |
|---|---|---|
| 流量 | UV、PV、CTR、跳失、来源结构 | 判断主图、封面和标题是否吸引正确流量 |
| 转化 | 加购率、下单率、支付率、CVR、AOV | 判断详情页、SKU和行动入口是否有效 |
| 交易 | GMV、订单量、实付GMV、折扣率 | 判断活动表达和价格策略 |
| 投放 | ROI、ROAS、CPC、CPM、ACoS、TACoS、CAC | 判断素材是否适合放量 |
| 体验 | 发货时效、退货率、仅退款率、纠纷率、DSR/体验分 | 判断是否需要期望值管理和售后兜底 |
| 用户 | 新客占比、复购率、复购间隔、RFM、LTV、会员占比 | 判断是否需要会员和复购表达 |
| 商品 | 售罄率、周转天数、缺货率、滞销SKU、单品毛利 | 判断SKU图、货盘和大促素材 |
| 内容/直播 | 完播率、互动率、进播率、停留、GPM、件单价 | 判断海报、封面和直播承接 |
| 私域 | 加粉成本、开口率、45日复购、私域GMV占比 | 判断私域海报和社群素材 |
| 财务 | 贡献毛利、净利率、库存周转、现金流周期 | 判断是否适合强调利润款、清仓或复购 |

## 阶段套餐

| 阶段 | 推荐组合 | 用法 |
|---|---|---|
| 从0到1验证 | 选品五力 + 小单测款 + 最小详情页 + 基础评价资产 + 搜索长尾词 + 单位经济 | 先证明有人买、能赚钱、能表达 |
| 从1到10放量 | 爆款公式 + 货盘金字塔 + 三流量 + 达人测款 + 供应链稳定 + 周复盘 | 强化主图、内容、详情页和履约承接 |
| 从10到N品牌化 | AIPL/5A + 公私域会员 + 多平台矩阵 + 品牌心智 + 第二曲线 | 建立品牌资产和长期复购 |
| 大促作战 | 预热种草 + 蓄水加购 + 爆发转化 + 返场收尾 + 复盘沉淀 | 按阶段输出主图、海报和详情页行动入口 |
