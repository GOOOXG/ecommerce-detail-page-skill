# 品牌增长与行业模型系统

本文件只负责品牌资产、增长实验、产品体验、数据复盘、合规出海和行业速查模型。不写电商平台细则、人群生命周期细则或最终分镜模板。

## 目录

`品牌与创意模型` / `增长与实验模型` / `AI与营销融合` / `产品、设计与创新模型` / `创意与体验深挖` / `数据、运营与复盘模型` / `合规、ESG与出海模型` / `行业速查模型` / `输出接口`

## 品牌与创意模型

| 模型 | 适配 | 页面动作 |
|---|---|---|
| 品类战略 / 品类心智阶梯 | 新品类、同质化类目 | 先建立“这是什么/为什么不同” |
| 定位理论 / 重新定位 | 强竞争、比价严重 | 用一句主张占据一个心智位置 |
| 显著度+差异化+相关性 | 主图、海报、品牌详情页 | 保证看得见、记得住、和购买有关 |
| How Brands Grow | 大众消费品、复购品 | 提升心智可得性和购买场景覆盖 |
| 独特性资产 | 有Logo、包装、颜色、符号 | 保持品牌符号稳定，不让生成图漂移 |
| USP / ESP / RSP | 功能、情绪、关系型商品 | 分别打独特功能、情绪利益、关系价值 |
| 12品牌原型 / 品牌人格 | 礼赠、国潮、生活方式 | 确定语气、道具、色彩和画面人格 |
| 奢侈品梦想方程 | 高客单、珠宝、礼品、设计师款 | 稀缺、工艺、历史、仪式感前置 |
| 国潮文化符号模型 | 国风、非遗、地域特产 | 文化符号必须服务产品，不空泛堆元素 |
| DTC内容社区飞轮 | 私域、复购、社群商品 | 场景内容、会员利益、复购理由连续表达 |

## 增长与实验模型

| 模型 | 适配 | 页面动作 |
|---|---|---|
| AARRR / RARRA | 新品、复购、私域 | 按获客、激活、留存、转化、推荐分配素材 |
| 增长循环 / 内容循环（Growth Loop / Content Loop） | 内容平台和种草型商品 | 让海报、主图、详情页形成可复用内容循环 |
| 付费投放循环（Paid Loop） | 投放型主图和海报 | 明确点击理由、落地页承接和复盘指标 |
| K因子 / 病毒传播循环（K-factor / Viral Loop） | 分享、拼团、社群传播 | 设计分享动机和社交证明，不能虚构人数 |
| 北星指标 + 输入指标 + 护栏指标 | 全案评估 | 主指标看转化，护栏看误导、退货、合规 |
| ICE / RICE / PIE | 多方案选择 | 优先高影响、低风险、易执行的方案 |
| 贝叶斯AB测试 / 多臂老虎机 | 多主图测试 | 多方案迭代，不把一次结果当绝对结论 |
| PMF / CMF / IMF | 新品或新渠道 | 判断产品、渠道、增量是否匹配 |
| 负增长诊断树 | 页面效果差 | 从流量、点击、理解、信任、价格、售后逐层排查 |

## AI与营销融合

| 模型 | 适配 | 页面动作 |
|---|---|---|
| GenAI营销六应用 | 文案、图片、视频、个性化、客服、数据分析 | 生成多版素材，但事实、认证和参数仍需确认 |
| Chatbot到AIAgent进化 | 导购、客服、比价、售后 | 分镜可预留咨询入口和导购场景，不虚构服务能力 |
| 个性化引擎架构 | 多人群、多平台投放 | 按人群标签生成不同主图/海报方向 |
| 预测性营销 | CLV、流失、下次购买、响应预测 | 复购品和会员图强调周期、唤醒和组合推荐 |
| 内容智能 | 内容标签匹配受众并预测表现 | 将卖点拆成标签，用于素材工厂和A/B测试 |
| AI营销归因 | 从启发式到数据驱动再到因果 | 复盘时不把平台归因当唯一真相 |
| Agent商务 | AI代理帮助用户搜索、比较、购买 | 页面信息要结构化、可信、可比较、便于AI读取 |
| AIGC品牌声音 | 品牌AI语气一致 | 主图、海报、详情页文案语气统一 |

## 创意与体验深挖

| 模型 | 适配 | 页面动作 |
|---|---|---|
| 内容营销4E | 内容种草 | 教育、娱乐、情感、参与中选择一个主方向 |
| 消费仪式感 | 开箱、礼赠、复购 | 设计开箱、试用、评价、分享的连续画面 |
| 叙事传输 | 场景页、品牌页 | 用情境、冲突、转折、结果增强代入 |
| 心理距离 / 解释水平 | 远期愿景或即时购买 | 远期讲价值，近期讲步骤、价格和行动 |
| 隐喻思维 | 抽象卖点 | 把“轻、稳、快、净、护”等抽象词视觉化 |
| 具身认知 | 触感、温度、舒适度 | 用手持、材质微距、柔光和场景动作表达感受 |
| 物哀/侘寂消费 | 国风、手作、生活方式 | 用克制质感和留白表达，不空泛堆文化符号 |

## 数据、运营与复盘模型

| 模型 | 适配 | 页面动作 |
|---|---|---|
| 指标树 | 全案复盘 | 把点击、停留、加购、转化、退货拆成可优化节点 |
| 漏斗/路径/留存 | 详情页和全案 | 找到流失发生在哪一屏或哪一类素材 |
| RFM / CLV | 复购品和会员 | 区分新客、老客、高价值客、沉睡客表达 |
| Cohort | 复购和活动复盘 | 不同批次用户不要混成一个结论 |
| 归因模型 | 多渠道投放 | 不把所有转化归功于某一张图 |
| VOC文本分析 | 评价和客服问题 | 从用户原话提炼痛点、顾虑和图内文案 |
| 决策智能 | 多模型冲突 | 用事实、目标和风险确定最终方案 |
| OODA | 快速迭代 | 观察、判断、决策、行动形成返修闭环 |
| 事前验尸 | 最终输出前 | 预想失败原因：识别错、卖点虚、证据缺、字太多 |
| Goodhart定律 | 指标防偏 | 不能为点击牺牲真实性、退货和品牌信任 |

## 合规、ESG与出海模型

| 模型 | 适配 | 页面动作 |
|---|---|---|
| 广告法宣传合规 | 全部输出 | 禁止极限、虚假、医疗化和无证据承诺 |
| 电商平台责任与商家合规 | 平台素材 | 活动、价格、售后、认证必须有依据 |
| 知识产权矩阵 | 品牌、IP、跨境 | 避免仿冒Logo、未经授权IP和侵权元素 |
| 产品合规认证路径 | 跨境、食品、母婴、3C | 认证只写已确认；缺失时自动跳过，影响合法性时才阻塞询问 |
| 内容本地化 | 跨境和出海 | 不只翻译，按文化和平台语境重写 |
| LCA / 可持续包装 | ESG、环保商品 | 环保表达必须有材料、认证或边界 |
| 可持续采购 / 绿色供应链 | 品牌页 | 用作信任和价值观，不替代产品证据 |
| 危机沟通3T | 争议或风险商品 | 坦诚边界、快速说明、少做夸张宣传 |

## 行业速查模型

| 行业 | 核心模型 | 分镜优先级 |
|---|---|---|
| 电商 | 人货场 × 流量结构 × 单品利润 | 主图点击、详情承接、SKU防错 |
| 直播 | GPM × 信任 × 货盘节奏 | 海报和封面要强钩子、强信任 |
| 跨境 | 合规 × 物流 × 本地化转化 | 认证、物流、售后、本地场景 |
| 即时零售 | 密度 × 时效 × 商品完整度 | 时段、履约、商品覆盖和评价 |
| 快消 | 渗透率 × 频次 × 分销 | 高频场景、复购、渠道心智 |
| 生鲜 | 损耗 × 履约 × 复购 | 新鲜度、时效、产地和周期 |
| 美妆 | 种草 × 大单品 × 会员 | 质地、肤质、成分、功效证据 |
| 服饰 | 售罄 × 连带 × 折扣 | 版型、上身、尺码、防退货 |
| 3C家电 | 评测信任 × 以旧换新 × 服务 | 参数、评测、安装、政策和售后 |
| 家居家装 | 场景方案 × 交付口碑 | 空间、尺寸、材质、安装 |
| 母婴 | 阶段需求 × 安全信任 × 社群 | 年龄、标准、安全、口碑 |
| 宠物 | 主粮订阅 × 内容社区 | 适口性、阶段、复购、社群 |
| 珠宝 | 稀缺故事 × 鉴定信任 | 证书、工艺、佩戴、礼赠 |
| 运动户外 | 专业功能 × 圈层内容 | 测试场景、装备清单、圈层语言 |
| 工业品 | 认证 × 项目销售 × 交付 | 参数、资质、工况、交期 |
| 医疗健康 | 合规证据 × 专业信任 × 风险边界 | 不医疗化，证据和适用边界前置 |
| 教育服务 | 满班 × 续费 × 口碑 | 结果边界、服务流程、真实案例 |
| 本地生活 | 到店频次 × 评价 × 券效率 | 场景、评价、地理便利和核销 |
| 专业服务 | 利用率 × 费率 × 口碑 | 流程、资质、案例边界、信任 |
