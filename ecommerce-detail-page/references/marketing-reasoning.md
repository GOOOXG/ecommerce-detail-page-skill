# 营销、心理与经营推演加速层

本文件把历史版本中有助于“更快想清楚、画清楚、证清楚”的营销、消费者心理、产品、运营和商业模型，收敛成一个只服务分镜的后台加速层。它不是第二套工作流，不要求用户选择模型，也不把模型名称、评分或推演过程写进最终分镜。

模型只能帮助提出问题、排序卖点和选择画面，不能把行业常识变成商品事实。所有结论都必须回到当前已确认商品卡、参考视觉、用户资料、可核验证据和真实生产能力。

## 何时读取与主流程关系

商品卡前只做轻量读取；正式调用要等商品主体已识别、商品卡事实边界基本成立，并且模型结论确实会改变卖点、图片任务、图组顺序或提示词表达。读取位置如下：

1. **预构建轻量调用**：只用“买家任务、可能利益、待补证据”帮助生成卖点候选，不锁定图型、数量或顺序。
2. **商品卡确认后正式调用**：确定一个首要买家问题，选一个主模型，必要时加入最多两个辅助检查，把结论交给图片规划。
3. **图组规划调用**：把模型阶段转成不同图片任务，检查每张是否新增事实、证据、选择帮助、使用代入或顾虑解法。
4. **提示词编译调用**：只编译已经通过证据和生产检查的结论，不重新发散商品身份或图组方案。
5. **生图反馈调用**：只根据用户明确指出的失败原因修正受影响字段，不把随机结果或工具失败当作心理偏好。

它始终嵌入既有主线：

`识别主体 → AI预构建 → 用户选择/纠正 → 商品卡确认 → 首要目标与风险 → 输出范围 → 图组规划 → 逐图分镜 → 可选生图`

模型层只能加速其中的“问题建模、卖点排序、证据路径和画面构设”，不能绕过商品卡、范围、隐藏视图确认、逐图确认或安全质检。

## 统一编译出口

无论使用哪一个模型，内部都必须翻译为同一组可执行字段：

`商品事实 → 买家任务 → 主要阻力/动机 → 卖点与利益 → 证据需求 → 图片任务 → 文案命题 → 生产边界 → 成功标准`

每个模型至少回答下列问题：

| 编译字段 | 要回答的问题 | 进入分镜的位置 |
|---|---|---|
| 买家问题 | 买家此刻最想确认什么？ | `成图任务`、`最终画面` |
| 卖点/利益 | 商品事实给用户带来什么可感知结果？ | `商品锁定`、`最终文案`、正向提示词 |
| 证据需求 | 凭什么相信，证据能证明到哪一步？ | `视角与事实边界`、`生产与后期` |
| 图片任务 | 用什么画面让问题被看懂或被证明？ | `成图任务`、图型与构图 |
| 文案命题 | 一眼要记住哪一句准确的话？ | `最终文案`或后期排版安全区 |
| 生产边界 | 单次生成、真实商品层、合成、实拍还是概念稿？ | `生产与后期` |
| 成功标准 | 缩略图、正常阅读或比较时怎样算完成？ | `画布与布局`、质检 |

“特征像什么”不等于“功能是什么”，“用户可能喜欢”不等于“商品承诺”。证据不足时，模型结论只能决定场景、顺序、留白或观察角度，不能进入高风险主张。

这套统一编译是后台的自然语言工作记忆，不建立新的合同式接口、营销锁或独立状态机；需要追溯时沿用现有商品卡、证据账本和分镜字段。

## 模型调用卡：从触发到分镜

模型不是术语清单，也不是要求用户填写的新表单。每次只在当前问题确实需要时，在内部用一张轻量调用卡把模型翻译成图片工作：

```text
触发问题 → 所需输入 → 阶段动作 → 对象/图型 → 可用证据
→ 不可推导 → 降级路径 → 停止条件
```

调用卡至少回答八件事：

1. **触发问题**：当前买家到底看不懂、信不过、选不出、不会用，还是没有下一步？
2. **所需输入**：商品卡中的哪些事实、SKU、用户意向、平台位置、真实经营资料或反馈已经存在？缺什么？
3. **阶段动作**：模型改变的是入口、理解、证明、选择、使用、交付、复购还是复盘中的哪一段？
4. **对象/图型**：结论落到主图、SKU图、海报、详情页模块或基础素材中的哪一个职责；优先选已有图型，不足时再创造商品专属画法。
5. **可用证据**：哪些参考视觉、说明书、实测、价格/库存资料、评价、授权或平台资料能支撑主张？
6. **不可推导**：哪些内容只能当假设，不能写进商品卡、文案或写实画面？
7. **降级路径**：缺证据或工具能力不足时，改成可观察特征、真实商品层/后期、补拍、三维资料或删除主张中的哪一种？
8. **停止条件**：继续调用是否还会新增买家问题、证据、选择帮助、场景理解或风险降低？没有就停止。

### 经营路径模型的调用映射

下表是内部的“触发—动作—落点”速查，不是每次必跑的清单。FAST 与 GROW 在不同平台可能有不同释义；未收到用户或平台明确定义时，采用本文件口径，用户/平台资料优先，不能把不同口径混用。

| 模型 | 何时触发与所需输入 | 阶段动作与图片落点 | 证据、降级与停止 |
|---|---|---|---|
| **AIPL** | 需要区分认知、兴趣、购买、忠诚素材；输入是当前触点、用户意向和已确认商品事实 | 认知：主图先让人认出品类；兴趣：场景或核心利益；购买：证据、SKU/适配与交付；忠诚：使用、维护、补货或服务图 | 没有生命周期或触点资料时只作为素材职责假设；不能把“忠诚”写成真实复购。若阶段不改变图组，停止调用 |
| **FAST** | 平台/经营目标需要判断素材偏人群总量、转化、高价值或活跃；输入是平台目标、受众阶段、SKU和真实经营资料 | 人群总量：入口识别与覆盖；转化：利益、证明与防错；高价值：真实套装、品质和升级价值；活跃：真实使用、复购或互动入口 | 没有平台数据时只标为“素材假设”，不写人群规模、转化率或高价值标签；无法改变图组职责就停止 |
| **GROW** | 需要判断增长来自渗透、复购、价格还是延展；输入是品类认知、补货周期、真实规格/价格带和关联场景资料 | 渗透力：品类教育与首屏识别；复购力：补货/维护/订阅场景；价格力：真实规格、寿命或套装参照；延展力：已存在的关联场景/品类组合 | 本文件固定采用“渗透力—复购力—价格力—延展力”；缺经营资料时只决定提问方向，不写增长结论、利润或热销标签 |
| **人货场** | 画面吸引了人却没有形成使用代入，或人物、商品、触点不匹配；输入是目标角色的真实任务、商品事实和使用时空 | “人”决定动作、尺度和顾虑；“货”决定主体、利益和证据；“场”决定接触点、时间、地点和道具，编译为场景图/第一视角/尺寸参照 | 不凭年龄、性别、收入或刻板印象造画像；角色、动作、空间和适配必须可解释。若换场景不改变买家问题，停止 |
| **AARRR** | 需要规划入口到复购/分享的多资产链路，或有真实漏斗反馈；输入是实际触点、行为和返修原因 | 获客：正确品类入口；激活：首次看懂/会用；留存：维护、补货、服务；收入：选型、套装和价值证明；推荐：真实分享、评价或UGC入口 | 没有行为数据时只分配图片职责，不声称漏斗提升；一次结果不能证明因果。若只需一张图，压缩为“识别+理解+一个证据”，没有新增链路就停止 |

### 消费决策心理的调用映射

心理模型只帮助找出阻力，不替代证据，也不允许操纵。通常沿“注意 → 理解 → 信任 → 选择 → 行动 → 复购/推荐”检查，但一张图只承担其中一个主要任务：

| 机制 | 触发问题 | 可编译的画面 | 硬边界 |
|---|---|---|---|
| **FOMO/错失恐惧** | 用户是否真的存在会错过的截止时间、库存、季节或预约窗口？ | 有当前资料时，把真实时点/库存/窗口放在利益与行动图；没有资料时完全不放倒计时、稀缺徽章或紧迫文案 | 不制造虚假稀缺、恐惧、羞辱或不可退出的压力；资料失效就删除该组件 |
| **锚定效应** | 用户需要什么真实参照才能判断规格、套装或价值？ | 用已确认尺寸、容量、套装内容、使用寿命或可核验替代成本做并列/阶梯/参照图；参照本身就是证据层 | 不虚构原价、划线价、节省金额、竞品差异或“大家都选”；参照不成立就改为单品事实展示并停止比较 |
| **消费决策心理学（综合链）** | 用户停留、理解、信任、选择或行动在哪一环卡住？ | 注意：主体和品类；理解：卖点可视化；信任：工艺/测试/来源；选择：SKU/适配；行动：真实入口；复购/推荐：使用与服务 | 不把心理推断当作用户事实；每环都要有对应证据或明确假设，不能一张图堆满整条链；缺证据就删除该环并停止扩展 |

调用卡完成后，只把“图片任务—画面—证据—生产边界—成功标准”写入现有分镜字段。模型名、调用卡、阶段标签和内部判断不进入最终提示词；没有新增价值就停止，不为了展示模型而增加图片。

#### 一个最小调用示例（仅示意内部思路）

```text
触发问题：买家能认出商品，但不知道哪个规格适合自己
所需输入：已确认SKU差异、真实尺寸/接口、目标使用场景
主模型：人货场；辅助检查：锚定效应、选择架构
阶段动作：把“使用者—任务—规格差异”编译成一张SKU适配/尺寸参照图
可用证据：同SKU实拍、规格表、真实参照物；不可推导：销量、热销排序、虚构竞品
降级路径：缺尺寸证据时只展示并列外观与适配字段，不画精确比例
停止条件：买家能在缩略图和正常阅读下区分并选择，继续添加模型不增加信息
```

上例最终只会生成一张自然中文分镜，不会输出“主模型”“辅助检查”或心理学解释。

## 模型选择规则

### 先按问题选，不按术语选

先把当前阻力归入一个问题，再调用相应模型：

| 当前问题 | 默认主模型 | 可选辅助检查 | 常见图片落点 |
|---|---|---|---|
| 用户不知道卖的是什么 | AIDA或ACCA | 品类心智、认知流畅 | 标准主图、品类识别、白底图 |
| 三秒内看不懂好在哪 | FABE或USP | 4U、金字塔原则 | 卖点主图、细节特写、功能状态 |
| 用户有痛点但不急 | PAS或BAB | SPIN、损失厌恶 | 前后对比、场景穿透、问题可视化 |
| 新品类/复杂原理需要教育 | ACCA或DAGMAR | QUEST、消费者采用路径 | 结构拆解、步骤、机制解释、FAQ式画面 |
| 用户怕买错SKU/规格 | MECE或JTBD | Kano、选择架构 | SKU并列、尺寸参照、适配防错 |
| 用户不相信品质或效果 | FABE或RTB | 权威/社会证明、CDJ | 材质工艺、测试过程、真实证据层 |
| 高客单、耐用品或ToB决策 | CDJ或DAGMAR | SPIN、MEDDIC、LAER | 对比、工况、交付、安装、售后边界 |
| 内容种草、搜索、分享 | AISAS或RACE | 叙事传输、4E、BAB | 场景海报、生活方式、可分享记忆点 |
| 复购、会员或私域承接 | AIPL/5A或RACE | RFM、CLV、内容循环 | 补货周期、会员权益、服务与复购场景 |
| 平台经营目标不清 | 人货场 | FAST、GROW、AIPL | 入口主图、场景海报、承接详情页 |
| 页面已上线但表现异常 | 指标树或漏斗 | OODA、CRO、事前验尸 | 只返修最高影响的一张或一层 |

### 默认组合边界

- 普通任务：1个主模型，最多1个辅助检查。
- 有真实取舍的中等任务：1个主模型，最多2个辅助检查；第二个辅助必须解除一个不同且明确的缺口。
- 多SKU、高风险、跨平台或复杂生产：优先按独立问题分阶段调用；同一阶段通常不超过3个模型/检查，增加的是证据审查或独立反证，不是无限堆模型。心理模型只作顾虑镜头，业务模型只作边界检查，不自动生成新的图片任务。
- 一个模型若没有新增图片任务、证据路径、选择帮助或风险降低，立即移除。

这里是防止模型堆叠的默认边界，不是限制推理能力的硬上限。若任务确有更多互不重复的问题，允许分阶段思考，但每一阶段都必须回到同一编译出口，并以新增图片价值决定是否保留。

模型名字只在内部或用户主动询问时作为简短依据出现；对外正式分镜只保留编译后的自然中文，不把模型名称写入最终分镜。

## 购买路径与内容推进模型

这些模型回答“用户先看什么、后相信什么、何时行动”，适合决定多图顺序，不直接替代单张画面设计。

| 模型 | 中文理解 | 适合问题 | 分镜编译 |
|---|---|---|---|
| AIDA | 注意—兴趣—欲望—行动 | 主图、海报、短详情页 | 首屏抓取识别，第二层给利益，随后给证据，最后保留自然行动空间 |
| AIDMA | 注意—兴趣—欲望—记忆—行动 | 货架反复曝光、品牌心智弱 | 建立稳定视觉锤、色彩或符号，避免每张完全换风格 |
| AISAS | 注意—兴趣—搜索—行动—分享 | 内容平台、种草与口碑 | 场景先引发相关性，再给可搜索的事实与分享理由 |
| ACCA | 认知—理解—确信—行动 | 新品类、复杂功能 | 先说是什么，再用结构/演示/证据降低理解成本 |
| DAGMAR | 知晓—理解—确信—行动 | 高客单、理性评估 | 分层解释参数、证据、场景和交付边界 |
| PASTOR | 痛点—放大—故事—转化—报价—回应 | 解决方案、服务和强痛点 | 只呈现真实问题与回应，不制造恐惧或虚假报价 |
| PAS | 痛点—放大—解决 | 低客单、快决策主图 | 一张画面清楚呈现问题、影响和可观察解法 |
| BAB | 之前—之后—桥梁 | 清洁、美妆、效率改善 | 前后状态必须同条件、可核验，产品作为真实桥梁 |
| QUEST | 识别—理解—教育—刺激—转化 | 需要教育的人群 | 把术语转成生活问题、图解和下一步理解 |
| CDJ | 考虑—评估—购买—体验—复购 | 高客单、家电、家居、服务 | 进入候选、比较、使用、售后和长期价值分别有证据 |
| 5A/4A/O-5A | 认知—吸引—询问—行动—拥护 | 会员、私域、平台人群资产 | 入口、咨询、购买、评价/推荐由不同资产承接 |
| RACE | 触达—互动—转化—留存 | 站外投放、内容流、私域 | 主图/海报负责触达，详情负责解释与转化，后续素材承接留存 |
| See-Think-Do-Care | 看见—考虑—行动—关怀 | 多阶段内容矩阵 | 不把一张图同时塞满四个阶段，按素材职责分工 |
| 消费者采用路径 | 知晓—兴趣—评估—试用—采用 | 新技术、新生活方式 | 用概念、实物、体验、结果逐步降低陌生感 |

路径模型的阶段必须落到具体图：不能只写“提升兴趣”，要写“用可见杯盖结构特写解释开合关系”或“用真实尺寸参照降低容量误判”。

## 图片转化框架

这些是把模型结论直接变成画面职责的中间层，不是额外流程；每次只选能解决当前买家问题的一个主框架，其他框架只作检查：

| 框架 | 解决的阻力 | 分镜编译 |
|---|---|---|
| 首屏截停 | 用户快速划屏不愿停留 | 用真实品类、主体比例、差异形态和一个核心利益建立第一眼识别 |
| 痛点递进 | 用户知道问题却没感到与自己有关 | 先呈现真实场景阻力，再给可观察的商品解法，不制造焦虑 |
| 竞品差异化 | 同类商品看起来都一样 | 只对比当前有资料的结构、规格、服务或到手内容，分别保持商品层 |
| 感官转译 | 抽象卖点难以想象 | 把轻、稳、净、快、柔等词转成材质、动作、尺度、光影或结果画面，不冒充性能测试 |
| 场景穿透 | 用户无法代入使用 | 用真实人物、空间、动作和前后关系，让买家看到自己如何使用 |
| 合规信任 | 用户担心品质、来源或承诺真假 | 将实拍细节、说明书、检测、授权、评价或服务边界放在证据层，缺证就删掉 |
| 价值解释 | 用户不理解价格或套餐差异 | 用真实规格、套装内容、寿命/服务资料或选择帮助解释价值，不虚构原价和节省 |
| 情绪溢价 | 功能相近但缺少记忆和向往 | 用商品专属色、符号、仪式和氛围增强身份感，不能用稀缺故事代替事实 |
| 行动促进 | 用户看懂了却不知道下一步 | 只呈现真实活动、咨询、预约、核销、加购或规格选择入口，保持可退出 |
| 顾虑兜底 | 买错、误用、安装或售后风险 | 用适配、尺寸、步骤、交付、维护和边界图减少不确定，不把警示写成恐吓 |

框架最终仍要编译到现有分镜字段；如果只是换背景、语气或装饰而没有新的买家任务，就不成立。

### 转化视觉技法库

技法是画法，不是额外图型。只在它能让同一个买家问题更快被看懂、相信或选择时启用，并把商品主体与证据层交给真实资料：

| 技法族 | 可探索的画法 | 适合解决的问题 | 硬边界 |
|---|---|---|---|
| 截停与相关性 | 认知反差、强对比、隐性问题可视化、圈层语境、悬念线索、情绪共鸣 | 快速划屏时停驻并认出品类 | 反差必须可解释；不靠惊吓、羞辱或错误品类吸睛 |
| 感官转译 | 剖面透视、流体/阻尼定格、解压瞬间、五感联想、微观放大、悬浮展示 | 抽象的材质、动作、温度或触感难以想象 | 只表达可观察质地或氛围，不把联想写成功能、功效或性能测试 |
| 场景穿透 | 全天候/全空间、第一视角、特殊使用情境、独处/办公/户外、生态搭配 | 用户无法代入“我会怎样用” | 人物、动作、尺度、空间和接触关系要真实；不凭刻板画像造场景 |
| 差异与比较 | 结构并列、匿名方案对比、信息清单、盲测/雷达式数据、缺口图鉴 | 同类商品看起来都一样或SKU难选 | 只对比当前有资料的维度；竞品商标、数据和劣化效果需授权/证据 |
| 信任与价值 | 证据链、研发/工艺过程、真实用户体验、第三方测试、比例参照、生命周期解释 | 用户不信品质、效果或价格理由 | 评价、销量、检测、专家、节省和寿命必须可核验；缺证据直接跳过 |
| 行动与兜底 | 真实限时、阶梯权益、默认推荐、轻量行动阶梯、顾虑分层、期望值管理、开箱/交付 | 看懂后仍不会选、不会用或担心后悔 | 活动、库存、赠品、服务和退换边界必须真实；不制造倒计时或零风险暗示 |

同一技法可以服务主图、SKU图、海报或详情页，但职责必须随对象改变：主图优先截停和品类识别，SKU图优先比较和防错，详情页优先解释、证明、使用与兜底，海报优先一个主题和传播入口，白底/透明/无字素材只保留保真与复用价值。

## 卖点、定位与价值表达模型

这些模型回答“商品事实怎样变成用户能理解、相信并愿意记住的利益”。

| 模型 | 中文理解 | 视觉/文案编译 | 证据边界 |
|---|---|---|---|
| FAB | 特征—优势—利益 | 由可见特征推到可感知使用好处 | 没有证据时只保留可观察特征与谨慎利益，不写强效果 |
| FABE | 特征—优势—利益—证据 | 先明确用户得到什么，再用结构、实测或资料承接 | E必须有对应证据；缺证据自动降级为FAB |
| USP | 独特销售主张 | 一组只突出一个真正不同、可被画面证明的点 | “独特”不能由口号自封，需有当前商品差异依据 |
| RTB | 相信理由 | 为每个主张指定“为什么可以相信”的证据 | 理由不能用氛围、奖项或模型猜测代替 |
| ESP/RSP | 情绪利益/关系利益 | 把安心、体面、专业、归属等情绪落到真实场景 | 情绪是体验预期，不升级为功效或身份承诺 |
| EPP | 情绪—痛点—承诺 | 用真实情绪入口连接具体痛点，再给可验证承诺 | 承诺必须有证据；无证据时只保留场景和可观察特征 |
| 4U | 有用、具体、独特、适时 | 检查标题和主图是否有明确对象、结果和必要时效 | 紧迫性仅使用真实活动或真实使用时点 |
| 4C文案 | 清楚、简洁、可信、有吸引力 | 控制图内文字密度、主次和移动端可读性 | 吸引力不能靠夸大和伪证据 |
| 3C定位 | 顾客、竞争、能力 | 判断卖点是否对目标人群有用、能区别且商家做得到 | 竞争结论需有当前对比资料，能力不能凭想象 |
| 价值主张画布 | 任务、痛点、收益与产品匹配 | 让画面同时回答“为谁、解决什么、得到什么” | 任务和收益先标为假设，确认后才上图 |
| JTBD | 买家雇佣商品完成的任务 | 把功能改写成“在某情境完成某结果” | 不把推断人群画像写成事实 |
| Kano | 基础、期望、兴奋、无差异、反向 | 基础项做清楚，兴奋项做记忆点，反向项做排雷 | 分类是排序工具，不证明商品拥有该功能 |
| MECE | 相互独立、完全穷尽 | 把卖点、SKU和详情模块分组，消除重复和遗漏 | “穷尽”不等于必须做很多张，仍受新增价值门控制 |
| 金字塔原则 | 先结论、后理由 | 主标题先说核心结果，画面/参数再证明 | 结论必须先通过证据账本 |
| 4P | 产品、价格、渠道、促销 | 检查运营信息是否会改变素材职责 | 价格和促销必须来自当前资料 |
| 4C营销 | 顾客、成本、便利、沟通 | 从买家成本、使用便利和沟通方式重排页面 | 不把假设成本写成节省金额 |
| 7P | 产品、价格、渠道、促销、人员、流程、有形展示 | 服务、安装、咨询和本地生活场景中补足流程与人员 | 人员、服务等级和承诺需有授权资料 |
| PEST | 政策、经济、社会、技术 | 只用于发现行业背景和风险，转成平台/合规检查 | 不把宏观趋势写成商品销量或需求事实 |
| SWOT | 优势、劣势、机会、威胁 | 用于判断主推差异和需要回避的表达 | 劣势不能被包装，机会不能当市场证明 |

## 消费者心理与选择架构

这一节是消费决策心理学在商品图片中的应用：心理模型只回答“为什么用户会停、信、选或行动”，必须使用尊重、可验证、可退出的表达。任何模型都不能成为操纵脆弱人群、制造恐惧或伪造稀缺的理由。

### 注意、理解与记忆

| 机制 | 判断问题 | 画面编译 |
|---|---|---|
| FOMO/错失恐惧 | 用户是否担心错过真实时机、权益或场景 | 只有真实截止时间、库存或季节窗口才可呈现；没有资料就不用倒计时 |
| 锚定效应 | 用户用什么真实参照判断价值 | 用已确认规格、真实套装、生命周期或可核验替代成本作参照，不虚构原价 |
| 框架效应 | 同一事实用获得还是避损更易懂 | 高风险品类优先清楚说明边界；悦己品类可强调真实体验收益 |
| 认知流畅 | 用户能否迅速理解 | 少术语、强层级、明确主体、短句和高对比安全区 |
| 精细加工可能性模型 | 用户是快速扫读还是深度评估 | 低客单先视觉和短利益，高客单补结构、参数、来源与售后 |
| 峰终定律 | 用户记住哪一个高潮和结尾 | 组内安排一个视觉记忆点，结尾用真实边界和选择帮助收口 |
| 蔡格尼克效应 | 未完成信息是否促使继续看 | 只用真实的下一步线索，不用故弄玄虚或隐藏关键条件 |
| 首因/近因与序位效应 | 首尾信息是否更容易被记住 | 首图锁定品类和主利益，尾图承担真实保障或选择提醒 |
| 冯·雷斯托夫效应 | 差异元素能否被记住 | 让商品独有形态成为视觉锤，不用无关装饰抢注意力 |
| 格式塔原则 | 用户能否看懂关系 | 用接近、相似、连续、闭合、图底关系组织部件、步骤和信息 |

### 信任、动机与风险

| 机制 | 适用顾虑 | 画面编译与红线 |
|---|---|---|
| 社会证明 | “别人是否也这样选” | 使用真实评价、实测、销量或UGC证据；无资料就删除组件 |
| 权威原则 | “专业机构是否认可” | 只呈现真实检测、标准、授权或专家资料；不生成徽章和证书 |
| 互惠 | 用户先得到有价值的信息 | 用清楚的选型、教程或尺寸帮助回馈，不以虚假赠品诱导 |
| 承诺一致 | 小行动是否能降低下一步阻力 | 允许查看详情、选择规格、咨询或收藏逐步推进，不强迫或误导 |
| 禀赋效应 | 用户能否想象拥有和使用 | 用真实手持、空间落位、开箱和使用后状态建立代入，不夸大效果 |
| 前景理论/损失厌恶 | 用户更怕损失还是想获得 | 用真实的买错、装错、错过适配提醒，禁止虚假恐吓 |
| 风险逆转 | 用户害怕后悔或售后困难 | 仅使用已确认的退换、保修、安装和服务边界 |
| Fogg行为模型 | 动机、能力和触发是否同时存在 | 降低步骤、讲清选项、给出可执行下一步；不把复杂流程藏起来 |
| 认知失调 | 反常识画面是否能引发注意 | 反差必须能被事实解释，不能靠伪对比或攻击用户焦虑 |
| 现状偏误/默认效应 | 用户倾向不改变或接受默认 | 只推荐真实适配的大多数方案，明确“适用边界”，不暗中默认购买 |

### 价格、套餐与选择

| 机制 | 画面用途 | 限制 |
|---|---|---|
| 心理账户 | 日用、享乐、礼赠、投资等价值解释 | 只能改变解释角度，不能虚构节省或身份收益 |
| 支付痛苦 | 用户觉得一次支付过重 | 用真实使用频次、套装内容、服务或寿命资料解释，不随意拆算 |
| 折中效应 | 多个真实规格需要选择 | 可突出适合目标人群的中间款，但不能伪造热销或“大家都选” |
| 诱饵效应 | 套餐关系需要被看懂 | 只有真实SKU和清楚差异才可使用，不能创造虚假对照款 |
| 选择悖论 | 选项太多导致停滞 | 用MECE、默认推荐、适配边界和简短比较减少负担 |
| 目标梯度 | 逐步行动或补齐条件 | 只展示真实进度、门槛和下一步，不伪造“还差一点” |
| 稀缺与时效 | 真实库存、季节、预约窗口 | 必须有当前资料；缺资料时完全删除稀缺视觉和文字 |
| 叙事传输 | 场景故事让用户代入 | 有开始、阻力、使用和结果，但不虚构用户案例或效果 |
| 心理距离/解释水平 | 远期愿景与即时购买的距离 | 远期用价值和身份，近期用步骤、价格、适配和证据 |
| 具身认知 | 触感、温度、重量、舒适度 | 用动作、手持、微距、材质和空间尺度表达，不宣称不可见感受为事实 |

## 人群、平台与人货场模型

这些模型决定“谁在什么场景看这张图、谁需要哪种证据”，不是用来凭空生成用户画像。

### 人货场与人群阶段

| 模型 | 中文理解 | 分镜用途 |
|---|---|---|
| 人货场 | 人群、商品、场景三者匹配 | 先确定谁在何时何地因什么任务需要商品，再选主体、道具和场景 |
| STP | 细分、目标选择、定位 | 让主图只对一个清晰人群说一个可验证差异 |
| Persona/用户画像 | 代表性使用者 | 只记录与任务相关的行为和场景，不用刻板年龄、收入或性别推断 |
| 非目标人群/不适用场景 | 谁或什么场景会误购、误用或无法获得预期价值 | 只依据已确认的适用限制决定人物/场景禁区、适配边界或防误购图，不凭人口属性推断 |
| 同理心地图 | 所想、所说、所做、所感 | 把真实评价、客服原话和观察转成痛点、语言和画面动作 |
| 公域—私域—品牌域 | 触达、承接、关系沉淀 | 入口图只负责触达，详情/服务图承接理解与信任；没有真实渠道资料时不写域名或经营结论 |
| AIPL | 认知、兴趣、购买、忠诚 | 为入口、卖点、成交和复购素材分配不同职责 |
| 5A/4A/O-5A | 认知、吸引、询问、行动、拥护 | 为内容、咨询、购买和口碑安排承接，不把所有阶段塞进一图 |
| FAST | 人群总量、转化、高价值、活跃 | 平台经营任务中判断素材偏拉新、转化、高价值或活跃；没有平台数据时只作假设 |
| GROW | 渗透力、复购力、价格力、延展力 | 判断图片应优先教育新品类、承接复购/补货、证明价格升级价值，还是展示关联品类与场景延展；没有经营数据时只作假设 |
| RFM/RFMTC | 最近购买、频次、金额及关系 | 复购和会员素材区分新客、老客、高价值和沉睡用户 |
| CLV/LTV | 用户长期价值 | 耗材、订阅和复购商品展示周期、补货和服务边界 |
| NPS | 推荐者、被动者、贬损者 | 只在有真实反馈时决定口碑/UGC表达，不虚构满意度 |

本技能中的GROW固定指品类增长语境下的“渗透力、复购力、价格力、延展力”，不与同名的教练式问答框架混用。

### 平台与成交场路由

仅当用户明确平台、且当前任务提供了可核验平台条件时调用；平台缩写是路由提示，不是最新规则来源。

| 场景/平台 | 可参考模型 | 图片重点 |
|---|---|---|
| 货架搜索 | AIDA、AIDMA、USP、FABE、主图CTR | 品类识别、核心差异、三秒利益、清晰SKU |
| 内容种草 | AISAS、RACE、4E、叙事传输、内容循环 | 真实场景、收藏/搜索理由、体验证据和分享记忆点 |
| 淘宝/天猫 | AIPL、FAST、GROW、DEEPLINK、ONE-ID | 搜索入口、详情承接、会员与复购衔接；不把平台名写进提示词 |
| 抖音/直播 | O-5A、GPM、FACT/FACT+S、内容场/中心场/营销场 | 封面钩子、直播信任、真实活动和商城承接 |
| 京东/标品 | 4A、履约与服务链、以旧换新 | 参数、交付、安装、售后和政策证据 |
| 小红书 | KFS、笔记漏斗、搜索词与内容词包、UGC | 场景、体验、关键词可读性和真实口碑 |
| 快手/私域 | STEPS、关系链、私域四阵地 | 坦诚过程、服务、咨询与轻行动 |
| Amazon/跨境 | Listing SEO、FBA、PPC、A+、Review、订阅购 | 结构化卖点、认证、评价、物流/售后和本地化；动态政策需核验 |
| 独立站/DTC | DTC漏斗、Email/SMS生命周期、Affiliate、订阅 | 首屏价值、信任、结账阻力和复购承接 |
| ToB/顾问/项目 | MEDDIC、SPIN、Gap Selling、LAER | 工况、规格、交付、ROI、采购和服务边界 |
| 门店/即时零售 | 地理便利、评价、核销、小时达 | 位置、时段、到店/配送和真实核销流程 |

### 成交场、平台与智能内容补全

平台术语只用于选择画面职责，不能替代当期官方规则。当前任务没有平台、经营数据或授权资料时，只保留通用的识别、证明、选型和生产要求：

| 场景/模型 | 它要解决什么 | 分镜编译 | 边界 |
|---|---|---|---|
| 货架销售与搜索词包 | 用户在极短时间判断是否相关 | 主图先锁定品类、差异和一个利益，详情承接证据 | 不把搜索词热度、点击率或排名当成商品事实 |
| 内容销售、直播销售与社交销售 | 场景、关系和讲解如何连续承接 | 海报/封面负责钩子，场景图负责代入，详情或直播承接真实权益 | 直播福利、倒计时、达人和社群关系必须有当前资料 |
| 顾问式、ToB交易型与项目型销售 | 多角色、多阶段和交付风险如何被看懂 | 用工况、规格、方案、采购、交期、安装和售后图分工 | ROI、交期、案例、资质和服务能力不能凭模型补造 |
| 公域—私域—品牌域三域 | 触达、承接和关系沉淀分别需要什么资产 | 入口图、解释/咨询图、品牌/复购图保持同一商品锚点而承担不同职责 | 没有真实渠道链路时不写域名、会员规模或经营结论 |
| GPM、FACT/FACT+S、KFS、STEPS、DEEPLINK、ONE-ID | 直播、内容、搜索和全域资产如何衔接 | 只提取封面钩子、信任证据、搜索词、关系承接或跨触点一致性 | 先核对平台和版本；缩写不进入最终分镜 |
| GenAI内容、个性化引擎、预测性营销、内容智能 | 同一商品如何按人群、渠道和生命周期复用 | 生成不同场景/信息层变体，保持商品层、事实和品牌锚点不变 | 不凭预测生成画像、销量、转化或个性化权益；真实文字仍由证据层/后期负责 |
| AI代理购物、结构化商品信息、AI营销归因 | 让人和机器都能比较、检索和回溯 | 稳定商品字段、规格、包装清单、适配和素材来源，便于复用 | 平台归因或自动标签不是商品事实；一次归因不等于图片因果 |

### 合规、出海与品牌安全模型

这些模型只负责把风险转成“保留什么、删除什么、需补什么证据”，不生成法律意见：

| 模型 | 分镜用途 | 必须核验 |
|---|---|---|
| 广告法宣传合规与平台责任 | 删除极限、医疗化、虚假比较、虚假促销和误导性视觉 | 当前平台规则、商品类别、活动条件和责任主体 |
| 产品合规认证路径 | 决定认证、标准、成分、标签和适用边界是否能上图 | 有效证书、适用型号/地区、有效期和原文 |
| 知识产权矩阵 | 固定可用品牌资产，隔离未经授权的Logo、IP、人物、包装和音乐/字体暗示 | 授权范围、商标/版权状态和可商用素材 |
| 内容本地化与CAGE/EPRG | 调整语言、单位、人物、场景、包装和平台阅读习惯 | 目标市场官方规则、当地语言/单位、文化与禁限售资料 |
| ESG/LCA与绿色供应链 | 仅在材料、来源、包装或认证真实时构成信任或价值图 | 材料清单、认证、边界和可追溯来源 |
| 危机沟通3T | 争议或风险场景下先呈现事实、边界和处理路径 | 事件事实、授权口径、时间线和可执行服务 |

若某个模型不能改变当前分镜的主张、证据、构图、生产方式或返修动作，就不加载；行业细分与具体合规要求继续以 [category-adaptation.md](category-adaptation.md) 和用户/官方资料为准。

### 人群角色分离

复杂商品要区分触发者、搜索者、决策者、付款者、使用者、影响者、收货/安装/维护者。若角色不同，入口主图、SKU防错、参数证据、安装教程、礼赠场景和售后图应分工；不要用单一“目标用户”概念掩盖不同顾虑。

### 需求与生命周期补全

历史版本中的人群和需求模型继续保留，但只提取能改变画面的部分。它们用于发现“谁在什么时刻需要看懂什么”，不用于生成无依据的人口画像：

| 思维工具 | 重点问题 | 可编译的分镜动作 | 使用边界 |
|---|---|---|---|
| 人口、地理、心理、行为、场景、价值、圈层细分 | 哪种已知差异会改变语言、尺度、场景或证据？ | 调整人物、空间、阅读密度、道具和场景任务 | 只有用户资料、授权数据或明确任务支持时才使用；不凭年龄、收入、性别或地域刻板推断购买动机 |
| Persona/用户故事/同理心地图 | 谁在什么情境下为了什么结果使用，所想、所说、所做、所感是什么？ | 将真实原话、动作和阻力变成场景、标题角度或顾虑图 | 只保留与当前决策有关的行为，不输出长篇人格画像 |
| 场景立方体（人—时—地—事—阻—证） | 触发时点、地点、任务、摩擦和继续决策所需的证据是什么？ | 组合人物、时间、空间、动作、替代方案和证据层 | “厨房/户外”等背景词本身不构成有效场景 |
| 非目标人群/不适用场景/排除人群 | 谁可能误购、误用或无法获得预期价值？ | 在SKU、适配、尺寸、安装或场景图中明确边界，减少误点和退货 | 只能依据已确认适用限制，不把排除写成对某类人的贬低 |
| 用户生命周期五阶段 | 引入、成长、成熟、衰退、流失时，买家问题是否改变？ | 新客先做识别与信任，老客做补货/升级，流失阶段做真实服务或替换说明 | 没有生命周期资料时只作为内容假设，不虚构会员状态 |
| 首单到二单、补货周期、订阅续订、流失原因树、服务补救 | 买家何时再次需要、为什么中断、如何恢复信任？ | 用周期装、耗材关系、维护、售后和交付边界承接复购 | 周期、权益、补偿和服务必须来自当前资料；不把复购预测写成承诺 |

这些模型的输出仍回到“买家任务、阻力/动机、证据需求、图片任务、成功标准”。如果分层只改变称呼而不改变画面职责，就不单独生成一张图。

## 增长、经营与复盘模型

这些模型只用于决定资产职责、优先级和返修方向，不生成独立运营报告。

| 模型 | 解决的问题 | 分镜编译 |
|---|---|---|
| AARRR/RARRA | 获客、激活、留存、收入、推荐的链路 | 入口图吸引正确流量，详情完成理解，复购/分享素材承接后续行为 |
| 增长循环/内容循环 | 一次内容如何带来下一次内容和用户 | 把主图、场景、详情证据做成可复用资产，不虚构传播人数 |
| K因子/病毒循环 | 分享是否带来可验证增量 | 只设计真实分享理由、关系场景或权益 |
| 北极星指标+输入/护栏指标 | 目标与副作用是否平衡 | 同时保护点击/转化和误购、退货、合规、品牌信任 |
| 漏斗/路径/留存 | 流失在哪一层 | 只返修对应的识别、理解、信任、选择、行动或复购画面 |
| 指标树 | 一个结果由哪些节点组成 | 把“转化差”拆成流量、理解、证据、价格、选择和售后问题 |
| CRO | 观察—假设—设计—实验—复盘 | 只在用户允许变体时形成单变量分镜，不自动扩张数量 |
| ICE/RICE/PIE | 多个候选如何排序 | 以影响、证据、可实现性和风险优先；不以伪精确总分替代判断 |
| OODA | 观察—判断—决策—行动 | 生图或投放反馈只改最早失败层 |
| 事前验尸 | 交付前预想失败 | 预查识别错、卖点虚、证据缺、字太多、平台不可用 |
| 5Why/逻辑树 | 找到根因而非表面症状 | 追问“为什么用户没懂/没信/选错”，直到能对应一张图或一个字段 |
| Goodhart定律 | 指标优化是否伤害真实目标 | 不为CTR牺牲商品真实性、退货率、信任和长期价值 |
| Cohort/归因 | 不同批次和渠道能否比较 | 有数据才区分人群/渠道，不把平台归因当成图片因果证明 |
| VOC文本分析 | 从评价、客服和搜索词找真实顾虑 | 只提取与当前商品相关的原话，转成问题、证据和文案命题 |
| PMF/CMF/IMF | 商品、渠道和增量市场是否匹配 | 只作为假设，画面先证明商品与场景的匹配，不写市场规模 |
| 选品五力/单位经济 | 需求、竞争、供应、利润、表达能否闭环 | 影响主推SKU、组合和素材优先级；不生成虚构销量或利润 |
| 货盘金字塔/价格带 | 引流、利润、形象、复购款如何分工 | SKU总览清楚角色与差异，不伪造“爆款/热销”标签 |
| 信任状组合 | 结构、来源、权威、体验等信任信号组合 | 只组合当前真实存在的证据层，不能用多个弱信号包装成强背书 |
| 电商全链路 | 选品、内容、流量、成交、履约、售后、评价、复购 | 找出当前图片只需补的一段，不把全链路都塞入一组图 |
| 单品—爆品—品类—品牌成长 | 商品验证、放量、品类扩展和品牌沉淀处于哪一段？ | 决定本轮优先做单SKU识别、货盘比较、系列记忆资产还是复购承接 | 没有经营阶段资料时只作为假设，不把“爆款/头部/品牌”写成事实 |
| 价格带卡位与SKU精简/长尾平衡 | 多个真实规格怎样减少自相残杀与选择负担？ | 用统一机位、字段顺序和适配边界做价格/规格比较，保留必要长尾 | 不伪造价格锚点、热销排序、利润或库存；每个SKU仍独立保真 |
| 详情页转化信息序 | 痛点、方案、证据、场景、规格、评价、保障、行动的先后是否合理？ | 按买家阻力安排模块，前段先识别和理解，中段证明与代入，尾段选择与边界 | 不为凑齐顺序增加无职责模块；评价、保障和活动必须有真实资料 |
| 主图CTR与三秒信息效率 | 列表缩略图能否一秒认品类、三秒理解一个利益？ | 放大主体、保留品类线索、建立一个差异重音和移动端安全区 | 点击不是唯一目标；不能用夸张、遮挡或错误吸引换取误点 |
| 计划—单元—创意与素材工厂 | 同一卖点怎样生成可比较、可复用的创意变体？ | 只改变一个已授权变量（场景、构图、文案或视觉锤），保持商品层和证据不变 | 用户未明确要测试时不自动增加分镜；一次结果不能证明因果 |

## 补充模型：仅在能改变图片任务时启用

下面是历史版本和行业实践中仍有直接图片价值的补充索引。它们不是必跑清单，也不新增公开字段；只有当某个模型能改变一个真实的买家问题、证据需求、场景、SKU选择、生产方式或返修动作时才读取。纯粹用于经营报表、投放归因或组织管理、却不能改变画面的内容，不在本技能中展开。

| 问题族 | 可调用模型（中文优先） | 只允许编译成什么 | 必须满足的边界 |
|---|---|---|---|
| 人群扩展与内容传播 | 相似人群（Lookalike）、KOC/UGC、ONE-ID/人群迁移、增长循环（Growth Loop）、内容循环（Content Loop）、付费循环（Paid Loop）、病毒循环/K因子 | 目标人群能看懂的共同利益、真实分享理由、跨入口素材连续性 | 不凭空生成画像、粉丝数、传播量、达人背书或转化结果；KOC/UGC必须是真实授权素材或明确的场景假设 |
| 版本实验与因果复盘 | A/B/n、贝叶斯更新、多臂老虎机、Lift Test、PDCA、边际ROI、因果推断 | 单变量主图/海报候选、反馈后最小返修、需要补采的数据 | 一次结果不等于因果结论；不为了测试自动增加分镜；没有数据只保留实验假设 |
| 定价、套餐与价值参照 | WTP/支付意愿、价格弹性、捆绑定价、价格带、价值阶梯、蓝海战略画布 | 真实规格/套装/服务的比较图、选型层级、价值解释 | 价格、原价、节省、库存和套餐必须来自当前资料；模型不能伪造锚点、折扣或“热销” |
| 跨境与本地化 | CAGE距离、EPRG、本地化内容、单位/法规适配 | 语言、单位、人物、场景、包装和平台阅读习惯的适配要求 | 规则和禁限售内容必须用当前官方或用户资料核验；不能把文化刻板印象当作人群事实 |
| 根因与不确定性 | 5W2H、鱼骨图、决策矩阵、事前验尸（Pre-Mortem）、二阶思维、奥卡姆剃刀、Cynefin、情景规划、六顶思考帽、贝叶斯更新 | 最小必要问题、风险清单、候选删除理由、降级路径 | 只保留能落到已有分镜字段的结论；不把思维工具名称写入提示词，不建立第二套评分 |
| 品牌、知识产权与危机 | 品牌资产、品类心智、CBBE、品牌棱镜、独特性资产、知识产权矩阵、危机沟通3T、ESG/LCA | 品牌色/形/符号锚点、授权与禁用元素、真实来源和边界说明 | 品牌、IP、环保、认证、危机事实必须有授权或当前证据；不仿冒、不虚构背书、不用道德压力替代商品价值 |
| AI购物与内容结构化 | AI代理购物、内容智能、AI归因、结构化商品信息 | 清晰的商品字段、可比较的规格、稳定的商品层和可回溯素材 | 只改善机器和用户的理解、检索或复用；不把平台归因、模型输出或自动标签当成商品事实 |

补充模型的调用顺序仍是：先确定商品和买家问题，再通过证据与生产门槛，最后把结论压缩成现有的“图片任务—画面—提示词”字段。模型只提供思考角度，不提供可直接粘贴的营销话术；没有新增图片价值就停止。

## 产品、创意与体验模型

| 模型 | 作用 | 画面编译 |
|---|---|---|
| 双钻/设计思维 | 先发现问题，再定义、开发、交付 | 先发散买家问题和画法，再收敛最小充分图组 |
| Opportunity Solution Tree | 机会—结果—方案—实验 | 从真实顾虑回推一张可验证的图片，不从模板反推需求 |
| Story Mapping/旅程地图 | 按使用流程和触点排内容 | 识别、选择、购买、到手、使用、维护和复购各自有职责 |
| Acceptance Criteria | 用户看完后应相信什么、能决定什么 | 作为每张分镜的成功标准和放行检查 |
| Kano | 基础、期望、兴奋与反向需求 | 基础项讲清，兴奋项做视觉锤，反向项做适配边界 |
| TRIZ/创新十类 | 寻找结构、服务、场景或体验创新 | 把创新原则转成商品专属构图，不改变事实或制造功能 |
| Stage-Gate | 概念、验证、上市、复盘 | 概念稿、证据图、上市图和反馈返修分开，不混淆状态 |
| 情感化设计三层 | 本能、行为、反思 | 先美观停驻，再可用理解，最后用身份/价值完成记忆 |
| 内容4E | 教育、娱乐、情感、参与 | 每组选择一个内容主调，不四种同时堆叠 |
| 叙事传输/消费仪式 | 用故事和仪式建立代入 | 场景、开箱、试用、分享形成连续画面，但不虚构案例 |
| Campaign Brief/Creative Brief | 目标、受众、命题、资产和约束对齐 | 将简报压缩为一个买家问题、一个核心命题、一个证据和一条生产路径，不把简报全文写入分镜 |
| Message Hierarchy/Hook-Proof-Close | 信息层级、钩子、证明、收口 | 首屏钩子、主体证明、结尾行动分别落到不同图片或模块，避免一张图堆满文字 |
| Content Architecture/模块化资产 | 内容职责和素材复用 | 建立跨主图、SKU、海报、详情页可复用的商品层与视觉锚点，按任务改变场景和信息 |
| 隐喻思维 | 把轻、稳、快、净、护等抽象词可视化 | 选择可理解且不改变商品事实的物理隐喻 |
| 模块化资产策略 | 一组身份锚点跨主图、SKU、海报和详情复用 | 保持商品层、色彩、光影和后期资产一致，按任务变体 |
| 视觉独特资产/品牌符号 | 让用户记住品牌而非通用模板 | 固定可见颜色、包装、形状或符号，避免生成漂移 |

## 品牌、行业与长期价值模型

只在品牌主图、长期系列、跨平台资产或用户明确要求行业视角时调用；普通单图不加载整组。

- **定位理论、品类心智阶梯、How Brands Grow**：让商品进入可识别的品类和购买场景，优先扩大“看得见、想得到、买得到”的真实触点。
- **独特性资产、USP/ESP/RSP**：分别强化功能、情绪和关系价值；每次只保留一个可证明的核心记忆点。
- **品牌原型、品牌人格、奢侈品梦想方程**：用语气、留白、工艺、历史和仪式感统一视觉，不用稀缺故事替代来源证据。
- **国潮/文化符号与在地化**：文化元素必须服务商品和目标场景；跨境内容不只翻译，还要核对当地语言、单位、禁忌和平台资料。
- **PEST、波特五力、SWOT、BCG、Ansoff**：只用于发现行业、竞争、产品组合和增长方向，最终必须折叠为“选哪个SKU、证明什么、删掉什么”，不能写成宏观报告。
- **ESG、LCA、绿色供应链、危机沟通3T**：只有材料、认证、来源或事件资料真实存在时，才作为信任或边界图的依据。
- **DTC社区飞轮、品牌社区、会员与复购**：把真实内容、服务、评价和补货连接起来，不虚构社区规模或会员权益。

## 从模型到图型与分镜

模型结论必须落到已有开放图型库或经验证的商品专属图型。可按下表快速编译：

| 模型结论 | 优先图型 | 适合承载的证据 |
|---|---|---|
| “一眼认出、三秒懂” | 标准呈现、主视觉、纯白底、主体+短利益 | 品类、轮廓、颜色、一个已确认卖点 |
| “特征带来什么好处” | 局部特写、材质肌理、工艺细节、使用状态 | 可见结构、说明书、实测或用户资料 |
| “为什么相信” | 功能验证、数据可视化、真实证据层、信任来源 | 测试、认证、授权、真实评价或原文 |
| “内部/装配如何工作” | 爆炸图、剖面图、分层堆叠、装配演示 | 同SKU结构资料、工程图、实拍或用户确认视图 |
| “尺寸/容量/适配怎么选” | 尺寸参照、真人比例、容量展示、SKU对标 | 尺寸、接口、人体/空间和真实SKU差异 |
| “我会怎样使用” | 实景使用、第一视角、多场景、步骤教学 | 真实动作、空间、安装/维护说明 |
| “想记住它、愿意分享” | 创意视觉、原料创意、氛围场景、品牌符号 | 商品专属形态、真实原料、品牌资产和场景依据 |
| “到手是什么、买哪套” | 全家福、多色陈列、量贩堆叠、包装/交付图 | 包装清单、数量、赠品条件、权益和状态 |
| “下一步怎么做” | 利益与行动、流程入口、服务路径 | 真实价格、活动、咨询、预约、核销和服务资料 |

每张编排时写清：唯一买家问题、主图型、辅助表现、证据来源、画面成功标准、前后信息增量和降级路径。营销模型不能让一张图承担两个互相竞争的视觉中心。

## FABE完整编译示例

以下是方法示例，不是任何商品的事实。只有方括号内容被当前商品卡和证据替换后，才能进入正式分镜。

**假设已确认资料**：商品卡确认“[可拆卸杯盖]”是可见结构；说明书和实拍共同证明“[可拆卸清洁步骤]”；没有确认“[抗菌、保温时长或防漏]”。

| FABE阶段 | 内部推演 | 可交给分镜的结果 |
|---|---|---|
| 特征 F | 看得见什么结构？ | [杯盖与杯身的可拆卸连接] |
| 优势 A | 相对当前任务改善什么？ | [能按说明步骤分离清洁]，不延伸为防漏或耐用 |
| 利益 B | 买家得到什么可感知结果？ | [更容易完成日常清洁，减少清洁死角顾虑] |
| 证据 E | 凭什么相信？ | [同SKU拆卸实拍 + 说明书步骤] |
| 图片任务 | 买家要看懂什么？ | [看清连接关系和拆卸顺序] |
| 文案命题 | 一句话怎么说？ | [拆开看清，按步骤清洁]（仅在文字资料允许时使用） |
| 生产边界 | 怎样做才真实？ | [真实商品层/结构实拍做证据，模型只生成中性背景与留白] |

如果没有说明书或实拍，E列为空，正式画面只能展示可见连接，不得把“可拆卸”写成已证实的清洁优势；如果连连接关系也看不清，整条主张删除或退回补证。FAB、FABE、USP、RTB等模型的差别，最终都必须收敛到同一套字段。

## 组合、定量与停止条件

### 定量排序只保留一套

营销模型不另建评分表。先执行硬门槛，再沿用 [image-set-planning.md](image-set-planning.md) 的六维诊断、候选排序和新增价值门；只有复杂候选难分高下时，才使用那一套既有的零到五锚点评估。`ICE/RICE/PIE` 只作为“影响、可实现性、证据和风险”的思考提醒，不再叠加第二个总分，也不能用任何总分抵消证据缺口。

### 形成页面主线

先选一个主路径，再按需要把销售模型和心理模型叠加到具体图片：

`入口识别 → 核心利益 → 证据/机制 → 场景/选择 → 顾虑与交付 → 真实行动`

短主图可以压缩为“识别 + 一个利益 + 一个证据”；SKU图优先“差异 + 适配”；详情页才展开完整链路；白底、透明和无字素材默认不加载完整营销链，只服务复用。

### 停止条件

出现以下任一情况就停止发散并进入编译：

- 新模型没有新增买家问题、证据、选择帮助、场景理解或风险降低。
- 候选只换背景、颜色或形容词，不能改变任务或信息增量。
- 继续扩展需要虚构参数、功效、认证、价格、稀缺、销量、评价、人物或隐藏结构。
- 图组已经覆盖最小充分决策链，剩余候选没有独立职责。
- 生产能力无法稳定实现，且降级路径会改变交付语义。

## 模型红队与自我进化

### 模型红队

在高风险、强促销、复杂SKU或模型组合冲突时，增加一个独立检查角色，只问一个问题：

- **证据红队**：这个模型是否把推断写成事实？
- **买家红队**：缩略图下是否仍能识别、理解和选择？
- **心理红队**：是否使用虚假FOMO、羞辱、恐惧、权威或从众？
- **平台红队**：活动、尺寸、文字、对比度和隐私是否有当前依据？
- **生产红队**：画面是否能由指定工具、真实商品层、后期或补拍完成？

红队只返回失败点、依据和最小修复，不重新写一份营销方案；主控按“事实/安全 > 用户目标 > 输出职责 > 平台 > 心理与创意”裁决。

### 受控自我进化

只学习用户明确表达且有归因的选择、否定、纠正、有效返修和评价结果：

1. 记录“采用了什么推演角度、为什么采用或拒绝、适用于哪个商品/对象/平台”。
2. 把经验抽象成排序偏好或提问方式，不复制某个商品的事实、文案或图片。
3. 新任务先用本轮明确要求覆盖历史偏好；商品事实、安全和证据永远不被偏好覆盖。
4. 没有明确授权时只在本轮使用；需要跨任务保存时记录来源、范围、时间、验证次数和撤销方式。
5. 沉默、候选数量、随机差异、工具失败和无归因指标不升级为偏好。

模型库可以持续扩展，但每个新增模型必须通过同一出口：能否改变一个真实图片任务？需要什么证据？如何生产？不满足就不加载。
