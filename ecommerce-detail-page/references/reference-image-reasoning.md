# 商品参考图推理系统

本文件是商品图到图生图约束的桥梁。它负责给参考图编号、提取保真锚点、判断每张图的作用和能力边界，并为逐张分镜生成可执行的参考图使用说明。

## 目录

`目标` / `参考图编号` / `商品视觉DNA` / `多图冲突裁决` / `参考图能力等级` / `按轴能力矩阵` / `可见面边界` / `多SKU与多状态` / `文字像素保留` / `单图参考策略` / `视角扩展规则` / `商品图到场景的变换` / `输出接口`

## 目标

让图像模型明确：哪张参考图定义商品身份，哪张定义角度、材质、颜色、文字、包装、配件、尺度或使用关系；哪些部分允许重新生成，哪些必须锁定或后期合成。

## 参考图编号

按原始附件到达顺序追加式建立稳定编号：`参考图1`、`参考图2`……。编号必须先于去重、筛选和分组；重复、排除、删除或被替换的图片保留原编号和状态，新图片只追加新编号，永不复用旧编号。如果环境可见附件名、上传轮次、原始序号或安全指纹，同时记录；不可见时不得猜测。后续分镜始终使用同一编号，不因筛选或排序重新编号。

每组正式分镜先建立参考图索引：`参考图编号 -> 附件名或上传轮次+原始序号 -> SKU/状态 -> 当前状态`。编号是推理键，附件绑定是交付键，两者都不能缺失。

每张图记录：

- 图片类型：正面、侧面、背面、斜角、俯拍、细节、包装、配件、SKU合照、手持、模特、场景、尺寸参照或弱参考。
- 主体完整度：完整、局部、遮挡、裁切或多个主体。
- 可定义内容：轮廓、结构、比例、颜色、表面、纹理、品牌文字、型号、包装、配件、角度、尺度、交互。
- 不可定义内容：未展示面、内部结构、真实材质名称、性能、适配、功效、尺寸或数量关系。
- 可信风险：透视畸变、滤镜、色偏、反光、低清、压缩、遮挡、背景污染、错误摆放或非原装配件。
- 生产角色：一个主要角色与零到多个辅助角色，包括身份母图、视角/几何母图、材质母图、文字母图、场景参考、交互参考、SKU参考、包装参考、证据参考或排除图。

## 商品视觉DNA

从全部有效参考图提取一份“商品视觉DNA”，供所有分镜共享：

1. **轮廓锚点**：外轮廓、长宽高关系、厚薄、曲率、开口、边缘与底座。
2. **结构锚点**：部件数量、连接、孔位、接口、按键、缝线、分区、层级和可见机械关系。
3. **比例锚点**：各部件相对大小、间距、对称、重心与产品整体姿态。
4. **材质锚点**：只写可观察表面，如哑光/高光、细纹/粗纹、透明/半透明、金属反射、织物纹理；材质名称需有资料依据。
5. **颜色锚点**：主体色、辅色、透明区域、金属色、品牌色和不可改色区域；警惕拍摄色偏。
6. **品牌文字锚点**：LOGO位置、方向、大小关系、型号、包装原文和不可重绘文字。
7. **包装与配件锚点**：仅使用被清楚展示且关系已确认的包装、配件、数量和套装。
8. **缺失视角**：背面、底部、内部、开合、安装关系或配件组合中未被资料证明的部分。

每个视觉DNA锚点必须记录：`value`、`source_ref`、`region`、`confidence`、`conflict`。视觉DNA只描述可观察和已确认内容，不用行业常识补齐商品结构。跨SKU/状态使用`shared_dna + sku_state_delta`，不能把不同颜色、型号、开合或包装版本混成一份平均DNA。

## 多图冲突裁决

当参考图不一致时，按身份、几何、颜色、材质、文字、包装配件、交互尺度和证据分别裁决，不能用一张整体更清晰的图片覆盖另一张更可信的局部证据：

1. 用户对真实商品的事实纠正优先，并写入事实覆盖记录；用户要求概念改色、改款或创意变化只形成概念变化许可，不得写回真实SKU视觉DNA。
2. 清晰、无滤镜、主体完整的标准商品图优先。
3. 包装/型号原文优先于文件名猜测。
4. 同一SKU优先统一；不同SKU不得合并成一个商品。
5. 颜色冲突保留为待确认或不同SKU，不自行调和。
6. 配件、数量、包装或适配冲突会影响购买时，进入硬阻塞。

## 参考图能力等级

| 等级 | 能力 | 可执行范围 |
|---|---|---|
| P0 不可用 | 主体无法识别或严重冲突 | 先补图/确认，不生成商用分镜 |
| P1 单视角保真 | 一张清晰主图，可锁外观和当前视角 | 白底、浅景、相近机位、背景替换、光影优化；不能真实扩展未知面 |
| P2 多视角保真 | 多张清晰角度，结构基本闭合 | 可规划多角度、场景合成、局部特写；仍不推断内部 |
| P3 商业合成 | 有清晰抠图、包装、配件、细节与交互资料 | 可做完整图组、人物互动、选型、操作与场景资产 |
| P4 结构生产 | 有与目标任务匹配的准确3D/CAD/摄影测量/结构资料 | 只放行对应能力轴：外部新视角、内部拆解、材质贴图和动态状态分别判断；转台照片不证明内部，CAD不自动证明真实材质 |

生产等级决定能做什么图。高创意不能抵消低参考能力。

## 按轴能力矩阵

P0-P4是总体生产等级，还必须逐轴判断，不能用“图片多”掩盖某项关键资料不足：

| 能力轴 | 要判断什么 | 不足时的处理 |
|---|---|---|
| 身份 | 是否能唯一识别商品/SKU/套装关系 | 阻塞或先确认身份 |
| 几何 | 外轮廓、比例、部件、连接和可见面是否完整 | 限制角度，优先抠图/锁定；不生成未知面 |
| 材质 | 表面纹理、反射、透明度和细节分辨率是否可信 | 不做高倍微距，不编造纹理 |
| 颜色 | 是否有无滤镜、白平衡可靠的颜色依据 | 使用主参考图颜色，不从氛围图取色；必要时确认SKU |
| 文字 | LOGO、型号、包装原文是否清晰到可保留 | 真实商品层/后期排版，禁止模型重绘 |
| 包装配件 | 包装、配件、数量、位置和套装关系是否清楚 | 不生成到手清单或额外配件 |
| 交互尺度 | 是否知道尺寸、握持、佩戴、安装与空间关系 | 使用弱尺度安全构图，或补尺寸/交互图 |
| 证据 | 报告、参数、结构或效果是否有真实资料 | 删除证明图、伪文件和效果暗示 |
| 外部新视角 | 是否有准确外部几何支持参考图未展示的角度 | 无模型/CAD/摄影测量时限制为已展示视角 |
| 内部拆解 | 是否有内部结构、层级和连接资料 | 不生成拆解、剖面或内部透视 |
| 材质贴图 | 是否有可信颜色、纹理、反射和贴图依据 | 只做可观察表面，不凭CAD名称猜材质 |
| 动态状态 | 开合、装配、折叠、工作状态是否有序列或结构依据 | 不从静态状态猜动作轨迹和终态 |

每张目标图必须先列出所需能力轴，所有必要轴通过后才可编译商用提示词。P0-P4只作总体摘要。例如P3整体资料仍可能“文字轴不足”，此时可做场景合成，但LOGO和包装文字必须使用真实图层。

## 可见面边界

为主参考图记录可见面：正面、左/右侧、顶部、底部、背面、内部、开合面。目标镜头暴露任何未被参考资料支持的新面时：

目标视角需记录源视角、目标视角、偏航/俯仰方向和是否新增可见面；禁止把左右镜像当新角度。处理顺序为：

1. 换成现有可靠角度；或
2. 使用真实商品抠图，不旋转本体；或
3. 索取对应角度/3D/CAD；或
4. 用户明确概念稿时标注非商用。

“小幅旋转”也必须检查是否会露出新接口、孔位、底部、背面或内部。结构简单不能自动等于新面可猜。

## 多SKU与多状态

- 不同颜色、型号、容量、开合状态、包装版本或配件组合分别建立参考图子组和视觉DNA差异。
- 目标图只能选择一个明确SKU/状态作为主体；SKU总览图可并列，但不得融合部件或颜色。
- 同一商品的开/关、装配前/后、包装内/外状态若资料不全，不从另一状态猜测不可见结构。
- 用户指定SKU后，其他SKU图片只能作为禁止混入的反例，不能作为材质或结构参考，除非确认完全相同。

## 文字像素保留

当品牌、型号、包装文字是识别关键时，默认生产策略是：

- 保留真实商品像素层或高质量抠图；
- 图像模型只生成背景、光影、人物、道具和必要接触阴影；
- 后期校准透视、边缘、综合色与文字清晰度；
- 不让模型“照着写”或重绘精确文字。

如果必须对商品本体做图生图，文字区域应锁定/遮罩保护，最终仍需人工核对。

## 单图参考策略

为每张目标图生成结构化参考策略；本文件只定义约束对象，提示词语言由 `prompt-orchestration.md` 编译：

- 身份母图：固定决定商品/SKU身份，不因逐张换视角而更换。
- 主参考图：逐张视角/几何母图，决定当前可靠机位与可见结构。
- 辅参考图：补充材质、细节、文字、包装、配件或交互。
- 参考用途：具体说明每张图提供什么，不写“综合参考全部图片”。
- 锁定区域：产品本体、LOGO、包装文字、配件、某个结构或颜色。
- 允许变化：背景、道具、人物、光影、摆放、镜头、留白与后期文字区。
- 禁止生成：未知背面、内部、额外部件、错误文字、错误数量、错误SKU或错误适配。
- 冲突优先级：身份母图定义SKU身份；逐张视角母图只定义机位和可见几何；辅图只补其声明能力轴，不得覆盖身份、目标SKU、结构或颜色。
- 实现建议：引用 `production-methods.md` 的模式ID；只写通用控制需求，不在本文件重复定义生产资格，也不假定具体工具存在。
- 能力轴：本张依赖的身份/几何/材质/颜色/文字/包装配件/交互尺度/证据能力及缺口。

## 视角扩展规则

- 同角度换背景：P1即可。
- 小幅旋转、俯仰或透视调整：必须记录源视角、目标视角、偏航/俯仰方向和新增可见面；只有不暴露未知面时可尝试，并标记保真风险，禁止左右镜像。
- 显著新角度、背面、底部、开合、佩戴另一侧或内部：需要对应参考图或P4资料。
- 材质微距：必须有足够分辨率的表面参考；低清图不得编造纹理。
- 人物持握/穿戴：需要确定真实尺寸、接触位置和动作关系；否则使用不强调精确尺度的安全构图或补资料。
- 多件排列：数量和套装关系必须确认；同一商品复制时仍保持结构一致。

## 商品图到场景的变换

图生图任务按三层拆分：

1. **锁定层**：商品本体及需要完全保留的文字/包装/配件。
2. **重建层**：原背景、杂乱反射、非目标手部或临时支撑物等允许清除的区域。
3. **生成层**：新背景、空间、道具、人物、光影、氛围、构图扩展和文字安全区。

提示词必须清楚说明三层，不把“参考商品图”理解为复制原图全部背景与构图。

## 输出接口

所有下游输出先携带参考图合同版本信封：`contract_id`、`contract_type: REFERENCE`、`contract_version: RC-nnn`、规范`status`、`owner: reference-image-reasoning`、`parent_versions.product: PC-nnn`、来源追溯记录与失效原因。只有`status: RELEASED`可被范围、分镜或提示词模块消费。

向商品文档交付：参考图清单、视觉DNA、冲突、缺失视角、参考能力等级和不可改变项。

向资产系统交付：当前资料能支持的图型、不能可靠制作的图片和建议补充素材。

向提示词编排器逐张交付：参考图合同版本、参考图索引、身份母图、主/辅参考图编号、各自能力轴与优先级、锁定区域、允许变化、视角边界、生产模式ID和动态负面项。
