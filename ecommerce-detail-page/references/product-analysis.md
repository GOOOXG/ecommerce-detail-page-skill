# 产品识别与分析系统

本文件统一负责商品身份识别、多图筛选、卖点参数体检和基础图片生产能力评估。参考图编号、视觉DNA、图生图锁定与视角能力由 `reference-image-reasoning.md` 负责；商品字段聚合和用户确认由 `product-dossier.md` 负责。

## 目录

`输入优先级` / `策略输入与证据链` / `身份与图片识别` / `置信度` / `原始视觉观察` / `多图筛选` / `卖点与参数体检` / `视觉承载与素材可用性` / `交接`

## 输入优先级

1. 用户明确文字与用户确认资料。
2. 图片清晰可见事实和产品原文。
3. 当前对话已确认信息。
4. 文件名、包装文字或附件说明线索。
5. 行业常识，只能形成字段需求和策略候选，不能生成商品事实。

用户已点名主图、SKU图、海报、素材图或详情页时，只保存输出意向；商品卡确认前不加载对象专属设计模块。

## 策略输入与证据链

在不推断商品事实的前提下，提取可供 `strategic-intelligence.md` 使用的上下文：用户明确的渠道、投放时点、目标人群、使用情境、经营目标、品牌禁区、已有素材、竞品资料或测试数据。每项都标注来源与状态；用户未提供时不主动虚构，也不把“常见买家”写成确定人群。

把每个可用线索映射为下列四项：

- 可证明主张：拥有已确认资料或可观察画面支持的事实、结构或原文。
- 可用情境：可用于策略候选的真实使用、购买、赠送、安装、补货或内容消费时刻。
- 决策风险：认错、误选SKU、误解功效、尺度失真、产品不保真、证据不足、渠道错配或无法生产。
- 信息缺口：只有补充后才能支持主张、选型、证据或视觉表现的字段；仍按高价值字段规则一次性建议，未补充即自动跳过。

不得从图片中的人物、环境、审美、道具或包装风格推导收入、年龄、地域、效果、认证、销量、品牌定位或竞品关系。此类线索最多作为策略候选，并在缺少用户或可靠资料支持时保持可替换。

## 身份与图片识别

识别并记录：商品名称候选、品牌/型号原文、品类与子类、主商品/配件/替换件/耗材/套装关系、图片类型、主体形态、比例、轮廓、颜色、可见材质、表面反光、纹理、LOGO/文字、包装、配件、可用角度、遮挡区域和不可改变项。

完成基础识别后必须读取 `reference-image-reasoning.md`：先按附件到达顺序给每张原始图片建立永久稳定编号，再做去重、排除和角色分配；输出身份母图、逐张视角/几何母图、材质/文字/交互辅图、商品视觉DNA、P0-P4摘要和按轴能力。后续分镜不得只写“参考上传图片”，必须能指出参考图编号、附件绑定和具体作用。

图片类型包括：单品正面、斜角/侧面、背面、俯拍、手持使用、模特上身、包装、SKU合照、局部特写、材质纹理、尺寸参照和低清遮挡。

- 单品标准照：优先作为商品身份锚点，并用于主图、白底和透明资产。
- 局部特写：用于材质、结构和工艺，但不能代替完整主体图。
- 多SKU合照：先区分SKU、型号、颜色、数量和套装关系，再决定是否可做SKU图。
- 使用/模特图：可用于场景、尺度和人物关系，产品本体仍以清晰标准照为准。
- 包装/配件图：只在包装、套装、礼赠或到手内容有准确关系时使用。
- 低清/遮挡图：只能作为弱参考；用户文字和其他清晰素材足以确认主体身份时可继续，否则阻塞主体确认。

## 置信度

- 高：单一身份候选和识别依据清楚，仍需商品卡确认。
- 中：输出Top3身份候选及差异；用户选择后重建商品文档，不视为确认整卡。
- 低：只询问产品全称、品类或用途中的一个关键问题，信息足够后再继续。

## 原始视觉观察

这里只记录逐图原始观察：主体形态、比例、轮廓、主辅色近似HEX、材质表面、反射与纹理、品牌标志位置、可见原文、包装、配件、可用视角、清晰度、遮挡和潜在冲突。无法确认的属性不填值，不用默认材质或行业常识补齐。跨图视觉DNA、锚点来源和最终商品身份锚点只由 `reference-image-reasoning.md` 派生，避免两个模块同时改写商品视觉事实。

产品质量分级：

- 可直接使用：主体、边缘、颜色、材质和品牌信息稳定。
- 适合抠图合成：主体清晰但背景复杂，优先真实产品合成。
- 适合局部放大：关键纹理、结构、接口或工艺清楚。
- 需要补图：遮挡、过曝、反光、低清、SKU缺失或关键角度不足。
- 仅能概念提案：无法保持真实产品一致性；不得进入正式商用分镜，除非用户明确要求非商用概念稿。

## 多图筛选

多图必须先为全部原始附件追加式编号，再去重、分组，并按主体完整、细节清晰、颜色可信、品牌可见、角度价值和生产可用性判断。重复图保留原编号并标记 `duplicate_of`，排除图保留原编号和排除原因；删除、替换或新增图片都不得复用旧编号。内部可使用四档质量等级，不向用户伪造精确分数：

- 关键素材：可承担首图、商品身份锚点或核心卖点。
- 有效补充：可承担细节、场景、SKU、包装或证据。
- 弱参考：只有缺少更好素材时使用，并限制生成范围。
- 排除素材：主体错误、冲突、过度遮挡或无法商用。

每张可用图分配一个主要角色和零到多个辅助角色；同一图片可以同时提供身份、几何、颜色和文字证据，但每个能力轴必须分别记录可信来源。不得为了“全部利用”把无价值图片塞入分镜。

## 卖点与参数体检

把用户普通描述拆成：商品属性、消费者利益、证据要求、视觉承载和表达边界。

| 状态 | 用法 |
|---|---|
| 已确认事实 | 可进入商品卡和匹配的设计任务 |
| 图片可见 | 只描述形态、颜色、表面、结构和原文，不推导性能 |
| 推断候选 | 只用于人群、场景、构图、信息顺序和补充建议 |
| 自动跳过 | 没有准确值的参数、适配、功效、认证、销量、活动、售后等，不进入用户可见设计 |
| 冲突/禁用 | 先纠正或删除，不用视觉与文案掩盖 |

优先寻找：核心用途、可见结构、材质表面、使用场景、选型防错、到手关系和情绪价值。情绪价值只能作为策略角度，不得伪装成产品功能。

参数缺口按“防买错/安全 > 卖点证明 > 转化价值 > 视觉可视化 > 跨素材复用”排序。最多5项高价值缺口交给 `product-dossier.md` 作为可选补充建议，其余自动跳过。不得给候选数值或诱导用户确认AI猜测。

常见高价值字段：

- 家电数码：型号、尺寸、功率、容量、接口、适配、安装和质保。
- 美妆个护：成分、肤质、规格、用法、备案或检测。
- 食品饮料：配料、净含量、产地、保质期和储存。
- 服饰鞋包：尺码、材质、颜色、版型、洗护和模特信息。
- 家居家装：尺寸、材质、承重、安装和适配空间。
- 母婴宠物：年龄/体重适配、材质、安全标准和禁忌。

## 视觉承载与素材可用性

卖点可映射为局部特写、材质微距、结构说明、真实场景、人物操作、参数信息、证据平铺或留白。只有资料可证明时才能使用结构拆解、效果对比、报告、证书和数据。

这里只说明现有素材能否支持商品身份保持、抠图、局部特写、颜色判断、文字保留、人物交互、已展示角度和证据表达。最终生产方式由 `production-methods.md` 选择。未知背面、内部结构、配件和安装关系不得补画为真实商品。

## 交接

向 `reference-image-reasoning.md` 交付：原始图片清单、基础识别、清晰度、遮挡、色偏、文字与冲突。向 `product-dossier.md` 交付：识别记录、置信度、参考图编号与角色、视觉DNA、参考能力等级、可确认事实、推断候选、高价值补充字段、自动跳过、冲突/禁用、可用卖点、视觉承载、生产建议、用户原始设计意向、策略上下文线索、证据等级、决策风险和唯一阻塞。向 `strategic-intelligence.md` 只交付已确认事实、可观察视觉锚点、用户明确上下文、策略候选和信息缺口；不得把候选升级为商品事实。
