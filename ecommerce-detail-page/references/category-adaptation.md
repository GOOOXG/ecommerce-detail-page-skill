# 全行业商品与输出对象适配

本文件把不同商品的购买难点转成可调用的图片任务。不要按行业名称套固定模板；先从全部有效参考图判断可能的决策特征，再在商品卡确认后用已确认事实正式选择主图、SKU图、海报和详情页任务。所有判断只进入预构建建议、候选图片、图组顺序和最终分镜字段，不另行输出行业分析报告。

## 分两次调用

- **AI预构建初筛**：商品卡尚未确认时，只依据图片可见内容和用户原话提出“可能影响购买的问题、需要补充的事实、可用素材和建议图片”。这些判断全部是待确认假设，不选择最终输出对象、数量、图型或顺序，也不把行业常识写成商品事实。
- **商品卡确认后正式调用**：只使用已确认商品卡、输出范围和平台用途，把真正相关的决策特征转成图片任务、图型、证据与顺序。预构建中未被用户采用或未补证的假设不再沿用。

## 八项商品决策特征

在内部把每项判断为低、中或高，只用于确定优先级，不形成第二套公开评分。一个商品可以同时命中多项；只保留会改变当前分镜的高价值特征。

| 商品决策特征 | 需要判断的问题 | 优先调用的图片能力 | 证据红线 |
|---|---|---|---|
| 身份与SKU复杂度 | 是否容易认错颜色、型号、容量、套装、包装或状态 | 标准呈现、SKU差异、到手全家福、选择防错 | 每个SKU分别绑定有效参考内容；不得平均或融合多个SKU |
| 尺寸、适配与空间风险 | 是否可能放不下、穿不合、装不上、接不上或挡住动线 | 尺寸参照、真人比例、空间落位、接口适配、适用边界 | 需要真实尺寸、接口、兼容型号、空间或人体比例依据 |
| 结构与功能解释难度 | 价值是否藏在内部、连接、层级、工作状态或操作动作中 | 爆炸、剖面、分层、机制路径、状态与性能验证 | 未知内部不得靠品类常识补齐；测试条件和结果必须可核验 |
| 效果与主张证据敏感度 | 是否涉及功效、前后变化、性能数据、成分或对比结论 | 同条件前后对比、数据图解、原料与结果画面、真实测试 | 参数、功效、成分、认证、竞品和结果必须有对应资料 |
| 使用、安装与维护成本 | 用户是否担心不会用、难安装、难清洁、难收纳或耗材难换 | 步骤、正确与错误、清洁维护、收纳携带、耗材更换 | 步骤、部件、工具、周期和安全限制必须来自说明或实证 |
| 安全、合规与人群风险 | 使用对象、环境、动作或传播是否有健康、安全和广告风险 | 使用边界、警示、防错、资质证据、保守场景 | 不新增医疗、安全、适用人群或极限能力结论；不展示可模仿危险动作 |
| 感官、审美与情绪依赖 | 购买是否依赖上身、触感、食欲、香气联想、空间气质或礼赠情绪 | 材质特写、真人/场景、原料创意、感官转译、礼赠场景 | 感官只能做视觉转译，不把氛围写成无法证明的效果或原料事实 |
| 包装、交付与服务复杂度 | 用户是否关心收到什么、包装版本、运输保护、赠品、授权或售后 | 开箱清单、包装层级、组合陈列、权益与服务范围 | 只出现真实到手内容和已确认权益；不伪造赠品、证书、保修或时效 |

## 按输出对象改变重点

同一商品在不同输出对象中不能照搬同一画面。先确认对象、位置、数量、平台和用途，再改变图型优先级：

| 输出对象 | 第一职责 | 优先选择 | 避免 |
|---|---|---|---|
| 主图 | 停驻、品类识别和一个核心购买理由 | 标准主视觉、单一卖点证据、真实使用场景、差异化创意、真实利益 | 参数百科、多个中心、复杂步骤、无法在缩略图读懂的长文字 |
| SKU图 | 选对款并降低误购 | 统一机位差异、尺寸容量、接口适配、套装与到手内容、适用边界 | 跨SKU借色借件、氛围遮挡差异、把道具误认为标配 |
| 海报 | 围绕一个主题形成记忆并承接行动 | 商品英雄构图、时刻场景、关系场景、视觉隐喻、品牌图形、真实权益 | 商品沦为装饰、无依据活动承诺、创意改变真实商品 |
| 详情页 | 连续完成理解、证明、选择、使用与顾虑解除 | 结构细节、功能证据、场景尺度、选型适配、教程维护、信任与交付 | 固定长页、同义重复、每屏同时解决多个购买问题 |

白底图、透明背景图和无字场景图属于可复用基础素材：分别优先商品真实、边缘质量和场景可排版性，不因“全套设计”自动生成。

## 常见类目族的证据重点

类目名称只帮助发现风险，不替代当前SKU证据。一个商品跨类目时，合并真正相关的判断，不套用整行模板。

| 类目族 | 高优先买家问题与图型 | 特别证据和风险 |
|---|---|---|
| 服饰鞋包与珠宝配饰 | 上身比例、版型垂坠、尺码选择、容量、材质工艺、搭配场景 | 锁定真实颜色、纹理、尺寸和穿戴关系；不修改人体结果或夸大材质等级 |
| 美妆个护、食品饮料与健康相关商品 | 质地食欲、成分原料、规格容量、使用步骤、效果与场景 | 配方、成分、营养、功效、人群和前后效果证据门槛最高；文字与标签优先后期 |
| 数码3C、家电与智能设备 | 接口适配、核心结构、工作状态、参数证据、操作与空间关系 | 型号、接口、界面、续航、功率、性能和安全必须对应当前SKU |
| 家居家具、收纳与空间用品 | 尺寸落位、容量、材质、承重、安装、清洁和空间风格 | 精确空间比例、开合动线、安装状态和承重条件不可凭视觉猜测 |
| 工具五金、汽配与工业品 | 型号公差、接口适配、装配、性能测试、安全边界和耐久 | 专业参数、适配清单、受力与操作动作必须可核验；禁止危险示范 |
| 母婴、宠物与安全敏感商品 | 人体或动物接触、卫生、材质、年龄体型边界、清洁和防误用 | 不推断安全、无毒、医疗或适龄结论；人物、婴幼儿和动物动作保持真实安全 |
| 户外、运动与穿戴装备 | 佩戴尺度、动作自由度、天气地形、收纳携带、耐候和安全 | 环境与测试强度必须在已证实范围；不把戏剧化天气当作性能证明 |
| 礼赠、收藏与高价值商品 | 工艺细节、真伪来源、编号版本、包装层级、赠礼关系和价值感 | 授权、限量、产地、证书、礼盒和配件必须真实；不生成虚假编号或印章 |
| 耗材、补充装与周期购商品 | 数量规格、适配设备、单次用量、更换步骤、储存和补货关系 | 不推测使用周期、节省金额或兼容范围；区分单件、多件和补充装 |
| 虚拟商品、数字内容与服务权益 | 实际交付内容、界面或效果预览、使用流程、版本差异、权限和服务范围 | 只用真实截图、演示资料和已确认权益；不得把虚拟权益画成会收到的实体物品 |

## 特殊商品与边界情况

- **定制、手作与天然差异品**：同时锁定不变结构和允许波动范围；样品纹理、颜色或图案不能承诺每件完全一致。
- **预售、概念款与未量产商品**：明确哪些是可靠模型或工程资料；不能把概念渲染伪装成已量产实拍。
- **生鲜、植物与活体相关商品**：处理大小、成熟度、季节和自然差异，不承诺每件外观一致；遵守运输、存活和食用证据边界。
- **多件套、任选组合与买赠商品**：先确认数量、必选/可选关系、包装版本和赠品条件，再决定组合与利益画面。
- **强监管或高风险商品**：提高事实和合规门槛；证据不足时删除主张或停在补资料，不用创意暗示替代。

## 调用顺序

1. 在商品卡确认后，按八项商品决策特征找出当前商品最可能导致停留、误购、怀疑、不会用或退货的地方。
2. 根据已确认的输出对象，把同一特征转成该位置真正能承担的一张图片任务。
3. 读取 [image-set-planning.md](image-set-planning.md)，优先用一个主图型组织画面，并按同一买家问题组合必要且相容的辅助表现；没有合适类型时按同一证据、生产和风险规则建立商品专属候选。
4. 核对参考图、参数、说明、授权、实拍、三维或后期能力；不能证明或稳定生产时降级、补素材或淘汰。
5. 用新增价值去重并安排顺序，再把行业判断折叠进现有分镜字段。不要在最终分镜中输出类目标签、决策特征等级或本文件的内部路由过程。
