# 人物场景与镜头系统

本文件只负责判断是否使用人物、人物承担的商业任务、景别、动作、产品交互、人物一致性和安全边界。不负责商品事实、整体美学或最终分镜格式。

## 使用原则

人物必须帮助用户理解产品、代入场景或建立尺度与情绪，不作为无目的装饰。AI根据商品、买家任务和当前图片职责自主选择“无人 / 手部 / 局部身体 / 半身 / 四分之三身 / 全身 / 人像特写 / 第一视角”，用户可随时改为其他方式。

优先使用人物的条件：

- 产品需要穿戴、手持、操作、安装、清洁、食用、涂抹、坐卧或运动才能看懂。
- 人体尺度、姿势、上身效果、肤感、容量感或空间关系是购买依据。
- 场景代入、目标人群认同、礼赠关系或情绪价值明显影响购买。
- 需要用真实动作证明便捷、顺手、易安装或使用路径，但不得虚构效果。

优先不使用人物的条件：

- 白底图、透明图、纯SKU规格、结构拆解、证据平铺或精密细节需要绝对清晰。
- 人物会遮挡产品核心结构、型号、接口、包装原文或适配关系。
- 当前素材不足以保持产品与人物接触真实，或存在高风险动作和合规误导。
- 用户明确不要人物。

## 景别选择

| 景别 | 主要价值 | 典型商品与任务 | 构图要求 |
|---|---|---|---|
| 仅手部 | 操作证明、尺寸参照、安装/拆卸、触感 | 配件、工具、厨具、家电耗材、数码、开箱 | 手部不遮关键结构，握持点和受力方向真实 |
| 局部身体 | 展示佩戴部位、触感或局部动作 | 饰品、鞋袜、美妆、护具、局部清洁 | 产品和接触部位同焦，裁切自然 |
| 半身 | 强化使用关系、表情和生活场景 | 小家电、厨房、个护、手持产品、母婴陪伴 | 产品位于主视觉区，人物视线或动作引导到产品 |
| 四分之三身 | 同时表现人物、产品与部分环境 | 家居、通勤、户外、健身、生活方式 | 保留场景信息，但产品不得缩小到不可识别 |
| 全身 | 展示上身效果、动作幅度和空间尺度 | 服装、鞋包、运动、户外、大件家居 | 姿态自然，人体比例准确，产品与场景尺度一致 |
| 人像特写 | 情绪、妆效、面部佩戴与品牌气质 | 美妆、护肤、眼镜、珠宝、耳机 | 只呈现有依据的效果，皮肤与五官自然，不制造医疗变化 |
| 第一视角/越肩 | 增强临场操作和步骤理解 | 安装、烹饪、清洁、数码操作、开箱 | 接触关系清楚，避免多手、错位和视角矛盾 |

## 商品到人物策略

- 服饰鞋包：全身或四分之三身负责版型与搭配，局部负责面料、五金和穿着细节。
- 美妆个护：人像特写或半身负责使用与情绪，微距负责质地；不得用生成前后对比暗示无证据功效。
- 家电家居：半身、四分之三身或手部负责操作、安装、尺度和空间关系；结构页仍优先无人产品特写。
- 食品饮料：手部、半身或多人关系可表现食用时刻；不得制造虚假份量、拉丝、汁水或口感证据。
- 数码3C：手持、半身、第一视角负责操作与生态，纯产品图负责接口和参数。
- 母婴宠物：只用安全、受控、符合年龄和真实照护逻辑的动作；不得让婴幼儿或宠物执行危险交互。
- 机械配件/耗材：优先手部安装、第一视角或半身工况；全身只在空间尺度和职业场景确有价值时使用。

## 动作与物理关系

人物动作必须能解释“正在做什么、产品如何被拿取/穿戴/安装/使用、动作完成后用户得到什么”。提示词明确：

- 左右手、握持点、接触面、受力方向、身体朝向和视线方向。
- 产品与手、身体、桌面、设备或环境的真实尺度和接触阴影。
- 产品主体遮挡比例；默认不让人物或道具遮挡核心卖点区，场景图通常保持关键结构至少75%可见。
- 动作前、中、后选择一个最能证明页面命题的瞬间，不在单张中混合多个互相冲突的动作。
- 手套、围裙、防护用品等只在真实任务需要时使用，不把角色服装伪装成专家或权威背书。

## 人物与活动一致性不变量

同一图组或活动需要重复人物时，保持以下不变量：人物类型、年龄段、发型、服装、配饰、妆容、肤色表现、道具、空间和光线。国内电商生活场景可优先使用与目标人群匹配的亚洲成人模特，但不得机械套用；用户提供品牌人群或授权模特时以用户资料为准。

人物不应在不同图片中无理由改变身份、服装、手部特征、佩戴方向或产品使用方式。等量并列结构可以使用不同人物，但必须有明确的人群测试变量。

## 合规与质量

- 不生成可识别名人、专家、医生、达人或真实人物仿冒，不暗示未经授权推荐。
- 未成年人、孕妇、老年人、残障人士和宠物场景只在商品确有关系且动作安全时使用，不把群体身份当作无依据功效证明。
- 避免人体畸形、多手、多指、手指穿模、关节反向、皮肤塑料感、眼神错位、产品悬空和接触阴影错误。
- 涉及厨房、电器、刀具、火源、高处、机械、化学品或清洁时，动作符合安全常识；不得为了视觉冲击制造危险操作。
- 人物生成负责场景与姿态，精确品牌、型号、参数和长文字仍由真实产品资产与后期排版保证。

## 输出接口

向视觉工作包和提示词编译器交付：是否使用人物、人物商业任务、人物类型、景别、机位、动作瞬间、产品接触方式、遮挡上限、视线动线、服装道具、人物一致性约束、安全边界、负面提示词和可修改位置。
