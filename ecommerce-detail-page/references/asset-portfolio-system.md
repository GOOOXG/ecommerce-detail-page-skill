# 电商资产组合系统

本文件负责根据商品图、用户目标和策略，推演最小充分图组，并让主图、SKU图、详情页、海报、产品素材图及扩展渠道图片各司其职。最终输出不是资产咨询报告，而是逐张图生图分镜提示词。

## 资产规划原则

1. 从购买任务和渠道承接反推资产，不从固定套餐反推需求。
2. 用户明确点名对象时直接写入范围卡并紧凑确认；AI只补充明显缺口与不做的代价，不强制扩容。
3. 每类资产承担不可替代任务；同一卖点跨资产出现时必须改变职责：入口、解释、证明、选择、使用或复用。
4. 优先复用商品、品牌、证据和视觉系统，不机械复用同一构图与文案。
5. 资产数量服从最小充分闭环、真实投放计划与生产预算。

## 资产角色

| 资产 | 核心职责 | 不能替代 |
|---|---|---|
| 主图/首图 | 在列表或商品轮播中快速完成识别、相关性和点击理由 | 深度证明、复杂参数、完整使用教育 |
| SKU图 | 帮助买对：规格、型号、颜色、套装、数量、适配、推荐关系 | 虚构SKU差异或用情绪掩盖选型 |
| 详情页 | 承接入口，解释价值、提供证据、演示使用、比较选择、管理预期与顾虑 | 没有证据时不能靠长篇制造可信度 |
| 海报 | 为一个传播时点、主题、人群或活动形成独立记忆与行动入口 | 多主题商品百科 |
| 白底图 | 清晰、标准、可审核的商品基础资产 | 场景种草和复杂信息 |
| 透明图 | 供后期、跨平台、组合与动态素材复用 | 最终场景成品 |
| 无字场景图 | 提供生活化、内容化、可二次排版的场景资产 | 精确参数或促销表达 |
| 证据/操作素材 | 证明结构、工艺、流程、尺度、安装或使用 | 无资料时不得伪造 |
| 扩展内容关键帧 | 支持短视频、直播、社媒、私域二次制作 | 不宣称已生成完整视频或互动成品 |

## 资产缺口判断

检查五类缺口：

- 入口缺口：有详情但没有能准确吸引目标流量的入口图。
- 选型缺口：有卖点但没有规格、适配和套装防错。
- 证明缺口：有主张但缺结构、数据、证据、操作或真实边界。
- 使用缺口：买家不知道怎么安装、使用、维护或预期结果。
- 复用缺口：只有成品图，没有白底、透明、无字场景和统一视觉底座。

建议增加资产时说明：解决什么问题、需要什么证据、生产成本、可以不做的条件与代价。

## 组合模式

- **单点资产**：一个明确对象和任务。直接执行，不加载全案。
- **成交闭环**：入口图 + 必要SKU/选型 + 最小详情承接。
- **内容种草闭环**：内容/海报/场景入口 + 商品识别 + 证据/使用承接。
- **活动闭环**：主题海报 + 主图/商品卡 + 详情/权益承接；所有活动事实需有依据。
- **全渠道资产库**：白底/透明/无字场景底座 + 各渠道变体 + 组件规范。
- **品牌增长系统**：统一记忆资产、货盘分层、渠道适配、复购与实验计划。

## 跨资产信息去重

为每个事实或主张分配一个首要角色：

- `钩子`：第一次出现，建立兴趣或相关性。
- `解释`：把属性翻译为利益与使用意义。
- `证明`：用可见结构、参数、资料或真实演示支持。
- `选择`：帮助判断哪款、多少、是否适合。
- `使用`：说明安装、操作、维护或体验边界。
- `收口`：处理最大顾虑、退货风险或行动条件。

同一内容只有在角色变化时才可跨资产复用。近义改写不算新信息。

## 多平台变体

先确认组级不变量：商品、事实、品牌记忆、核心价值和证据。再根据平台改变：

- 入口情境与注意力时长。
- 主体占比、文字密度和阅读方向。
- 真实感、内容感、促销感或专业感。
- 人物角色、场景、行动与信任组件。
- 画布、版式和后期安全区。

不要用同一张图仅改尺寸作为完整的平台适配。

## 数量与结构

数量先服从用户指定与 `execution-engine.md` 的对象默认，再由任务数检验是否同义重复。每新增一张必须能回答一个此前未解决的问题。多图可采用递进、并列或混合，并按 `structure-selection.md` 建立结构合同；交互模式确认，自动模式内部确认。

资产计划至少记录：对象、数量、平台/位置、唯一职责、前后承接、证据需求、生产方式、复用关系、最大风险和是否需要用户确认。

## 交接

向场景、营销、视觉与生产模块交付：

- 资产组合与优先级。
- 每组结构和每张唯一职责。
- 跨资产不变量与可变项。
- 信息首要角色和去重规则。
- 缺口、证据、生产依赖与不做代价。
- 用户明确范围与AI建议范围的区别。

最终只生产用户确认或明确授权的范围。
