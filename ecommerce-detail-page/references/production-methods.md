# 视觉生产形式系统

本文件只负责选择实拍、3D、插画、创意合成及动态扩展的生产方式，并定义输入资产和真实性边界。不负责风格、主体、背景或营销组件。

## 生产形式

| 系统 | 适用任务 | 必要输入 | 风险边界 |
|---|---|---|---|
| 实拍写实 | 全品类主体、真实使用、材质和证据 | 真实产品、拍摄条件或可用原图 | 保持颜色、比例和细节，不做过度修图 |
| 图生图保真 | 在真实产品基础上更换背景、光影和环境 | 清晰产品图、商品身份锚点、保护遮罩或可验证的像素保留能力 | “图生图”本身不保证保真；不能稳定保护结构、LOGO、包装和原文时禁止重绘商品层 |
| 背景生成+后期合成 | 品牌产品、复杂文字、包装或高保真商业图 | 真实抠图/透明通道、保护遮罩、背景板要求、商品位置与尺度、后期能力 | AI不重绘产品本体，必须补接触阴影、边缘、透视和综合色 |
| 3D渲染 | 新外部角度、结构、家具、家电、3C和虚拟棚拍 | 准确3D模型/CAD/摄影测量；只有多角度照片时仅支持已展示外表面重建 | 转台照片不证明内部；CAD不自动证明材质贴图；没有对应资料时不能生成未知背面和拆解结构 |
| 手绘插画 | 文创、食品、母婴、潮玩、主题叙事 | 原创或已授权视觉方向 | 不模仿受保护IP，不用插画掩盖商品真实性 |
| 创意合成 | 海报、创意主图、超现实视觉锤 | 真实产品资产、可执行合成关系 | 创意只改环境与展示，不篡改产品和效果事实 |
| 动态视频 | 主图短视频、详情视频、动态海报 | 脚本、镜头、产品动作、时长和平台规格 | 当前技能只提供关键帧/镜头设计时需明确，不伪装已生成视频 |
| 360度交互 | 高端数码、家电、家具、潮玩全角度查看 | 完整3D模型或全角度实拍序列 | 单张参考图不能推断不可见面；实际交互需外部制作能力 |

## 选择顺序

1. 产品真实性要求高、品牌文字复杂：优先真实产品抠图加背景生成和后期合成。
2. 材质、佩戴、食欲、肤感、人物互动依赖真实体验：优先实拍或高质量图生图保真。
3. 需要任意外部角度时必须有准确外部几何；需要内部或拆解时必须另有内部结构资料；需要真实材质时必须另有可信贴图/材质依据。三项分别放行，不能用“有多角度图”一并替代。
4. 需要文化叙事、童趣或原创IP气质：可用插画，但真实商品仍保持可识别。
5. 需要超现实记忆点：使用创意合成，产品本体不变。
6. 用户要求视频或360时，先确认是否只需要脚本/关键帧/提示词，避免把静态image分镜当成动态成品。

## 混合生产管线

专家级电商成图优先采用可控混合流程：

`真实商品资产 -> 产品锁定/抠图 -> AI生成背景与氛围 -> 人物/道具按需合成 -> 接触阴影与色彩统一 -> 精确文字后期排版 -> 事实与平台复核`

混合管线可提高产品一致性，不等于允许改变产品。生成模型擅长场景、光影和创意，不负责凭空还原未知结构、准确长文字或真实证据。

## 生产可行性

每个方案记录：模式ID、所需输入、可直接生成部分、必须后期部分、需要补拍/建模部分、成本等级、返修灵活性和商用真实性。逐张使用前检查该图所需的身份、几何、材质、颜色、文字、包装配件、交互尺度、证据、新外部视角、内部拆解、材质贴图与动态状态能力轴；任一必要轴为阻塞时，不得仅凭总体P级放行。无法执行的高概念方案不得作为唯一首推。

## 输出接口

向场景工作包和提示词编译器交付：生产形式、输入资产、产品保真方式、AI生成范围、后期合成范围、文字处理、未知结构边界、成本/可行性和动态扩展说明。
