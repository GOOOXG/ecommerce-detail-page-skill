# 消费者心理系统

本文件只负责转化核心驱动力、信任与从众、人群心理和客单价机制。不写购买路径模型、转化框架库或最终分镜模板。

## 目录

`转化核心驱动力` / `信任与从众` / `消费者心理模型` / `信息接收与选择架构` / `人群心理构造` / `人群与客单价` / `输出接口`

## 转化核心驱动力

每次只选1个主驱动力，最多补1个次驱动力：

- 点击率：主图、信息流海报优先，小图可读、视觉锤、强利益点。
- 停留率：详情页首屏和前三屏优先，悬念、痛点、场景和视觉连续性。
- 完读率：中长详情页优先，信息层级、渐进披露、下滑钩子。
- 加购率：标品和低中客单优先，价格理由、套装、规格选择。
- 咨询率：高客单、定制、复杂参数优先，问题入口和专家感解释。
- 支付转化率：证据、价值解释、风险降低、行动收口。
- 退货风险：SKU、尺码、参数、适配边界和期望值管理。
- 复购价值：会员、耗材、补充装、使用周期和私域承接。

## 信任与从众

只能使用有依据的证据；没有依据时自动跳过证据组件，不要编造或保留占位。

- 权威信任：检测报告、执行标准、授权、专利、认证。
- 经验信任：实测过程、使用前后、真实开箱、场景反馈。
- 从众信任：真实销量、榜单、复购、评价截图、达人实测。
- 坦诚信任：主动说明不适合人群、使用边界、色差或安装限制。
- 一致性信任：全页字体、色彩、道具、光影、图标和参数框一致。

## 消费者心理模型

每次只选择能解释当前购买阻力的模型，不把心理学名词直接写成图内文案。

| 模型 | 判断问题 | 电商落地 |
|---|---|---|
| Fogg行为模型 | 用户是否同时具备动机、能力和触发 | 降低操作门槛，增加行动触发和购买理由 |
| 精细加工可能性模型 | 用户是理性深读还是快速扫读 | 高客单给证据和参数，低客单给强视觉和短利益 |
| 前景理论 | 用户对损失更敏感还是对收益更敏感 | 用风险降低、损失避免和价值解释降低犹豫 |
| 损失厌恶 | 不买会失去什么 | 只做真实、温和提醒，不制造虚假恐慌 |
| 锚定效应 | 用户用什么参照物判断贵不贵 | 用真实价格锚、生命周期或替代方案对比 |
| 社会认同 | 用户是否需要别人也在用的证据 | 用真实评价、UGC、榜单或达人实测；无依据时自动跳过 |
| 权威原则 | 用户是否需要专业背书 | 用检测、标准、专家或机构信息；必须有依据 |
| 稀缺原则 | 用户是否受限时和稀缺影响 | 只在活动真实时使用，不能编造限量和倒计时 |
| 承诺一致 | 用户是否可从小动作走向下单 | 领券、咨询、收藏、加购、选择SKU逐步推进 |
| 禀赋效应 | 用户是否一旦代入就更想拥有 | 场景代入、开箱预览、使用后状态和搭配效果 |
| 认知流畅 | 用户是否能快速理解 | 简化信息层级、减少术语、主卖点前置 |
| 峰终定律 | 用户记住峰值体验和结尾感受 | 设计视觉高潮页和尾屏顾虑兜底 |
| 蔡格尼克效应 | 未完成信息会驱动继续看 | 用下滑钩子和半露出信息，但不故弄玄虚 |
| 认知失调 | 反常识会激活注意 | 适合首屏截停，必须能被事实或常识支撑 |
| 选择悖论 | 选项越多越难决策 | SKU图做默认推荐、分层选择和防选错提示 |

## 信息接收与选择架构

用于把心理模型转成页面信息层级，不直接把模型名写成画面文案。

| 机制 | 适配场景 | 页面动作 |
|---|---|---|
| 框架效应 | 同一卖点可从收益或避损表达 | 高风险品类用避损，悦己品类用获得感 |
| 心理账户 | 用户把钱归入日常、享乐、礼赠或投资账户 | 日用品讲长期省钱，高客单讲资产感和长期价值 |
| 支付痛苦 | 价格让用户犹豫 | 用生命周期、使用频次、套装价值或服务兜底解释 |
| 折中效应 | SKU或套餐多 | SKU图突出中间推荐款，但不能虚构“热销” |
| 诱饵效应 | 需要引导套餐选择 | 只在真实SKU存在时使用，不制造虚假规格 |
| 默认选项效应 | 用户选择成本高 | 明确“适合大多数人”的推荐逻辑和适配边界 |
| 目标梯度 | 领券、会员、加购、满减 | 用进度、阶梯和下一步动作降低行动阻力 |
| 叙事传输 | 场景页、品牌页、海报 | 用情境、冲突、解决和结果增强代入 |
| 心理距离 | 远期价值或即时决策 | 远期讲愿景，近期讲步骤、价格、适配和行动 |
| 触觉与具身认知 | 材质、手感、温度、舒适度 | 用手持、微距、柔光、动作和接触画面表达 |

## 人群心理构造

先判断人群的“购买防御”，再决定卖点顺序：

| 防御类型 | 典型顾虑 | 优先破解方式 |
|---|---|---|
| 怕买错 | 型号、规格、尺码、适配不确定 | SKU对比、选型表、适配边界 |
| 怕没用 | 功能不明显、效果不确定 | 实测、对比、过程可视化 |
| 怕麻烦 | 安装、学习、清洁、维护成本高 | 步骤压缩、懒人场景、售后说明 |
| 怕不安全 | 材质、成分、儿童宠物、食品接触风险 | 检测、标准、边界提醒 |
| 怕廉价 | 质感、包装、送礼、空间搭配不够体面 | 材质微距、生活方式、礼赠场景 |
| 怕被坑 | 价格、促销、夸大宣传 | 坦诚边界、价值拆解、真实证据 |
| 怕后悔 | 售后、退换、耐用、期望落差 | 兜底承诺、期望值管理、参数说明 |

## 人群与客单价

| 人群类型 | 核心心理 | 表达方式 |
|---|---|---|
| 理性参数型 | 怕买错、怕不值 | 参数对比、证据链、适配边界 |
| 效率省事型 | 怕麻烦、怕学习成本 | 一步到位、少操作、流程可视化 |
| 审美悦己型 | 怕丑、怕廉价 | 氛围、材质、搭配、生活方式 |
| 安全谨慎型 | 怕风险、怕伤害 | 合规证据、安全边界、使用提醒 |
| 价格敏感型 | 怕贵、怕被坑 | 生命周期平摊、隐形成本、套装价值 |
| 礼赠社交型 | 怕没面子、怕不合适 | 包装、场景、人群、祝福语气 |
| 圈层认同型 | 怕不专业、怕不懂行 | 圈层语言、专业场景、垂直符号 |

客单价机制：

- 低客单：快速理解、强利益、强行动，减少解释成本。
- 中客单：卖点证明、场景覆盖、对比和评价更重要。
- 高客单：留白、质感、证据、参数解释、售后和品牌可信度必须前置。
- 高频复购：强调使用周期、补货便利、会员权益和长期成本。
- 低频耐用品：强调寿命、稳定、安装维护、售后和长期价值。

## 输出接口

- 主转化驱动力：1个。
- 次驱动力：可选1个。
- 主要人群心理：1到2类。
- 信任策略：权威、经验、从众、坦诚或一致性。
- 客单价策略：低客单、中客单、高客单、复购或耐用品。
- 主要心理模型：1到2个。
- 选择架构：默认、折中、行动阶梯、心理账户或支付痛苦。
- 购买防御：1到2个。
