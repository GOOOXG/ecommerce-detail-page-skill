# 返修与失败诊断模块

本文件是返修范围识别、修改事务、依赖影响、回退层级、局部重算和返修回归的唯一来源。不负责普通导航、长期偏好、专业模型选择或最终分镜模板。

内部流程为“失败诊断 + 最小补丁”。每次操作创建补丁事务：`快照 → 诊断 → 保护 → 修补 → 回归 → 发布/回滚`，目标是修改最小失败层并保持追溯链完整。对已发布单图的任何修改都必须创建新的原子 FR/PR 配对；“最小”表示语义修改最小，不允许只升级 PR 版本。

## 返修输入

提取：输出对象、图序或素材组、失败字段、不满意表现、必须保留内容、新要求、是否重发整组，以及是否需要前后页联动。用户只说“返修第2张”时，默认只改当前素材组第2张，并只检查相邻页面连续性。

信息不完整时先根据当前合同、工作包和草案推断修改目标；只有无法判断要改哪一张、哪一组或产品事实发生冲突时，才问一个最小问题。

逐图流程还要读取当前单图状态：待确认卡直接修改；已发布卡先创建待替换的新 FR/PR 配对并计算后续影响；已失效卡必须重算，不能继续写入最终分镜。

## 修改事务

每次返修按一个可回溯事务执行：

1. **快照**：记录返修前已发布合同、分镜草案、FR/PR 配对、工作包、发布闸门发现项和偏好事件。
2. **定位**：确定直接失败合同/草案字段、根因候选、受影响下游和只需检查的相邻页。
3. **保护**：冻结未受影响素材组、已确认事实和用户明确要求保留的内容。
4. **重算**：只重算失败合同或草案字段及必要下游，不用全案覆盖局部问题。
5. **比较**：检查修改前后是否真正解决原问题，是否引入事实、重复、连续性或一致性回归。
6. **提交**：通过回归后，把新FR/PR以同一`release_pair`先设为`PENDING`，确认或自动内审后原子`RELEASED`，同时使旧配对的FR/PR同步`INVALIDATED`；任一步失败则不部分提交，回滚到快照并提升返修层级。

## 问题归因

| 表现 | 首要回退 | 必要联动 |
|---|---|---|
| 产品识别错、形态变了、品牌文字错 | 商品合同/参考图合同 | 重建确认卡；确认前冻结全部下游 |
| 参数、型号、适配或事实错 | 商品合同 | 重建确认卡，并检查文案、SKU、证据和合规 |
| 做错素材类型或数量 | 范围合同 | 检查场景、文案、编号和必要画布 |
| 递进/并列/混合结构选择不合适 | 结构合同 | 当前素材组角色、文案矩阵、视觉节奏、提示词和依赖关系 |
| 人群、卖点、场景、美学或文案主线整体不合适 | 方向合同 | 当前素材组策略、文案、视觉、逐张角色和提示词 |
| 页面任务重复、顺序断裂 | 方向合同/分镜草案 | 文案命题、图型和视觉节奏 |
| 文案重复、空泛、生硬或越界 | 分镜草案文案字段 | 当前页与前后页语义指纹、证据等级 |
| 风格、颜色、光影、角度不对 | 方向合同或分镜草案视觉字段 | 局部问题只改当前页；组级不变量变化时检查整组一致性 |
| 实拍、图生图、3D或合成方式不可执行 | 分镜草案生产字段 | 产品保真、输入资产、场景摘要、视觉栈和后期边界 |
| 中途新增尺寸、型号、材质、适配或其他准确字段 | 商品合同 | 重发商品卡并只重算引用该字段的任务、文案、组件和提示词 |
| 画布比例或尺寸错误 | 分镜槽位合同 | 仅对应素材组每张的比例/尺寸子项，并回归检查强制分镜槽位布局 |
| 夸大、侵权或证据不足 | 商品合同/发布闸门发现项 | 删除主张、重写文案和提示词 |
| 分镜字段、页码或源码块错误 | 输出模板 | 只修格式，不重算专业策略 |

## 返修层级

| 层级 | 适用 | 动作 |
|---|---|---|
| L1 字段修正 | 标题、卖点、颜色、局部构图、单个字段 | 只改失败字段并检查关联字段 |
| L2 单页重做 | 页面任务正确但整页表达失效 | 保留产品、事实和顺序，重做当前页文案、视觉与提示词 |
| L3 素材组重排 | 多页重复、顺序不合理、递进/并列结构错误 | 重建该组策略、文案矩阵和视觉节奏 |
| L4 策略重推 | 定位、人群、核心卖点或购买路径不成立 | 保留商品合同，重算方向合同及其下游 |
| L5 主体纠错 | 商品身份、型号、SKU关系错误 | 冻结交付，重建商品信息确认卡；重新确认后再发布商品与参考图合同 |

默认从最小可行层级开始。连续两轮仍未解决同一问题时提升一级；主体或事实错误可直接进入L5或相应上游合同。

## 依赖边界

- 商品合同变化：先将旧商品合同标记为`INVALIDATED`，冻结全部受影响下游；更新草案、重发确认卡并获确认后，再按字段影响重算。
- 参考图合同变化：所有依赖受影响身份、视觉DNA或能力轴的素材组失效并重算。
- 范围合同变化：只影响对应素材组的数量、角色、顺序和编号。
- 方向合同变化：重算当前素材组所有依赖该方向的人群、卖点、场景、文案与视觉任务；其他素材组保持不变，除非用户修改共享品牌方向。
- 结构合同变化：读取 `structure-selection.md`，当前素材组全部下游设计失效；只保留能映射到新角色且语义不冲突的已发布卡，其他卡重新确认。
- 分镜槽位合同变化：只修改对应素材组每张`画布与槽位`中的比例/尺寸子项，不删除产品锚点、占比、完整性、裁切边界或实际安全区；若比例显著改变，再联动分镜槽位构图安全区并产生受影响页面的新 FR/PR 配对。
- 分镜草案文案字段变化：只改指定字段或页面，并检查前后页语义去重。
- 分镜草案视觉字段变化：局部要求只改指定页；明确修改全组风格时先更新方向合同，再重算整组。
- 分镜草案生产字段变化：只重算依赖该制作方式的页面；从3D降级为真实产品合成时，删除未知角度和结构表达。
- 模板错误：只修模板和编号，不触发产品、营销或视觉重推。

局部返修不得悄悄改变其他素材组、产品事实、已确认字体、全组画布或用户明确保留项。

## 逐图返修事务

- 当前待确认卡：按 `frame-confirmation.md` 的`2-1`到`2-10`定位字段，修改后重新自检并完整重发当前卡。
- 已确认当前卡：先保留旧 FR/PR 配对快照并标记待失效，基于当前上游与分镜槽位创建新配对候选；通过返修回归并再次确认后原子发布新配对、同步使旧配对失效，不能原地替换版本。
- 已确认前序卡：修改前先说明将“保持确认、仅检查、标记失效”的后续图序；用户确认影响范围后执行。
- 递进式：任务、命题、证据或内部阅读衔接变化时检查全部下游；仅局部措辞、装饰且不影响语义时只检查相邻卡。
- 等量并列：局部变化只影响当前卡；商品合同、全组分镜槽位、风格和组件等共享约束变化才影响其他卡。
- 混合结构：主链按递进式处理，独立变体按并列处理；共享价值主张变化时检查两部分。
- 用户重选结构：先展示新结构注解和影响图序，确认后再解除受影响卡；不得静默切换或只改“图组结构”标签而沿用旧文案顺序。
- 返修后必须输出差异摘要和完整当前卡；未经再次确认不能推进游标或进入最终聚合。
- 只改提示词时也复制未变化的分镜正文到新 FR，并与新 PR 共同提交；只改分镜时必须重检提示词并生成新 PR。旧配对在新配对成功前保持完整，不出现一新一旧的混合状态。

## 口语转专业动作

- “更能卖”：定位相关性、利益、证据、价值解释或行动中最弱的一项，不默认加夸张词。
- “更高级”：降低促销腔和无意义装饰，增强材质、留白、字体克制、光影层次和同级道具。
- “更真实”：降低概念合成感，修正结构、接触阴影、尺度、人物交互和证据边界。
- “别太乱”：减少页面任务、文案层级、颜色、标签和装饰组件。
- “文案重复”：读取文案系统，重建唯一命题和语义指纹，不做近义词替换。
- “产品不对”：立即回到产品分析，不能用背景、光影或文案掩盖主体错误。

## 局部返修交付

- 用户只要求返修指定页：只输出该页，保留原编号，例如 `## 第2张`，不得重编号为第1张。
- 用户要求“返修第2张并重发整组”：完成局部修改后输出整个素材组，并从第1张真实递增到最后一张。
- 用户要求修改多个不连续页面：只输出点名页面并保留各自原编号；除非用户要求重发整组。
- 源码块外可说明保留项、修改范围和联动检查；源码块内仍只放分镜正文。

## 回归检查

返修完成后必须检查：

- 原问题是否消失，用户明确保留项是否未变。
- 产品主体、事实、证据、英文原文和合规边界是否正确。
- 当前页与前后页的任务、语义、视觉节奏和内部阅读衔接是否连续。
- 对应素材组画布比例/尺寸子项是否一致；未指定时是否只省略这些子项，同时保留每张强制的产品锚点、占比、完整性、裁切边界和实际安全区。
- 局部输出是否保留原编号；整组输出是否从第1张连续递增。
- 单对象返修是否没有混入其他输出对象。
- 最终源码块是否没有导航、循环、测试说明或内部推演。
- 逐图返修后当前卡是否重新确认，受影响下游卡是否完成检查或失效处理。

## 返修循环

按 `loop-control.md` 最多2轮执行“定位 → 定向候选 → 回归检查 → 更新合同/草案”。两轮仍失败时，提升返修层级、回到最近上游合同，或向用户询问一个能解除问题的关键约束。

## 返修摘要

源码块外按需显示：

- 保留不变：未受影响合同、工作包和页面。
- 本次修改：具体字段、页面或素材组。
- 联动检查：只检查但未修改的相邻内容。
- 剩余阻塞：只记录尚未解除且会使主体、安全或合法性无法成立的问题；没有准确值的非关键字段不显示。
- 可继续动作：读取 `next-action-engine.md` 生成编号`0`到`9`的10项菜单。

## 输出接口

向执行模块交付：返修层级、事务快照、保留合同、重算合同、相邻检查、影响范围、旧/新 FR 与 PR 版本、旧/新`release_pair`、原子状态变化、失效卡、回归结果、输出范围和剩余阻塞。导航由下一步决策模块生成；单图确认读取逐图工作流，最终正文由统一分镜模板生成。
